2019 AMC 10B Problem 13

2019AMC 10BProblem 13概率与统计平均数与数据集平均数数据

Problem Statement

What is the sum of all real numbers $x$ for which the median of the numbers $4,6,8,17,$ and $x$ is equal to the mean of those five numbers?

Choices

  1. A-5
  2. B0
  3. C5
  4. D$\frac{15}{4}$
  5. E$\frac{35}{4}$

Answer

A. -5

Solution

Step 1: Compute the mean expression

The five numbers have sum \[4+6+8+17+x=35+x,\] so their mean is \[\frac{35+x}{5}.\]

Step 2: Consider possible medians

The median must be one of the middle values after inserting $x$ into $4,6,8,17$. We check intervals for $x$.

Step 3: Find the working case

If $x\le4$, the ordered list has median $6$. Setting mean equal to median gives \[\frac{35+x}{5}=6,\] so $x=-5$, which fits $x\le4$.

Step 4: Check other intervals

If $4\le x\le6$, the median is $6$, again giving $x=-5$, which does not fit. If $6\le x\le8$, the median is $x$, giving $x=\frac{35}{4}$, which does not fit. If $x\ge8$, the median is $8$, giving $x=5$, which does not fit.

Step 5: Conclude

The only real value is $x=-5$, so the requested sum is $\boxed{-5}$.

Key Idea

Break into cases based on the possible median.
