2016 AMC 10A Problem 23

2016AMC 10AProblem 23数论质因数与整除质因数整除

Problem Statement

A binary operation $\diamond$ has the properties that $a\diamond(b\diamond c)=(a\diamond b)\cdot c$ and that $a\diamond a=1$ for all nonzero real numbers $a$, $b$, and $c$. The solution to the equation $2016\diamond(6\diamond x)=100$ can be written as $\frac pq$, where $p$ and $q$ are relatively prime positive integers. What is $p+q$?

Choices

  1. A109
  2. B201
  3. C301
  4. D3049
  5. E33,601

Answer

A. 109

Solution

Step 1: Find what the operation must be

The condition $a\diamond a=1$ suggests division. We can prove it from the given identity instead of guessing.

Step 2: Use b diamond b

Put $c=b$ in the identity: \[a\diamond(b\diamond b)=(a\diamond b)\cdot b.\] Since $b\diamond b=1$, this becomes \[a\diamond1=(a\diamond b)b.\]

Step 3: Determine a diamond 1

Now set $b=a$ in the last equation. Since $a\diamond a=1$, we get \[a\diamond1=a.\] Therefore $a=(a\diamond b)b$, so \[a\diamond b=\frac ab.\]

Step 4: Solve the equation

Then $6\diamond x=\frac6x$, and \[2016\diamond(6\diamond x)=2016\div\frac6x=336x.\] The equation becomes $336x=100$.

Step 5: Finish

Thus \[x=\frac{100}{336}=\frac{25}{84}.\] Hence $p+q=25+84=109$.

Step 6: Conclude

The answer is $\boxed{109}$.

Key Idea

Derive the operation from its identities before solving the equation.
