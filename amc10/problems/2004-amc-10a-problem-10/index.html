2004 AMC 10A Problem 10

2004AMC 10AProblem 10概率与统计组合概率概率计数

Problem Statement

Coin A is flipped three times and coin B is flipped four times. What is the probability that the number of heads obtained from flipping the two fair coins is the same?

Choices

  1. A$\frac{19}{128}$
  2. B$\frac{23}{128}$
  3. C$\frac14$
  4. D$\frac{35}{128}$
  5. E$\frac12$

Answer

D. \frac{35}{128}

Solution

Step 1: Organize by the number of heads

Coin A is flipped $3$ times, so it can have $0,1,2,$ or $3$ heads. Coin B is flipped $4$ times, and we need the same number of heads.

Step 2: Count favorable outcomes

For each possible $k$, the number of ways is $\binom{3}{k}\binom{4}{k}$. Therefore the favorable count is \[\binom30\binom40+\binom31\binom41+\binom32\binom42+\binom33\binom43.\]

Step 3: Compute the sum

This equals $1\cdot1+3\cdot4+3\cdot6+1\cdot4=1+12+18+4=35$.

Step 4: Count all outcomes

There are $2^3$ outcomes for coin A and $2^4$ outcomes for coin B, for a total of $2^7=128$ equally likely outcomes.

Step 5: Answer

The probability is $\boxed{\frac{35}{128}}$.

Key Idea

Sum the probabilities that both coins produce the same number of heads.
