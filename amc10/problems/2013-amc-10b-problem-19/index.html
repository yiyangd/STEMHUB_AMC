2013 AMC 10B Problem 19

2013AMC 10BProblem 19代数数列与递推数列递推

Problem Statement

The real numbers $c,b,a$ form an arithmetic sequence with $a\ge b\ge c\ge0$. The quadratic $ax^2+bx+c$ has exactly one root. What is this root?

Choices

  1. A-7-4\sqrt3
  2. B-2-\sqrt3
  3. C-1
  4. D-2+\sqrt3
  5. E-7+4\sqrt3

Answer

D. -2+\sqrt3

Solution

Step 1: Use the arithmetic sequence

Since $c,b,a$ form an arithmetic sequence, write $a=b+d$ and $c=b-d$, where $d\ge0$.

Step 2: Use the one-root condition

A quadratic has exactly one real root when its discriminant is zero, so $b^2-4ac=0$.

Step 3: Substitute

This gives $b^2=4(b+d)(b-d)=4(b^2-d^2)$, so $3b^2=4d^2$. Hence $\frac db=\frac{\sqrt3}{2}$.

Step 4: Find the root

The repeated root is $x=-\frac{b}{2a}=-\frac{b}{2(b+d)}=-\frac{1}{2(1+d/b)}=-\frac{1}{2+\sqrt3}$.

Step 5: Simplify

Rationalizing gives $x=\sqrt3-2=-2+\sqrt3$. The answer is $\boxed{-2+\sqrt3}$.

Key Idea

Use the arithmetic-sequence condition and discriminant zero.
