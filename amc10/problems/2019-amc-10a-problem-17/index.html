2019 AMC 10A Problem 17

2019AMC 10AProblem 17组合数学染色与构造染色构造

Problem Statement

A child builds towers using identically shaped cubes of different colors. How many different towers with a height of $8$ cubes can the child build with $2$ red cubes, $3$ blue cubes, and $4$ green cubes? One cube will be left out.

Choices

  1. A24
  2. B288
  3. C312
  4. D1260
  5. E40320

Answer

D. 1260

Solution

Step 1: Use cases based on the omitted cube

There are $2+3+4=9$ cubes available, but a tower uses $8$, so exactly one cube is left out. The count depends on which color is omitted.

Step 2: Leave out a red cube

Then the tower uses $1$ red, $3$ blue, and $4$ green cubes. The number of arrangements is \[\frac{8!}{1!3!4!}=280.\]

Step 3: Leave out a blue cube

Then the tower uses $2$ red, $2$ blue, and $4$ green cubes, giving \[\frac{8!}{2!2!4!}=420.\]

Step 4: Leave out a green cube

Then the tower uses $2$ red, $3$ blue, and $3$ green cubes, giving \[\frac{8!}{2!3!3!}=560.\]

Step 5: Add cases

The total number of towers is \[280+420+560=1260.\]

Step 6: Conclude

The answer is $\boxed{1260}$.

Key Idea

Split into cases according to which cube color is left out.
