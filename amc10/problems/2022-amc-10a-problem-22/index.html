2022AMC 10AProblem 22概率与统计平均数与数据集平均数数据

Problem Statement

Suppose that $13$ cards numbered $1,2,3,\ldots,13$ are arranged in a row. The task is to pick them up in numerically increasing order, working repeatedly from left to right. For how many of the $13!$ possible orderings of the cards will the $13$ cards be picked up in exactly two passes?

Choices

  1. A4082
  2. B4095
  3. C4096
  4. D8178
  5. E8191

Answer

D. 8178

Solution

Step 1: Translate passes into positions

For each card number $i$, let $p_i$ be its position in the row. While moving left to right, card $i+1$ can be picked up in the same pass as card $i$ exactly when $p_{i+1}>p_i$.

Step 2: Identify what starts a new pass

A new pass is needed exactly when the position sequence goes down: \[p_{i+1}<p_i.\] Therefore the number of extra passes equals the number of descents in \[p_1,p_2,\ldots,p_{13}.\]

Step 3: Restate the target

Exactly two passes means the position sequence has exactly one descent. So we must count permutations of $1,2,\ldots,13$ with exactly one descent.

Step 4: Use a clean counting fact

The number of permutations of $n$ objects with exactly one descent is the Eulerian number \[A(n,1)=2^n-n-1.\] One way to see this is to split the numbers into two increasing blocks; there are $2^n$ choices of the first block, but the empty block, full block, and the $n-1$ splits with no descent must be removed, leaving $2^n-n-1$.

Step 5: Apply n equals 13

Thus the count is \[2^{13}-13-1=8192-14=8178.\]

Step 6: Conclude

The answer is $\boxed{8178}$.

Key Idea

Count permutations by descents in the position sequence.
