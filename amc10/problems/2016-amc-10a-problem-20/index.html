2016 AMC 10A Problem 20

2016AMC 10AProblem 20组合数学排列组合排列组合计数

Problem Statement

For some particular value of $N$, when $(a+b+c+d+1)^N$ is expanded and like terms are combined, the resulting expression contains exactly $1001$ terms that include all four variables $a$, $b$, $c$, and $d$, each to some positive power. What is $N$?

Choices

  1. A9
  2. B14
  3. C16
  4. D17
  5. E19

Answer

B. 14

Solution

Step 1: Interpret a term in the expansion

A term from $(a+b+c+d+1)^N$ is determined by the exponents of $a,b,c,d$, and the remaining exponent of $1$. The term includes all four variables when the exponents of $a,b,c,d$ are all positive.

Step 2: Convert to a counting problem

Let those positive exponents be $x_1,x_2,x_3,x_4$. Since some factors may contribute the $1$, we need \[x_1+x_2+x_3+x_4\le N,\quad x_i\ge1.\]

Step 3: Remove the positivity condition

Set $y_i=x_i-1$. Then $y_i\ge0$ and \[y_1+y_2+y_3+y_4\le N-4.\]

Step 4: Use stars and bars

The number of nonnegative quadruples with sum at most $N-4$ is \[\binom{N}{4}.\] This is a standard stars-and-bars result: add a slack variable for the unused degree.

Step 5: Find N

We need \[\binom{N}{4}=1001.\] Since \[\binom{14}{4}=\frac{14\cdot13\cdot12\cdot11}{24}=1001,\] we get $N=14$.

Step 6: Conclude

The answer is $\boxed{14}$.

Key Idea

Count exponent quadruples with positive powers using stars and bars.
