2022 AMC 10A Problem 24

2022AMC 10AProblem 24组合数学递推与序列计数递推序列

Problem Statement

How many strings of length $5$ formed from the digits $0,1,2,3,4$ are there such that for each $j\in\{1,2,3,4\}$, at least $j$ of the digits are less than $j$?

Choices

  1. A500
  2. B625
  3. C1089
  4. D1199
  5. E1296

Answer

E. 1296

Solution

Step 1: Sort the digits to see the condition

After sorting the five digits as \[d_1\le d_2\le d_3\le d_4\le d_5,\] the conditions say \[d_1<1,\quad d_2<2,\quad d_3<3,\quad d_4<4.\] This is the standard parking-function condition for length $5$.

Step 2: Connect to parking functions

Think of the digits as parking preferences $0,1,2,3,4$ for $5$ cars. A string satisfies the condition exactly when the usual parking process succeeds.

Step 3: Use Pollak's circular argument

Place $6$ parking spaces in a circle. For any of the $6^5$ preference strings using spaces $0$ through $5$, all $5$ cars can park and exactly one space remains empty.

Step 4: Use rotational symmetry

Rotating every preference by the same amount modulo $6$ gives a group of $6$ strings. In each group, exactly one string has the empty space equal to the extra space, which corresponds to a valid string using digits $0$ through $4$.

Step 5: Count

Therefore the number of valid strings is \[\frac{6^5}{6}=6^4=1296.\]

Step 6: Conclude

The answer is $\boxed{1296}$.

Key Idea

Recognize the strings as parking functions and use Pollak's counting argument.
