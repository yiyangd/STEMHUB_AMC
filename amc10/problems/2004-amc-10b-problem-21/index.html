2004 AMC 10B Problem 21

2004AMC 10BProblem 21代数数列与递推数列递推

Problem Statement

Let $1,4,\ldots$ and $9,16,\ldots$ be two arithmetic progressions. The set $S$ is the union of the first $2004$ terms of each sequence. How many distinct numbers are in $S$?

Choices

  1. A$3722$
  2. B$3732$
  3. C$3914$
  4. D$3924$
  5. E$4007$

Answer

A. 3722

Solution

Step 1: Describe the two progressions

The first progression is $1,4,7,\ldots$, so its terms are $1+3k$ for $0\le k\le2003$. The second is $9,16,23,\ldots$, so its terms are $9+7j$ for $0\le j\le2003$.

Step 2: Use inclusion-exclusion

If there were no overlap, the union would have $2004+2004=4008$ numbers. We need to subtract the common terms.

Step 3: Solve for overlaps

A common term satisfies $1+3k=9+7j$, so $3k-7j=8$. Modulo $7$, this gives $3k\equiv1\pmod7$, so $k\equiv5\pmod7$.

Step 4: Count valid k values

Thus $k=5+7t$. The condition $k\le2003$ gives $5+7t\le2003$, so $t=0,1,\ldots,285$. That gives $286$ overlaps; the corresponding $j=1+3t$ values are also within range.

Step 5: Compute the union size

Therefore $|S|=4008-286=\boxed{3722}$.

Key Idea

Use inclusion-exclusion on two finite arithmetic progressions.
