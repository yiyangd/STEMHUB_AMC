Problem Statement

For a set of four distinct lines in a plane, there are exactly $N$ distinct points that lie on two or more of the lines. What is the sum of all possible values of $N$?

Choices

  1. A14
  2. B16
  3. C18
  4. D19
  5. E21

Answer

D. 19

Solution

Step 1: Start with the maximum

With four lines and no parallel lines or three-line concurrency, every pair intersects in a different point. This gives \[\binom42=6\] points.

Step 2: List ways to reduce intersections

Parallel lines remove intersection points, while three or four concurrent lines merge several pairwise intersections into one point.

Step 3: Find possible values

The possible values are: $0$ if all four lines are parallel; $1$ if all four are concurrent; $3$ if three are parallel and the fourth crosses them; $4$ if three are concurrent and the fourth crosses them, or if there are two pairs of parallel lines; $5$ if exactly one pair is parallel; and $6$ in general position.

Step 4: Notice what is missing

There is no way to get exactly $2$ distinct intersection points from four distinct lines. The intersection pattern always creates one of the listed values.

Step 5: Add

The sum is \[0+1+3+4+5+6=19.\]

Step 6: Conclude

The answer is $\boxed{19}$.

Key Idea

List possible intersection patterns of four lines.
