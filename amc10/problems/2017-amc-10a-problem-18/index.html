2017 AMC 10A Problem 18

2017AMC 10AProblem 18概率与统计独立性独立事件概率

Problem Statement

Amelia has a coin that lands heads with probability $\frac13$, and Blaine has a coin that lands heads with probability $\frac25$. Amelia and Blaine alternately toss their coins until someone gets a head; the first one to get a head wins. All coin tosses are independent. Amelia goes first. The probability that Amelia wins is $\frac pq$, where $p$ and $q$ are relatively prime positive integers. What is $q-p$?

Choices

  1. A1
  2. B2
  3. C3
  4. D4
  5. E5

Answer

D. 4

Solution

Step 1: Let P be Amelia's win probability

Amelia can win immediately by tossing heads, which has probability $\frac13$.

Step 2: Handle the reset case

If Amelia tosses tails and then Blaine tosses tails, the game returns to the same situation. That probability is \[\frac23\cdot\frac35=\frac25.\]

Step 3: Set up the equation

Therefore \[P=\frac13+\frac25P.\]

Step 4: Solve

\[\frac35P=\frac13,\quad P=\frac59.\] Thus $p=5$ and $q=9$.

Step 5: Compute the requested value

$q-p=9-5=4$.

Step 6: Conclude

The answer is $\boxed{4}$.

Key Idea

Use a recursive probability equation after both players miss.
