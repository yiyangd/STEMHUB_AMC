2005 AMC 10B Problem 20

2005AMC 10BProblem 20概率与统计平均数与数据集平均数数据

Problem Statement

What is the average (mean) of all 5-digit numbers that can be formed by using each of the digits 1, 3, 5, 7, and 8 exactly once?

Choices

  1. A48000
  2. B49999.5
  3. C53332.8
  4. D55555
  5. E56432.8

Answer

C. 53332.8

Solution

Step 1: Use symmetry of permutations

All permutations of the digits $1,3,5,7,8$ are used. In each place value, every digit appears equally often.

Step 2: Find the average digit in each place

The average of the five digits is \[\frac{1+3+5+7+8}{5}=\frac{24}{5}=4.8.\]

Step 3: Build the average number

Since each place has average digit $4.8$, the average number is \[4.8(10000+1000+100+10+1).\]

Step 4: Compute

This is $4.8\cdot11111=53332.8$.

Step 5: Answer

The average is $\boxed{53332.8}$.

Key Idea

Use symmetry: each digit appears equally often in each place value.
