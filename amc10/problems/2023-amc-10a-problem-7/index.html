2023 AMC 10A Problem 7

2023AMC 10AProblem 7概率与统计组合概率概率计数

Problem Statement

Janet rolls a standard $6$-sided die $4$ times and keeps a running total of the numbers she rolls. What is the probability that at some point, her running total will equal $3$?

Choices

  1. A$\frac29$
  2. B$\frac{49}{216}$
  3. C$\frac{25}{108}$
  4. D$\frac{17}{72}$
  5. E$\frac{13}{54}$

Answer

B. \frac{49}{216}

Solution

Step 1: Notice totals only increase

Because every die roll is positive, once the running total passes $3$, it can never return to $3$. So we only count sequences that hit $3$ exactly.

Step 2: Hit 3 on the first roll

If the first roll is $3$, the last three rolls can be anything. This gives \[6^3=216\] sequences.

Step 3: Hit 3 on the second roll

The first two rolls must be $(1,2)$ or $(2,1)$, and the last two rolls can be anything. This gives \[2\cdot6^2=72\] sequences.

Step 4: Hit 3 on the third roll

The only way to first reach $3$ on the third roll is $(1,1,1)$, and the last roll can be anything. This gives $6$ sequences.

Step 5: Divide by all outcomes

The favorable count is $216+72+6=294$, and the total number of roll sequences is $6^4=1296$. Thus \[\frac{294}{1296}=\frac{49}{216}.\]

Step 6: Conclude

The answer is $\boxed{\frac{49}{216}}$.

Key Idea

Count roll sequences that first reach total 3.
