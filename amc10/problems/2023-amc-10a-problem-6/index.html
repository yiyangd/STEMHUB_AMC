2023 AMC 10A Problem 6

2023AMC 10AProblem 6几何空间几何空间几何体积

Problem Statement

An integer is assigned to each vertex of a cube. The value of an edge is the sum of the values of the two vertices it touches, and the value of a face is the sum of the values of the four edges surrounding it. The value of the cube is the sum of the values of its six faces. Suppose the sum of the integers assigned to the vertices is $21$. What is the value of the cube?

Choices

  1. A42
  2. B63
  3. C84
  4. D126
  5. E252

Answer

D. 126

Solution

Step 1: Track how often each vertex is counted

Each vertex of a cube touches $3$ edges. Therefore, when all edge values are added, each vertex value is counted $3$ times.

Step 2: Relate edge sums to face sums

Each edge belongs to exactly $2$ faces. So when the six face values are added, each edge value is counted twice.

Step 3: Combine the two counts

The cube value is therefore \[2\cdot3\cdot(\text{sum of vertex values}).\]

Step 4: Use the given vertex sum

The sum of the vertex values is $21$, so the cube value is \[6\cdot21=126.\]

Step 5: Conclude

The answer is $\boxed{126}$.

Key Idea

Count how many times each vertex contributes to the face sum.
