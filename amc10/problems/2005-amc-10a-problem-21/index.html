2005 AMC 10A Problem 21

2005AMC 10AProblem 21数论整数构造整数构造

Problem Statement

For how many positive integers $n$ does $1+2+\cdots+n$ evenly divide $6n$?

Choices

  1. A$3$
  2. B$5$
  3. C$7$
  4. D$9$
  5. E$11$

Answer

B. 5

Solution

Step 1: Rewrite the divisor

The sum $1+2+\cdots+n$ is the triangular number $\frac{n(n+1)}{2}$. The condition is \[\frac{n(n+1)}2 \mid 6n.\]

Step 2: Cancel the common factor carefully

Since $n$ is positive, compare $6n$ with $\frac{n(n+1)}2$: \[\frac{6n}{n(n+1)/2}=\frac{12}{n+1}.\] The divisibility holds exactly when $\frac{12}{n+1}$ is an integer.

Step 3: Count possible n

Thus $n+1$ must be a positive divisor of $12$. The divisors are $1,2,3,4,6,12$.

Step 4: Remove the impossible divisor

Because $n$ is positive, $n+1>1$, so we use $2,3,4,6,12$. These give $n=1,2,3,5,11$.

Step 5: Answer

There are $\boxed{5}$ possible values of $n$.

Key Idea

Convert the triangular-number divisibility condition into a divisor condition on n+1.
