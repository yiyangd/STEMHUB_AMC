2005 AMC 10B Problem 22

2005AMC 10BProblem 22数论质因数与整除质因数整除

Problem Statement

For how many positive integers $n\le24$ is $n!$ evenly divisible by $1+2+\cdots+n$?

Choices

  1. A$8$
  2. B$12$
  3. C$16$
  4. D$17$
  5. E$21$

Answer

C. 16

Solution

Step 1: Rewrite the divisor

The sum $1+2+\cdots+n$ is $\frac{n(n+1)}2$. We need \[\frac{n(n+1)}2\mid n!.\]

Step 2: Cancel the common factor n

For $n\ge1$, this is equivalent to asking whether $n+1$ divides $2(n-1)!$.

Step 3: Identify failures

If $n+1$ is an odd prime greater than $2$, then none of the factors $1,2,\ldots,n-1$ is divisible by $n+1$, and the extra factor $2$ does not help. So those cases fail.

Step 4: Count the failed values

For $n\le24$, we have $n+1\le25$. The odd primes from $3$ to $25$ are $3,5,7,11,13,17,19,23$, giving $8$ failures.

Step 5: Conclude

All other values work, because composite $n+1$ has enough factors inside $2(n-1)!$. There are $24-8=16$ working values. The answer is $\boxed{16}$.

Key Idea

Reduce the triangular-number divisibility condition to whether n+1 divides 2(n-1)!.
