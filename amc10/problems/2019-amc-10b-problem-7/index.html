2019 AMC 10B Problem 7

2019AMC 10BProblem 7代数三角恒等式三角函数恒等式

Problem Statement

Each piece of candy in a store costs a whole number of cents. Casper has exactly enough money to buy either $12$ red candies, $14$ green candies, $15$ blue candies, or $n$ purple candies. A purple candy costs $20$ cents. What is the smallest possible value of $n$?

Choices

  1. A18
  2. B21
  3. C24
  4. D25
  5. E28

Answer

B. 21

Solution

Step 1: Translate the money condition

Let Casper's amount of money be $M$ cents. Because candy prices are whole numbers of cents, $M$ must be divisible by $12$, $14$, and $15$.

Step 2: Find the smallest possible money amount

The least common multiple is \[\operatorname{lcm}(12,14,15)=420.\]

Step 3: Use purple candy

Purple candy costs $20$ cents, so if $M=420$, then \[n=\frac{420}{20}=21.\]

Step 4: Check minimality

Any smaller amount that works for the first three colors would have to be a smaller positive multiple of $420$, which is impossible.

Step 5: Conclude

The smallest possible value of $n$ is $\boxed{21}$.

Key Idea

Use least common multiples.
