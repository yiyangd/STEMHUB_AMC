2021 Spring AMC 10A Problem 11

2021 SpringAMC 10AProblem 11数论进制与数字数字进制

Problem Statement

For which of the following integers $b$ is the base-$b$ number $2021_b-221_b$ not divisible by $3$?

Choices

  1. A3
  2. B4
  3. C6
  4. D7
  5. E8

Answer

E. 8

Solution

Step 1: Convert the base-b numbers

In base $b$, \[2021_b=2b^3+2b+1\] and \[221_b=2b^2+2b+1.\]

Step 2: Subtract

The difference is \[(2b^3+2b+1)-(2b^2+2b+1)=2b^3-2b^2=2b^2(b-1).\]

Step 3: Test divisibility by 3

The factor $2$ is not divisible by $3$, so divisibility depends on $b^2(b-1)$. This is divisible by $3$ if $b\equiv0$ or $1\pmod3$.

Step 4: Check the answer choices

Among $3,4,6,7,8$, only $8\equiv2\pmod3$. Therefore the expression is not divisible by $3$ only for $b=8$.

Step 5: Conclude

The answer is $\boxed{8}$.

Key Idea

Convert the base-b expression to a polynomial in b.
