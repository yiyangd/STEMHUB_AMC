2018 AMC 10B Problem 25

2018AMC 10BProblem 25数论整数构造整数构造

Problem Statement

Let $\lfloor x\rfloor$ denote the greatest integer less than or equal to $x$. How many real numbers $x$ satisfy the equation \[x^2+10000\lfloor x\rfloor=10000x?\]

Choices

  1. A197
  2. B198
  3. C199
  4. D200
  5. E201

Answer

C. 199

Solution

Step 1: Fix the floor value

Let \[m=\lfloor x\rfloor.\] Then $x$ lies in the interval $[m,m+1)$, and the equation becomes \[x^2+10000m=10000x.\]

Step 2: Use the fractional part

Write $x=m+y$, where $0\le y<1$. Then $x-m=y$, so the equation is equivalent to \[x^2=10000y.\]

Step 3: Turn existence into an interval test

For a fixed integer $m$, define \[H(y)=10000y-(m+y)^2.\] We need a zero of $H(y)$ for some $0\le y<1$.

Step 4: Check the endpoints

At $y=0$, \[H(0)=-m^2\le0.\] For all relevant $m$, the function is increasing on $0\le y\le1$, so a solution exists exactly when \[H(1)=10000-(m+1)^2>0,\] with the special endpoint $m=0,y=0$ included.

Step 5: Count the integers m

The inequality \[10000-(m+1)^2>0\] means \[|m+1|<100.\] Thus \[m=-100,-99,\ldots,98,\] which gives $199$ integer values of $m$.

Step 6: Conclude

Each such interval gives one solution, so there are $\boxed{199}$ real numbers $x$.

Key Idea

Fix $\lfloor x floor$ and count intervals that contain a solution.
