2023 AMC 10B Problem 23

2023AMC 10BProblem 23代数数列与递推数列递推

Problem Statement

An arithmetic sequence has $n\ge3$ terms, initial term $a$, and common difference $d>1$. Carl wrote down all the terms in this sequence correctly except for one term, which was off by $1$. The sum of the terms Carl wrote was $222$. What is $a+d+n$?

Choices

  1. A24
  2. B20
  3. C22
  4. D28
  5. E26

Answer

B. 20

Solution

Step 1: Undo Carl's one-unit error

Carl's written sum is $222$, but exactly one term was off by $1$. Therefore the true sum of the arithmetic sequence must be either \[221\quad\text{or}\quad223.\]

Step 2: Rule out the prime-looking option

The number $223$ is prime. Since the sequence has $n\ge3$ positive integer terms, the arithmetic-series sum structure would force a nontrivial factorization pattern; $223$ gives no workable case here.

Step 3: Use the factorization of 221

We have \[221=13\cdot17.\] For an arithmetic sequence with an odd number of terms, the sum is the number of terms times the middle term.

Step 4: Test possible odd lengths

If $n=17$, the middle term would be $13$, so \[a+8d=13.\] Since $d>1$, this would make $a$ nonpositive. If $n=13$, the middle term is $17$, so \[a+6d=17.\]

Step 5: Find a and d

With $d>1$ and $a>0$, the equation $a+6d=17$ gives $d=2$ and $a=5$.

Step 6: Compute the requested sum

Thus \[a+d+n=5+2+13=20.\] The answer is $\boxed{20}$.

Key Idea

Use the arithmetic-series sum and the fact that the recorded sum is off by 1.
