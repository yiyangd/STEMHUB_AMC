2003 AMC 10B Problem 7

2003AMC 10BProblem 7数论整数构造整数构造

Problem Statement

The symbolism ⌊x⌋ denotes the largest integer not exceeding x. For example. ⌊3⌋ = 3, and ⌊9/2⌋ = 4. Compute √ √ √ √ ⌊ 1⌋ + ⌊ 2⌋ + ⌊ 3⌋ + · · · + ⌊ 16⌋.

Choices

  1. A35
  2. B38
  3. C40
  4. D42
  5. E136

Answer

B. 38

Solution

Step 1: Group by square roots

$\lfloor\sqrt n\rfloor=1$ for $n=1,2,3$; $2$ for $n=4,5,6,7,8$; $3$ for $n=9$ through $15$; and $4$ for $n=16$.

Step 2: Add contributions

The sum is $3\cdot1+5\cdot2+7\cdot3+1\cdot4$.

Step 3: Compute

This equals $3+10+21+4=38$.

Step 4: Answer

The answer is $\\boxed{38}$.

Key Idea

用整数范围、构造和极值条件筛选可能值。
