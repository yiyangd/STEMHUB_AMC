2023 AMC 10B Problem 21

2023AMC 10BProblem 21概率与统计组合概率概率计数

Problem Statement

Each of $2023$ balls is placed independently into one of $3$ bins. Which of the following is closest to the probability that each of the bins contains an odd number of balls?

Choices

  1. A$\frac23$
  2. B$\frac3{10}$
  3. C$\frac12$
  4. D$\frac13$
  5. E$\frac14$

Answer

E. \frac14

Solution

Step 1: Focus on parity, not exact bin sizes

The question only asks whether each bin has an odd number of balls. So the important information is the parity pattern of the three bin counts, such as odd-even-even or odd-odd-odd.

Step 2: Use the fact that 2023 is odd

Since the total number of balls is odd, the number of bins with odd counts must also be odd. Therefore the possible parity patterns are either exactly one odd bin or all three bins odd.

Step 3: Count the favorable parity pattern

For $n$ balls distributed among $3$ bins, a standard parity count gives the number of assignments with all three bin counts odd as \[\frac{3^n-3}{4}.\] Here $n=2023$, so the probability is \[\frac{3^{2023}-3}{4\cdot3^{2023}}=\frac14-\frac{3}{4\cdot3^{2023}}.\]

Step 4: Compare with the choices

The correction term \[\frac{3}{4\cdot3^{2023}}\] is extraordinarily small. Thus the probability is just slightly less than $\frac14$.

Step 5: Choose the closest value

Among the choices, $\frac14$ is overwhelmingly the closest. The answer is $\boxed{\frac14}$.

Key Idea

Use parity-state counting for balls in bins.
