Problem Statement

Amy, Beth, and Jo listen to four different songs and discuss which ones they like. No song is liked by all three. Furthermore, for each of the three pairs of girls, there is at least one song liked by those two girls but disliked by the third. In how many different ways is this possible?

Choices

  1. A108
  2. B132
  3. C671
  4. D846
  5. E1105

Answer

B. 132

Solution

Step 1: Classify one song

For each song, the set of girls who like it can be any subset except the set of all three girls. So each song has $7$ possible like-patterns.

Step 2: Identify required patterns

The condition requires at least one song of each pair-only type: Amy-Beth only, Amy-Jo only, and Beth-Jo only.

Step 3: Use inclusion-exclusion

For four labeled songs, start with $7^4$ assignments. Subtract those missing at least one required pair type: $3\cdot6^4$. Add back assignments missing two required pair types: $3\cdot5^4$. Subtract assignments missing all three required pair types: $4^4$.

Step 4: Calculate

The count is $7^4-3\cdot6^4+3\cdot5^4-4^4=2401-3888+1875-256=132$. The answer is $\boxed{132}$.

Key Idea

Use inclusion-exclusion on the three required pair-only song types.
