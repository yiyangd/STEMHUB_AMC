2002 AMC 10A Problem 24

2002AMC 10AProblem 24概率与统计组合概率概率计数

Problem Statement

Tina randomly selects two distinct numbers from the set {1, 2, 3, 4, 5} and Sergio randomly se- lects a number from the set {1, 2, ..., 10}. The probability that Sergio’s number is larger than the sum of the two numbers chosen by Tina is

Choices

  1. A2/5
  2. B9/20
  3. C1/2
  4. D11/20
  5. E24/25

Answer

A. \frac{2}{5}

Solution

Step 1: Count outcomes

Tina has $\binom52=10$ possible pairs and Sergio has $10$ choices, so there are $100$ equally likely outcomes.

Step 2: List Tina's sums

The pair sums are $3,4,5,5,6,6,7,7,8,9$.

Step 3: Count Sergio wins

For a sum $s$, Sergio has $10-s$ choices larger than $s$. The favorable count is $7+6+5+5+4+4+3+3+2+1=40$.

Step 4: Probability

The probability is $40/100=2/5$, so the answer is $\boxed{\frac25}$.

Key Idea

分别计数有利情况与总情况，再化为概率。
