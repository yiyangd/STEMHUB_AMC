2005 AMC 10A Problem 16

2005AMC 10AProblem 16数论进制与数字数字进制

Problem Statement

The sum of the digits of a two-digit number is subtracted from the number. The units digit of the result is 6. How many two-digit numbers have this property?

Choices

  1. A5
  2. B7
  3. C9
  4. D10
  5. E19

Answer

D. 10

Solution

Step 1: Write the number by digits

Let the two-digit number be $10a+b$, where $a$ is from $1$ to $9$ and $b$ is from $0$ to $9$.

Step 2: Subtract the digit sum

Subtracting the sum of the digits gives $(10a+b)-(a+b)=9a$. Notice that the units digit depends only on the tens digit $a$.

Step 3: Find the needed tens digit

We need the units digit of $9a$ to be $6$. Testing $a=1,2,\ldots,9$, this happens only when $a=4$, since $9\cdot4=36$.

Step 4: Count possible units digits

Once $a=4$, the original units digit $b$ can be any of $0,1,\ldots,9$. That gives $10$ numbers.

Step 5: Answer

The answer is $\boxed{10}$.

Key Idea

Use digit algebra to simplify the subtraction of digit sum from a two-digit number.
