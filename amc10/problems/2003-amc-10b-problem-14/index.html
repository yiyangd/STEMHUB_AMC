2003 AMC 10B Problem 14

2003AMC 10BProblem 14数论整数构造整数构造

Problem Statement

Given that $3^8\cdot 5^2=a^b$, where both $a$ and $b$ are positive integers, find the smallest possible value for $a+b$.

Choices

  1. A$25$
  2. B$34$
  3. C$351$
  4. D$407$
  5. E$900$

Answer

D. 407

Solution

Step 1: Interpret the expression as a perfect power

The right side is $a^b$, so the left side must be written as a power with integer exponent $b$. Prime exponents tell us which exponents are possible.

Step 2: Look at the prime factorization

The expression is already factored: $3^8\cdot 5^2$. If it equals $a^b$, then $b$ must divide both exponents $8$ and $2$.

Step 3: Choose the exponent that can make a small base

The common divisors of $8$ and $2$ are $1$ and $2$. Using $b=2$ makes the base much smaller than using $b=1$, so it is the only serious candidate for minimizing $a+b$.

Step 4: Compute the base

With $b=2$, we have \[a=3^{8/2}\cdot 5^{2/2}=3^4\cdot 5=81\cdot 5=405.\] Thus $a+b=405+2=407$.

Step 5: Check the other exponent

If $b=1$, then $a=3^8\cdot 5^2$, which is far larger. Therefore the smallest possible value is $\boxed{407}$.

Key Idea

Use prime exponents to decide the largest possible exponent b, which minimizes a+b.
