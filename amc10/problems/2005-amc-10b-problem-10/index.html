Problem Statement

In $\triangle ABC$, we have $AC=BC=7$ and $AB=2$. Suppose that $D$ is a point on line $AB$ such that $B$ lies between $A$ and $D$ and $CD=8$. What is $BD$?

Choices

  1. A$3$
  2. B$2\sqrt3$
  3. C$4$
  4. D$5$
  5. E$4\sqrt2$

Answer

A. 3

Solution

Step 1: Use symmetry

Since $AC=BC=7$ and $AB=2$, point $C$ lies above the midpoint of $AB$. Put $A=(-1,0)$ and $B=(1,0)$.

Step 2: Find the height of C

The distance from the midpoint to either endpoint is $1$, so the height $h$ satisfies $h^2+1^2=7^2$. Thus $h^2=48$.

Step 3: Place point D

Point $D$ is on line $AB$ beyond $B$, so write $D=(1+x,0)$ where $x=BD$.

Step 4: Use CD=8

The distance from $C=(0,\sqrt{48})$ to $D=(1+x,0)$ is $8$, so \[(1+x)^2+48=64.\] Therefore $(1+x)^2=16$.

Step 5: Solve

Since $x>0$, $1+x=4$, so $x=3$. Thus $BD=\boxed{3}$.

Key Idea

Use symmetry and the Pythagorean theorem in an isosceles triangle.
