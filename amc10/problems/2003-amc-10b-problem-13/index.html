2003 AMC 10B Problem 13

2003AMC 10BProblem 13数论进制与数字数字进制

Problem Statement

Let ♣(x) denote the sum of the digits of the positive integer x. For example, ♣(8) = 8 and ♣(123) = 1 + 2 + 3 = 6. For how many two-digit values of x is ♣(♣(x)) = 3?

Choices

  1. A3
  2. B4
  3. C6
  4. D9
  5. E10

Answer

E. 10

Solution

Step 1: Name the digit sum

For a two-digit number $x$, the value $\clubsuit(x)$ is the sum of its digits. This sum can range from $1$ to $18$.

Step 2: Find which digit sums work

We need $\clubsuit(\clubsuit(x))=3$. Between $1$ and $18$, the numbers whose digit sum is $3$ are $3$ and $12$. So $\clubsuit(x)$ must be either $3$ or $12$.

Step 3: Count two-digit numbers with digit sum 3

The tens digit cannot be $0$. The pairs are $(1,2),(2,1),(3,0)$, giving $3$ numbers.

Step 4: Count two-digit numbers with digit sum 12

The possible tens digits are $3,4,5,6,7,8,9$, with the ones digit determined each time. That gives $7$ numbers.

Step 5: Combine the cases

The total is $3+7=10$, so the answer is $\boxed{10}$.

Key Idea

Reduce the condition to possible digit sums, then count two-digit numbers with those sums.
