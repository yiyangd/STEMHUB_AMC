2018 AMC 10B Problem 5

2018AMC 10BProblem 5组合数学排列组合排列组合计数

Problem Statement

How many subsets of $\{2,3,4,5,6,7,8,9\}$ contain at least one prime number?

Choices

  1. A128
  2. B192
  3. C224
  4. D240
  5. E256

Answer

D. 240

Solution

Step 1: Count all subsets

The set has $8$ elements, so it has $2^8=256$ subsets total.

Step 2: Count subsets with no primes

The primes in the set are $2,3,5,7$. The nonprimes are $4,6,8,9$. A subset with no primes can use only these $4$ nonprimes, giving $2^4=16$ subsets.

Step 3: Subtract

Subsets with at least one prime: \[256-16=240.\]

Step 4: Conclude

The answer is $\boxed{240}$.

Key Idea

Count all subsets minus subsets with no primes.
