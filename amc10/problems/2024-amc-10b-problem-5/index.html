2024 AMC 10B Problem 5 代数 运算与化简 代数化简

Problem Statement

In the expression $1+3+5+\cdots+97+99$, Melanie changes some plus signs to minus signs. The new expression is negative. What is the least number of plus signs she could have changed?

Choices

  1. A14
  2. B15
  3. C16
  4. D17
  5. E18

Answer

B. 15

Solution

Step 1: Start with the original sum

The expression adds all positive odd numbers from $1$ to $99$. There are $50$ such numbers, and the sum of the first $50$ positive odd numbers is \[ 1+3+5+\cdots+99=50^2=2500. \] So before any signs are changed, the expression is quite positive.

Step 2: Understand what changing one sign does

If a term $k$ changes from $+k$ to $-k$, the value of the expression decreases by $2k$, not just by $k$. For example, changing $+99$ to $-99$ changes the total by $198$. To make the total negative using as few sign changes as possible, we should change the largest odd numbers first.

Step 3: Set up the target decrease

To make the new expression negative, the total decrease must be more than $2500$. If the changed odd numbers have sum $S$, then the decrease is $2S$. Therefore we need \[ 2S>2500, \qquad \text{so} \qquad S>1250. \] Now the problem becomes: how few of the largest odd numbers can have sum greater than $1250$?

Step 4: Test the largest possible groups

The largest $14$ odd numbers are $73,75,\ldots,99$. Their average is $\frac{73+99}{2}=86$, so their sum is $14\cdot86=1204$. This is not enough, because $1204<1250$.

Step 5: Add one more term and finish

If we also include the next largest odd number, $71$, the sum becomes \[ 1204+71=1275>1250. \] So $15$ sign changes are enough, while $14$ are not enough even in the best possible case. Therefore the least number of plus signs changed is $\boxed{15}$.

Key Idea

Use the sum of odd numbers and choose the largest terms greedily to minimize the number of sign changes.
