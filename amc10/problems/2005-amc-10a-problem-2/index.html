2005 AMC 10A Problem 2

2005AMC 10AProblem 2代数运算与化简代数化简

Problem Statement

For each pair of real numbers $a\ne b$, define the operation $\star$ by $a\star b=\frac{a+b}{a-b}$. What is the value of $((1\star2)\star3)$?

Choices

  1. A$-\frac23$
  2. B$-\frac15$
  3. C$0$
  4. D$\frac12$
  5. EThis value is not defined.

Answer

C. 0

Solution

Step 1: Start with the inner operation

The expression is nested, so first compute $1\star2$. By the definition, \[1\star2=\frac{1+2}{1-2}=\frac3{-1}=-3.\]

Step 2: Substitute into the outer operation

Now the original expression becomes $(-3)\star3$.

Step 3: Apply the definition again

We get \[(-3)\star3=\frac{-3+3}{-3-3}=\frac0{-6}=0.\]

Step 4: Check that it is defined

The denominator in the last step is not zero, so the value is defined.

Step 5: Answer

The answer is $\boxed{0}$.

Key Idea

Evaluate the custom operation from the inside out.
