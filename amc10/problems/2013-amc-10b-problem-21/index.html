2013 AMC 10B Problem 21

2013AMC 10BProblem 21组合数学递推与序列计数递推序列

Problem Statement

Two non-decreasing sequences of nonnegative integers have different first terms. Each sequence has the property that each term beginning with the third is the sum of the previous two terms, and the seventh term of each sequence is $N$. What is the smallest possible value of $N$?

Choices

  1. A55
  2. B89
  3. C104
  4. D144
  5. E273

Answer

C. 104

Solution

Step 1: Describe a sequence by its first two terms

Let the first two terms be $a$ and $b$. Because the sequence is non-decreasing and uses nonnegative integers, we need $0\le a\le b$.

Step 2: Write the seventh term

The recurrence gives $a,b,a+b,a+2b,2a+3b,3a+5b,5a+8b$. Therefore the seventh term is $N=5a+8b$.

Step 3: Ask when two different first terms are possible

For a fixed $N$, the value of $a$ must satisfy $5a\equiv N\pmod 8$, so possible values of $a$ differ by $8$. To have two sequences with different first terms, we need at least two allowed values of $a$.

Step 4: Use the non-decreasing condition

The condition $a\le b$ means $a\le\frac{N-5a}{8}$, so $13a\le N$. If two possible $a$ values differ by $8$, the smallest pair is $a=0$ and $a=8$, which requires $N\ge13\cdot8=104$.

Step 5: Check that the lower bound works

When $N=104$, the pairs $(a,b)=(0,13)$ and $(8,8)$ both work. They give non-decreasing sequences and have different first terms.

Step 6: Conclude

The smallest possible value is $\boxed{104}$.

Key Idea

Represent the seventh term as a linear expression in the first two terms.
