2010 AMC 10B Problem 18

2010AMC 10BProblem 18概率与统计独立性独立事件概率

Problem Statement

Positive integers $a,b,c$ are randomly and independently selected with replacement from the set $\{1,2,3,\ldots,2010\}$. What is the probability that $abc+ab+a$ is divisible by $3$?

Choices

    Answer

    E. \frac{13}{27}

    Solution

    Step 1: Reduce the expression modulo 3

    We only care whether $abc+ab+a$ is divisible by $3$. Factor the expression as \[abc+ab+a=a(bc+b+1)=a\bigl(b(c+1)+1\bigr).\] A product is $0$ modulo $3$ if at least one factor is $0$ modulo $3$.

    Step 2: Use uniform residues

    The set $\{1,2,\ldots,2010\}$ has the same number of integers in each residue class modulo $3$, because $2010$ is divisible by $3$. So $a,b,c$ are each equally likely to be $0,1,$ or $2$ modulo $3$.

    Step 3: Count when the first factor works

    If $a\equiv0\pmod3$, the expression is automatically divisible by $3$. This happens with probability $\frac13$.

    Step 4: Count when the second factor works

    If $a\not\equiv0\pmod3$, we need $b(c+1)+1\equiv0\pmod3$. Among the $9$ possible residue pairs $(b,c)$, this happens for $(b,c)=(1,1)$ and $(2,0)$, so the probability is $\frac29$.

    Step 5: Combine the cases

    The cases are disjoint by whether $a$ is $0$ modulo $3$. Thus the probability is \[\frac13+\frac23\cdot\frac29=\frac13+\frac4{27}=\frac{13}{27}.\] The answer is $\boxed{\frac{13}{27}}$.

    Key Idea

    Work modulo $3$ and count residue classes instead of individual integers.
