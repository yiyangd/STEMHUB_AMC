2023 AMC 10B Problem 22

2023AMC 10BProblem 22数论整数构造整数构造

Problem Statement

How many distinct values of $x$ satisfy \[\lfloor x\rfloor^2-3x+2=0,\] where $\lfloor x\rfloor$ denotes the greatest integer less than or equal to $x$?

Choices

  1. Aan infinite number
  2. B4
  3. C2
  4. D3
  5. E0

Answer

B. 4

Solution

Step 1: Name the floor value

Let \[k=\lfloor x\rfloor.\] Then $k$ is an integer and $x$ must lie in the interval \[k\le x<k+1.\]

Step 2: Solve the equation in terms of k

The equation becomes \[k^2-3x+2=0,\] so \[x=\frac{k^2+2}{3}.\] Now each integer $k$ gives at most one possible value of $x$.

Step 3: Force x into the correct interval

We need \[k\le\frac{k^2+2}{3}<k+1.\] The left inequality gives \[k^2-3k+2\ge0,\] or \[(k-1)(k-2)\ge0.\]

Step 4: Use the right inequality

The right inequality gives \[k^2+2<3k+3,\] so \[k^2-3k-1<0.\] This holds for integer values $k=0,1,2,3$.

Step 5: Combine the two conditions

The first condition allows $k\le1$ or $k\ge2$, so it does not remove any of $0,1,2,3$. Therefore there are $4$ possible values of $k$, and each gives one value of $x$.

Step 6: Conclude

There are $\boxed{4}$ distinct values of $x$.

Key Idea

Set k equal to the floor of x and solve interval inequalities.
