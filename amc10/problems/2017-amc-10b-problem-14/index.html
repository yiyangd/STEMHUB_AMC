2017 AMC 10B Problem 14

2017AMC 10BProblem 14概率与统计平均数与数据集平均数数据

Problem Statement

An integer $N$ is selected at random in the range $1\le N\le2020$. What is the probability that the remainder when $N^{16}$ is divided by $5$ is $1$?

Choices

  1. A$\frac15$
  2. B$\frac25$
  3. C$\frac35$
  4. D$\frac45$
  5. E1

Answer

D. \frac45

Solution

Step 1: Work modulo 5

We only care about $N^{16}$ modulo $5$. If $N$ is divisible by $5$, then $N^{16}\equiv0\pmod5$.

Step 2: Use nonzero residues

If $N$ is not divisible by $5$, then by Fermat's little theorem, $N^4\equiv1\pmod5$. Therefore \[N^{16}=(N^4)^4\equiv1\pmod5.\]

Step 3: Count the integers

Among any $5$ consecutive integers, $4$ are not divisible by $5$. The range $1$ to $2020$ contains complete groups of $5$.

Step 4: Find the probability

Thus the probability is \[\frac45.\]

Step 5: Conclude

The answer is $\boxed{\frac45}$.

Key Idea

Use residues modulo 5 and Fermat's little theorem.
