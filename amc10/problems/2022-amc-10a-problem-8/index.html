2022 AMC 10A Problem 8

2022AMC 10AProblem 8概率与统计平均数与数据集平均数数据

Problem Statement

A data set consists of $6$ not necessarily distinct positive integers: $1,7,5,2,5,$ and $X$. The average of the $6$ numbers equals a value in the data set. What is the sum of all positive values of $X$?

Choices

  1. A10
  2. B26
  3. C32
  4. D36
  5. E40

Answer

D. 36

Solution

Step 1: Write the average

The known five numbers sum to \[1+7+5+2+5=20.\] Thus the average is \[\frac{20+X}{6}.\]

Step 2: Test possible data values

The average must equal one of the data values: $1,2,5,7,$ or $X$.

Step 3: Find possible X values

If the average is $5$, then $20+X=30$, so $X=10$. If the average is $7$, then $20+X=42$, so $X=22$. If the average is $X$, then $20+X=6X$, so $X=4$.

Step 4: Reject impossible cases

An average of $1$ or $2$ is impossible because the known sum is already $20$.

Step 5: Add

The positive possible values are $10,22,4$, and their sum is \[10+22+4=36.\]

Step 6: Conclude

The answer is $\boxed{36}$.

Key Idea

Test which data-set value can equal the mean.
