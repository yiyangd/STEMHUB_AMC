2008 AMC 10A Problem 23

2008AMC 10AProblem 23组合数学排列组合排列组合计数

Problem Statement

Two subsets of the set $S=\{a,b,c,d,e\}$ are to be chosen so that their union is $S$ and their intersection contains exactly two elements. In how many ways can this be done, assuming that the order in which the subsets are chosen does not matter?

Choices

  1. A$20$
  2. B$40$
  3. C$60$
  4. D$160$
  5. E$320$

Answer

B. 40

Solution

Step 1: Translate the set conditions into roles

For each element of $S$, there are three possible roles: it can be in both subsets, only in the first subset, or only in the second subset. The union being $S$ means no element is allowed to be in neither subset.

Step 2: Choose the intersection first

The intersection must contain exactly two elements. We choose those two shared elements in $\binom{5}{2}=10$ ways.

Step 3: Place the remaining elements

The other $3$ elements must be in exactly one of the two subsets. If the two subsets were ordered, each of these $3$ elements would have $2$ choices, so there would be $2^3=8$ ordered assignments.

Step 4: Remove the ordering

The problem says the order of the two subsets does not matter. Since the remaining $3$ elements cannot all switch to the same assignment under a swap, every unordered pair is counted exactly twice in the ordered count.

Step 5: Compute the final count

Thus the number of unordered choices is $10\cdot \frac{8}{2}=40$.

Step 6: Answer

The answer is $\boxed{40}$.

Key Idea

Classify each element by whether it belongs to both subsets or to exactly one subset, then account for unordered pairs.
