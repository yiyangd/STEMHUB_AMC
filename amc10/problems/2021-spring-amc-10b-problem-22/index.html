2021 Spring AMC 10B Problem 22

2021 SpringAMC 10BProblem 22概率与统计独立性独立事件概率

Problem Statement

Ang, Ben, and Jasmin each have $5$ blocks, colored red, blue, yellow, white, and green, and there are $5$ empty boxes. Each person randomly and independently places one block into each box. The probability that at least one box receives $3$ blocks all of the same color is $\frac mn$, where $m$ and $n$ are relatively prime. What is $m+n$?

Choices

  1. A47
  2. B94
  3. C227
  4. D471
  5. E542

Answer

D. 471

Solution

Step 1: Fix one person's placement

Because the colors are symmetric, fix Ang's placement of the five colors in the five boxes. Ben and Jasmin each independently choose a random permutation of the five colors.

Step 2: Define the matching event

A box receives three blocks of the same color exactly when both Ben and Jasmin put the box's Ang-color into that same box. So we need at least one common fixed box for Ben's and Jasmin's permutations relative to Ang.

Step 3: Use inclusion-exclusion

There are $(5!)^2$ total pairs of permutations. If a chosen set of $k$ boxes is forced to match for both Ben and Jasmin, then the remaining choices can be made in \[((5-k)!)^2\] ways.

Step 4: Count favorable pairs

By inclusion-exclusion, the number with at least one matching box is \[\binom51(4!)^2-\binom52(3!)^2+\binom53(2!)^2-\binom54(1!)^2+\binom55(0!)^2=2556.\]

Step 5: Compute the probability

The probability is \[\frac{2556}{(5!)^2}=\frac{2556}{14400}=\frac{71}{400}.\]

Step 6: Conclude

Thus $m+n=71+400=\boxed{471}$.

Key Idea

Use inclusion-exclusion on boxes where all three colors match.
