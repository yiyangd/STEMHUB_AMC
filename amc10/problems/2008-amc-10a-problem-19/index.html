2008 AMC 10A Problem 19

2008AMC 10AProblem 19几何几何变换变换对称

Problem Statement

Rectangle $PQRS$ lies in a plane with $PQ=RS=2$ and $QR=SP=6$. The rectangle is rotated $90^\circ$ clockwise about $R$, then rotated $90^\circ$ clockwise about the point that $S$ moved to after the first rotation. What is the length of the path traveled by point $P$?

Choices

  1. A$(2\sqrt3+5)\pi$
  2. B$6\pi$
  3. C$(3+\sqrt{10})\pi$
  4. D$(\sqrt3+2\sqrt5)\pi$
  5. E$2\sqrt{10}\pi$

Answer

C. (3+\sqrt{10})\pi

Solution

Step 1: Break the path into two arcs

Point $P$ moves along a quarter-circle during each $90^\circ$ rotation. We need the radius of each arc.

Step 2: First rotation

In the original rectangle, $PR=\sqrt{2^2+6^2}=2\sqrt{10}$. A quarter-circle with this radius has length $\frac{\pi}{2}\cdot2\sqrt{10}=\pi\sqrt{10}$.

Step 3: Second rotation

After the first rotation, the new center is where $S$ moved. The distance from that point to the moved point $P$ is $6$, so the second quarter-circle has length $\frac{\pi}{2}\cdot6=3\pi$.

Step 4: Add arcs

The total path length is $\pi\sqrt{10}+3\pi=(3+\sqrt{10})\pi$.

Step 5: Answer

The answer is $\boxed{(3+\sqrt{10})\pi}$.

Key Idea

Add two quarter-circle arc lengths with different rotation centers.
