2019 AMC 10A Problem 22

2019AMC 10AProblem 22概率与统计独立性独立事件概率

Problem Statement

Real numbers between $0$ and $1$, inclusive, are chosen in the following manner. A fair coin is flipped. If it lands heads, then it is flipped again and the chosen number is $0$ if the second flip is heads and $1$ if the second flip is tails. If the first coin flip is tails, then the number is chosen uniformly at random from $[0,1]$. Two random numbers $x$ and $y$ are chosen independently in this manner. What is the probability that $|x-y|>\frac12$?

Choices

  1. A$\frac13$
  2. B$\frac7{16}$
  3. C$\frac12$
  4. D$\frac9{16}$
  5. E$\frac23$

Answer

B. \frac7{16}

Solution

Step 1: Understand the distribution

One chosen number is $0$ with probability $\frac14$, is $1$ with probability $\frac14$, and is uniformly distributed on $[0,1]$ with probability $\frac12$.

Step 2: Both numbers are endpoint values

If both numbers come from the endpoint process, then $|x-y|>\frac12$ exactly when the pair is $(0,1)$ or $(1,0)$. This contributes \[2\cdot\frac14\cdot\frac14=\frac18.\]

Step 3: One endpoint and one uniform

If one number is an endpoint and the other is uniform, the uniform number must lie in the opposite half of the interval. For each order, the probability is \[\frac12\cdot\frac12\cdot\frac12=\frac18,\] so the two orders contribute $\frac14$ total.

Step 4: Both uniform

If both are uniform, the region $|x-y|>\frac12$ consists of two right triangles in the unit square with total area $\frac14$. Since both numbers are uniform with probability $\frac12\cdot\frac12=\frac14$, this contributes \[\frac14\cdot\frac14=\frac1{16}.\]

Step 5: Add the cases

The total probability is \[\frac18+\frac14+\frac1{16}=\frac7{16}.\]

Step 6: Conclude

The answer is $\boxed{\frac7{16}}$.

Key Idea

Split the mixed distribution into discrete and continuous cases.
