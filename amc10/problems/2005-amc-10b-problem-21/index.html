2005 AMC 10B Problem 21

2005AMC 10BProblem 21概率与统计组合概率概率计数

Problem Statement

Forty slips are placed into a hat, each bearing a number $1,2,3,4,5,6,7,8,9,$ or $10$, with each number entered on four slips. Four slips are drawn from the hat at random and without replacement. Let $p$ be the probability that all four slips bear the same number. Let $q$ be the probability that two of the slips bear a number $a$ and the other two bear a number $b\ne a$. What is the value of $q/p$?

Choices

  1. A$162$
  2. B$180$
  3. C$324$
  4. D$360$
  5. E$720$

Answer

A. 162

Solution

Step 1: Use counts instead of probabilities

Both $p$ and $q$ have the same denominator, namely the number of ways to draw $4$ slips from $40$. So $q/p$ can be found by dividing favorable counts.

Step 2: Count all four the same

For event $p$, choose which number appears on all four slips. There are $10$ choices, and once the number is chosen, all four slips of that number must be drawn. So the favorable count for $p$ is $10$.

Step 3: Count two and two

For event $q$, choose the two numbers that appear: $\binom{10}{2}=45$ choices.

Step 4: Choose the slips

For each chosen number, choose $2$ of its $4$ slips. That gives $\binom42^2=6^2=36$ choices.

Step 5: Divide

Thus $q/p=\frac{45\cdot36}{10}=162$. The answer is $\boxed{162}$.

Key Idea

Count favorable four-slip selections for each event, then divide to cancel the common denominator.
