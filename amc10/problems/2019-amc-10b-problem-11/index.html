2019 AMC 10B Problem 11

2019AMC 10BProblem 11概率与统计组合概率概率计数

Problem Statement

Two jars each contain the same number of marbles, and every marble is either blue or green. In Jar 1 the ratio of blue to green marbles is $9:1$, and in Jar 2 the ratio is $8:1$. There are $95$ green marbles in all. How many more blue marbles are in Jar 1 than in Jar 2?

Choices

  1. A5
  2. B10
  3. C25
  4. D45
  5. E50

Answer

A. 5

Solution

Step 1: Use a common jar size

Let each jar contain $N$ marbles. Jar 1 has blue:green ratio $9:1$, so its green count is $\frac{N}{10}$. Jar 2 has ratio $8:1$, so its green count is $\frac{N}{9}$.

Step 2: Use the total green count

The total number of green marbles is $95$, so \[\frac{N}{10}+\frac{N}{9}=95.\]

Step 3: Solve for N

\[\frac{19N}{90}=95,\] so \[N=450.\]

Step 4: Find blue counts

Jar 1 has \[\frac9{10}\cdot450=405\] blue marbles. Jar 2 has \[\frac89\cdot450=400\] blue marbles.

Step 5: Compare

The difference is \[405-400=5.\]

Step 6: Conclude

The answer is $\boxed{5}$.

Key Idea

Use equal jar totals to write green counts in terms of one variable.
