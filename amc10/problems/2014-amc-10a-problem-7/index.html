2014 AMC 10A Problem 7

2014AMC 10AProblem 7代数方程与不等式方程不等式

Problem Statement

Nonzero real numbers $x$, $y$, $a$, and $b$ satisfy $x<a$ and $y<b$. How many of the following inequalities must be true? $\text{(I) }x+y<a+b$, $\text{(II) }x-y<a-b$, $\text{(III) }xy<ab$, $\text{(IV) }\frac{x}{y}<\frac{a}{b}$.

Choices

  1. A0
  2. B1
  3. C2
  4. D3
  5. E4

Answer

B. 1

Solution

Step 1: Prove the easy one

Since $x<a$ and $y<b$, adding the two inequalities gives $x+y<a+b$. So statement I must be true.

Step 2: Remember what 'must be true' means

To disprove a statement, one counterexample is enough. We need examples that still satisfy $x<a$ and $y<b$.

Step 3: Use one counterexample for II, III, and IV

Take $x=-3$, $y=-4$, $a=1$, and $b=4$. Then $x<a$ and $y<b$ are both true.

Step 4: Test the remaining statements

For II, $x-y=1$ but $a-b=-3$, so $1<-3$ is false. For III, $xy=12$ but $ab=4$, so $12<4$ is false. For IV, $\frac{x}{y}=\frac34$ but $\frac{a}{b}=\frac14$, so $\frac34<\frac14$ is false.

Step 5: Conclude

Only statement I must be true, so the answer is $\boxed{1}$.

Key Idea

Prove the one always-true inequality and disprove the others with counterexamples.
