2022 AMC 10A Problem 18

2022AMC 10AProblem 18几何坐标几何坐标几何

Problem Statement

Let $T_k$ be the transformation of the coordinate plane that first rotates the plane $k$ degrees counterclockwise around the origin and then reflects the plane across the $y$-axis. What is the least positive integer $n$ such that performing the sequence of transformations $T_1,T_2,T_3,\ldots,T_n$ returns the point $(1,0)$ back to itself?

Choices

  1. A359
  2. B360
  3. C719
  4. D720
  5. E721

Answer

A. 359

Solution

Step 1: Track only the angle

Rotations and reflections keep the point on the unit circle, so we only need to track its angle. Start with $(1,0)$, which has angle $0^\circ$.

Step 2: Describe one transformation

After rotating by $k^\circ$, an angle $\theta$ becomes $\theta+k$. Reflecting across the $y$-axis sends an angle $\alpha$ to $180^\circ-\alpha$.

Step 3: Pair consecutive transformations

Applying $T_k$ and then $T_{k+1}$ sends an angle $\theta$ back to \[\theta-1^\circ.\] This is the key simplification: every two transformations rotate the point $1^\circ$ clockwise.

Step 4: Check the odd first step

After $T_1$, the point is at angle $179^\circ$. Then every two more transformations decrease this angle by $1^\circ$.

Step 5: Return to the starting point

We need to go from $179^\circ$ down to $0^\circ$, which takes $179$ two-step decreases after the first step. Therefore \[n=1+2\cdot179=359.\]

Step 6: Conclude

The least positive value is $\boxed{359}$.

Key Idea

Track the angle after pairs of transformations.
