2018 AMC 10B Problem 16

2018AMC 10BProblem 16数论整除与同余同余余数

Problem Statement

Let $a_1,a_2,\ldots,a_{2018}$ be a strictly increasing sequence of positive integers such that $a_1+a_2+\cdots+a_{2018}=2018^{2018}$. What is the remainder when $a_1^3+a_2^3+\cdots+a_{2018}^3$ is divided by $6$?

Choices

  1. A0
  2. B1
  3. C2
  4. D3
  5. E4

Answer

E. 4

Solution

Step 1: Look for a congruence that connects cubes to numbers

The sequence itself is not specified, so we should look for a fact that works for every integer. Modulo $6$, every integer has the same remainder as its cube.

Step 2: State the useful fact

For any integer $n$, \[n^3\equiv n\pmod6.\] This can be checked from residues $0,1,2,3,4,5$ modulo $6$.

Step 3: Apply it to the whole sum

Therefore \[a_1^3+a_2^3+\cdots+a_{2018}^3\equiv a_1+a_2+\cdots+a_{2018}\pmod6.\]

Step 4: Use the given sum

The given sum is $2018^{2018}$. Since $2018\equiv2\pmod6$, we need $2^{2018}\pmod6$. Powers of $2$ modulo $6$ alternate $2,4,2,4,\ldots$, so an even exponent gives $4$.

Step 5: Conclude

The remainder is $\boxed{4}$.

Key Idea

Use the congruence $n^3\equiv n\pmod 6$.
