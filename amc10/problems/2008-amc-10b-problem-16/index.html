2008 AMC 10B Problem 16

2008AMC 10BProblem 16概率与统计组合概率概率计数

Problem Statement

Two fair coins are to be tossed once. For each head that results, one fair die is to be rolled. What is the probability that the sum of the die rolls is odd? Note that if no die is rolled, their sum is $0$.

Choices

  1. A$\frac{3}{8}$
  2. B$\frac{1}{2}$
  3. C$\frac{43}{72}$
  4. D$\frac{5}{8}$
  5. E$\frac{2}{3}$

Answer

A. \frac{3}{8}

Solution

Step 1: Condition on the number of heads

The number of dice rolled equals the number of heads among two coins. We consider $0$, $1$, or $2$ heads.

Step 2: Handle zero heads

If there are no heads, no die is rolled and the sum is $0$, which is even. This case contributes no success.

Step 3: Handle one head

Exactly one head occurs with probability $\frac12$. Then one die is rolled, and it is odd with probability $\frac12$, contributing $\frac12\cdot\frac12=\frac14$.

Step 4: Handle two heads

Two heads occur with probability $\frac14$. Two dice have an odd sum when one die is odd and the other is even, which has probability $\frac12$. This contributes $\frac14\cdot\frac12=\frac18$.

Step 5: Add the successful cases

The total probability is $\frac14+\frac18=\frac38$.

Step 6: Answer

The probability is $\boxed{\frac38}$.

Key Idea

Condition on how many heads occur, then compute when the die-roll sum is odd.
