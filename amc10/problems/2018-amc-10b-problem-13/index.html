2018 AMC 10B Problem 13

2018AMC 10BProblem 13数论质因数与整除质因数整除

Problem Statement

How many of the first $2018$ numbers in the sequence $101,1001,10001,100001,\ldots$ are divisible by $101$?

Choices

  1. A253
  2. B504
  3. C505
  4. D506
  5. E1009

Answer

C. 505

Solution

Step 1: Rewrite the sequence

The terms are $10^2+1,10^3+1,10^4+1,\ldots$. The first $2018$ terms correspond to exponents $2$ through $2019$.

Step 2: Use the key modular fact

Since \[10^2=100\equiv-1\pmod{101},\] powers of $10$ repeat every $4$ exponents modulo $101$.

Step 3: Find the exponents that work

We need $10^k+1\equiv0\pmod{101}$, which means $10^k\equiv-1\pmod{101}$. This happens when \[k\equiv2\pmod4.\]

Step 4: Count the exponents

From $2$ through $2019$, the working exponents are \[2,6,10,\ldots,2018.\] This arithmetic sequence has \[\frac{2018-2}{4}+1=505\] terms.

Step 5: Conclude

There are $\boxed{505}$ divisible terms.

Key Idea

Use the repeating powers of 10 modulo 101.
