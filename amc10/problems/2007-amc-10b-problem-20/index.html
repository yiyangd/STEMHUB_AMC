2007 AMC 10B Problem 20

2007AMC 10BProblem 20组合数学排列组合排列组合计数

Problem Statement

A set of $25$ square blocks is arranged into a $5\times5$ square. How many different combinations of $3$ blocks can be selected from that set so that no two are in the same row or column?

Choices

  1. A$100$
  2. B$125$
  3. C$600$
  4. D$2300$
  5. E$3600$

Answer

C. 600

Solution

Step 1: Choose the rows

No two selected blocks can be in the same row, so first choose which $3$ of the $5$ rows will contain selected blocks. This can be done in $\binom53$ ways.

Step 2: Choose the columns

Similarly, choose which $3$ of the $5$ columns will contain selected blocks. This can also be done in $\binom53$ ways.

Step 3: Match rows to columns

Once the rows and columns are chosen, each selected row must be paired with a different selected column. There are $3!$ such matchings.

Step 4: Compute

The number of combinations is $\binom53\binom53\cdot3!=10\cdot10\cdot6=600$.

Step 5: Answer

The answer is $\boxed{600}$.

Key Idea

Choose rows, choose columns, then match them with a permutation.
