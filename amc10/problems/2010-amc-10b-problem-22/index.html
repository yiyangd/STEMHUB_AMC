2010 AMC 10B Problem 22

2010AMC 10BProblem 22组合数学排列组合排列组合计数

Problem Statement

Seven distinct pieces of candy are to be distributed among three bags. The red bag and the blue bag must each receive at least one piece of candy; the white bag may remain empty. How many arrangements are possible?

Choices

    Answer

    C. 1932

    Solution

    Step 1: Start with all distributions

    Each of the $7$ distinct candies can independently go into the red, blue, or white bag. Without restrictions, that gives $3^7$ possible distributions.

    Step 2: Subtract distributions with an empty required bag

    The red bag is not allowed to be empty. If it is empty, each candy has only two choices, blue or white, giving $2^7$ bad distributions. Similarly, there are $2^7$ distributions where the blue bag is empty.

    Step 3: Correct for double subtraction

    If both the red and blue bags are empty, then all candies are in the white bag. That one distribution was subtracted twice, so we add it back once.

    Step 4: Calculate

    The number of valid distributions is \[3^7-2^7-2^7+1=2187-128-128+1=1932.\]

    Step 5: Conclude

    Therefore there are $\boxed{1932}$ arrangements.

    Key Idea

    Use complementary counting to enforce nonempty red and blue bags.
