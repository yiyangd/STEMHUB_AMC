2018 AMC 10A Problem 18

2018AMC 10AProblem 18数论整数构造整数构造

Problem Statement

How many nonnegative integers can be written in the form $a_7\cdot3^7+a_6\cdot3^6+\cdots+a_1\cdot3+a_0$, where $a_i\in\{-1,0,1\}$ for $0\le i\le7$?

Choices

  1. A512
  2. B729
  3. C1094
  4. D3281
  5. E59048

Answer

D. 3281

Solution

Step 1: Recognize balanced ternary

The expression uses powers of $3$ with coefficients $-1$, $0$, and $1$. Such a representation is unique: if two different coefficient choices gave the same number, their difference would give a nontrivial base-$3$ representation with coefficients too small to cancel the highest nonzero term.

Step 2: Count all represented integers

There are $3^8$ choices for the coefficients $a_0,\ldots,a_7$, so there are $3^8=6561$ represented integers.

Step 3: Use symmetry

For every positive represented integer, changing every coefficient sign gives the corresponding negative integer. The value $0$ is represented once.

Step 4: Count nonnegative values

Therefore the number of nonnegative represented integers is \[\frac{6561+1}{2}=3281.\]

Step 5: Conclude

The answer is $\boxed{3281}$.

Key Idea

Use uniqueness and symmetry of balanced ternary representations.
