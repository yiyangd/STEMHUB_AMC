2020 AMC 10B Problem 19

2020AMC 10BProblem 19概率与统计组合概率概率计数

Problem Statement

How many $10$-element subsets are there of a $52$-element set? The number is written in the form $158A00A4AA0$, where $A$ represents a digit. What is $A$?

Choices

  1. A2
  2. B3
  3. C4
  4. D5
  5. E6

Answer

A. 2

Solution

Step 1: Recognize the counting expression

The number of $10$-element subsets of a $52$-element set is the binomial coefficient \[\binom{52}{10}.\]

Step 2: Compute in a controlled way

Using \[\binom{52}{10}=\frac{52\cdot51\cdot50\cdots43}{10!},\] careful arithmetic gives \[\binom{52}{10}=15,820,024,220.\]

Step 3: Match the given digit pattern

The problem writes the number as $158A00A4AA0$. Comparing with \[15820024220,\] every $A$ must be the digit $2$.

Step 4: Check consistency

The positions of $A$ all agree with the same digit, so there is no contradiction in the pattern.

Step 5: Conclude

The answer is $\boxed{2}$.

Key Idea

Compute the binomial coefficient and match the digit pattern.
