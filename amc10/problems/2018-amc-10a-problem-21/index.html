Problem Statement

Which of the following describes the set of values of $a$ for which the curves $x^2+y^2=a^2$ and $y=x^2-a$ in the real $xy$-plane intersect at exactly $3$ points?

Choices

  1. A$a=\frac14$
  2. B$\frac14<a<\frac12$
  3. C$a>\frac14$
  4. D$a=\frac12$
  5. E$a>\frac12$

Answer

E. a>\frac12

Solution

Step 1: Substitute the parabola into the circle

Using $y=x^2-a$ in $x^2+y^2=a^2$ gives \[x^2+(x^2-a)^2=a^2.\]

Step 2: Simplify

Expanding and canceling $a^2$ gives \[x^2+x^4-2ax^2=0,\] or \[x^2(x^2+1-2a)=0.\]

Step 3: Count solutions for x

The factor $x^2=0$ always gives $x=0$, which gives one intersection point. The other factor gives \[x^2=2a-1.\]

Step 4: Require two more points

To have exactly three intersection points, we need two additional real nonzero $x$-values, so $2a-1>0$.

Step 5: Conclude

Thus $a>\frac12$, so the answer is $\boxed{a>\frac12}$.

Key Idea

Substitute the parabola into the circle and count real x-values.
