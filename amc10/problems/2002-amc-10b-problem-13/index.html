2002AMC 10BProblem 13代数运算与化简代数化简

Problem Statement

Find the value of $x$ such that $8xy-12y+2x-3=0$ is true for all values of $y$.

Choices

  1. A$\frac32$
  2. B$\frac32$ or $-\frac14$
  3. C$-\frac23$ or $-\frac14$
  4. D$3$
  5. E$-\frac34$ or $-\frac12$

Answer

A. \frac{3}{2}

Solution

Step 1: Group by $y$

Rewrite the expression as $(8x-12)y+(2x-3)=0$.

Step 2: Use 'all values of $y$'

For this to be true for every $y$, both the coefficient of $y$ and the constant term must be $0$.

Step 3: Solve both conditions

$8x-12=0$ gives $x=3/2$, and $2x-3=0$ also gives $x=3/2$.

Step 4: Answer

The value is $\\boxed{\\frac32}$.

Key Idea

通过代数化简、配对或基本运算降低计算量。
