2007 AMC 10A Problem 9

2007AMC 10AProblem 9代数方程与不等式方程不等式

Problem Statement

Real numbers $a$ and $b$ satisfy the equations $3^a=81^{b+2}$ and $125^b=5^{a-3}$. What is $ab$?

Choices

  1. A$-60$
  2. B$-17$
  3. C$9$
  4. D$12$
  5. E$60$

Answer

E. 60

Solution

Step 1: Rewrite using common bases

Since $81=3^4$, the first equation becomes $3^a=(3^4)^{b+2}=3^{4b+8}$, so $a=4b+8$.

Step 2: Rewrite the second equation

Since $125=5^3$, the second equation becomes $(5^3)^b=5^{a-3}$, so $3b=a-3$, or $a=3b+3$.

Step 3: Solve the linear system

Set the two expressions for $a$ equal: $4b+8=3b+3$. Hence $b=-5$. Then $a=3(-5)+3=-12$.

Step 4: Compute $ab$

Now $ab=(-12)(-5)=60$.

Step 5: Answer

The answer is $\boxed{60}$.

Key Idea

Rewrite powers using common bases and solve the resulting linear system.
