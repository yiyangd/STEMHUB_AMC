2016 AMC 10B Problem 25

2016AMC 10BProblem 25数论整数构造整数构造

Problem Statement

Let $f(x)=\sum_{k=2}^{10}(\lfloor kx\rfloor-k\lfloor x\rfloor)$, where $\lfloor r\rfloor$ denotes the greatest integer less than or equal to $r$. How many distinct values does $f(x)$ assume for $x\ge0$?

Choices

  1. A32
  2. B36
  3. C45
  4. D46
  5. Einfinitely many

Answer

A. 32

Solution

Step 1: Remove the integer part of x

Write $x=n+t$, where $n=\lfloor x\rfloor$ and $0\le t<1$. Then \[\lfloor kx\rfloor-k\lfloor x\rfloor=\lfloor k(n+t)\rfloor-kn=\lfloor kt\rfloor.\] So $f(x)$ depends only on the fractional part $t$.

Step 2: Find where f can change

The value of $\lfloor kt\rfloor$ changes only when $t$ reaches a fraction $\frac{m}{k}$ for $1\le m<k$ and $2\le k\le10$. Thus it is enough to evaluate $f$ at the distinct breakpoints in $[0,1)$.

Step 3: List the resulting values

Evaluating \[\sum_{k=2}^{10}\lfloor kt\rfloor\] at the breakpoints gives the distinct values \[0,1,2,3,4,5,7,8,10,11,12,15,16,18,19,20,25,26,27,29,30,33,34,35,37,38,40,41,42,43,44,45.\]

Step 4: Count them

There are $32$ values in this list. The gaps occur because at some breakpoints several floor functions jump at the same time.

Step 5: Conclude

The number of distinct values is $\boxed{32}$.

Key Idea

Reduce the floor function to the fractional part of x and count breakpoint values.
