2018 AMC 10A Problem 8

2018AMC 10AProblem 8概率与统计组合概率概率计数

Problem Statement

Joe has a collection of $23$ coins, consisting of $5$-cent coins, $10$-cent coins, and $25$-cent coins. He has $3$ more $10$-cent coins than $5$-cent coins, and the total value is $320$ cents. How many more $25$-cent coins does Joe have than $5$-cent coins?

Choices

  1. A0
  2. B1
  3. C2
  4. D3
  5. E4

Answer

C. 2

Solution

Step 1: Set variables

Let $x$ be the number of $5$-cent coins. Then the number of $10$-cent coins is $x+3$.

Step 2: Use the total number of coins

The number of $25$-cent coins is \[23-x-(x+3)=20-2x.\]

Step 3: Use the total value

The total value is \[5x+10(x+3)+25(20-2x)=320.\]

Step 4: Solve

Simplifying gives \[530-35x=320,\] so $x=6$.

Step 5: Answer the comparison

The number of $25$-cent coins is $20-2(6)=8$, which is $2$ more than the $6$ five-cent coins.

Step 6: Conclude

The answer is $\boxed{2}$.

Key Idea

Set variables for coin counts and use total number and value.
