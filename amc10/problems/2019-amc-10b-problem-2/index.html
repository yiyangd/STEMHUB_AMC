2019 AMC 10B Problem 2

2019AMC 10BProblem 2数论质因数与整除质因数整除

Problem Statement

Consider the statement, \"If $n$ is not prime, then $n-2$ is prime.\" Which of the following values of $n$ is a counterexample to this statement?

Choices

  1. A11
  2. B15
  3. C19
  4. D21
  5. E27

Answer

E. 27

Solution

Step 1: Recall what a counterexample must do

A counterexample to an if-then statement must make the hypothesis true and the conclusion false.

Step 2: Apply the hypothesis

The hypothesis says $n$ is not prime. So we only test answer choices that are not prime: $15,21,$ and $27$.

Step 3: Test the conclusion

For $n=15$, $n-2=13$ is prime. For $n=21$, $n-2=19$ is prime. For $n=27$, $n-2=25$ is not prime.

Step 4: Identify the counterexample

The value $27$ makes the hypothesis true but the conclusion false.

Step 5: Conclude

The answer is $\boxed{27}$.

Key Idea

A counterexample must make the hypothesis true and the conclusion false.
