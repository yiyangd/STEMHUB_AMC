2018 AMC 10A Problem 20

2018AMC 10AProblem 20组合数学图形计数网格计数

Problem Statement

A scanning code consists of a $7\times7$ grid of squares, with some squares colored black and the rest white. There must be at least one square of each color. A scanning code is called symmetric if it does not change under rotations by multiples of $90^\circ$ or reflections across diagonals or midlines of the square. What is the total number of possible symmetric scanning codes?

Choices

  1. A510
  2. B1022
  3. C8190
  4. D8192
  5. E65,534

Answer

B. 1022

Solution

Step 1: Find the independent cell groups

A fully symmetric $7\times7$ grid must be constant on each orbit of cells under the symmetries of the square.

Step 2: Count the orbits

For a $7\times7$ grid, these symmetries create $10$ cell orbits. One way to see this is to classify cells by their sorted distances from the center in horizontal and vertical directions.

Step 3: Choose colors by orbit

Each orbit can independently be colored black or white, so there are \[2^{10}=1024\] symmetric colorings before the color condition.

Step 4: Exclude one-color grids

The problem requires at least one square of each color, so exclude the all-black and all-white grids.

Step 5: Conclude

The total is \[1024-2=\boxed{1022}.\]

Key Idea

Count orbits of grid cells under the full square symmetry group.
