2013 AMC 10A Problem 11

2013AMC 10AProblem 11组合数学排列组合排列组合计数

Problem Statement

A student council must select a two-person welcoming committee and a three-person planning committee from among its members. There are exactly $10$ ways to select a two-person team for the welcoming committee. It is possible for students to serve on both committees. In how many different ways can a three-person planning committee be selected?

Choices

  1. A10
  2. B12
  3. C15
  4. D18
  5. E25

Answer

A. 10

Solution

Step 1: Find the number of council members

If there are $n$ members, the number of two-person welcoming committees is $\binom n2=10$.

Step 2: Solve for n

The equation $\frac{n(n-1)}2=10$ gives $n(n-1)=20$, so $n=5$.

Step 3: Choose the planning committee

Students may serve on both committees, so the planning committee is chosen independently from the same $5$ members.

Step 4: Compute

The number of three-person planning committees is $\binom53=10$. The answer is $\boxed{10}$.

Key Idea

Recover the number of students from the number of two-person committees, then choose three.
