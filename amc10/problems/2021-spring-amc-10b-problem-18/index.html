2021 Spring AMC 10B Problem 18

2021 SpringAMC 10BProblem 18概率与统计组合概率概率计数

Problem Statement

A fair $6$-sided die is repeatedly rolled until an odd number appears. What is the probability that every even number appears at least once before the first occurrence of an odd number?

Choices

  1. A$\frac1{120}$
  2. B$\frac1{32}$
  3. C$\frac1{20}$
  4. D$\frac3{20}$
  5. E$\frac16$

Answer

C. \frac1{20}

Solution

Step 1: Think about first appearances

The process stops at the first odd roll. We need the first appearances of all three even faces $2,4,6$ to occur before any odd face appears.

Step 2: Ignore repeated rolls

Repeated rolls of a face already seen do not change which new face appears next. So we can look at the order in which distinct die faces first appear.

Step 3: Count distinct-face orders

Among the six faces, every set of three faces is equally likely to be the first three distinct faces. We need those first three distinct faces to be exactly $\{2,4,6\}$.

Step 4: Compute the probability

There is only one favorable $3$-element set out of \[\binom63=20\] possible sets.

Step 5: Conclude

The probability is $\boxed{\frac1{20}}$.

Key Idea

Think of the first distinct die faces before the first odd.
