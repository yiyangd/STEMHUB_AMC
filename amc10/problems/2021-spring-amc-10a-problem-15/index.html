2021 Spring AMC 10A Problem 15

2021 SpringAMC 10AProblem 15组合数学递推与序列计数递推序列

Problem Statement

Values for $A,B,C,$ and $D$ are to be selected from $\{1,2,3,4,5,6\}$ without replacement. How many ways are there to make such choices so that the two curves $y=Ax^2+B$ and $y=Cx^2+D$ intersect? The order in which the curves are listed does not matter.

Choices

  1. A30
  2. B60
  3. C90
  4. D180
  5. E360

Answer

C. 90

Solution

Step 1: Write the intersection condition

The curves intersect when \[Ax^2+B=Cx^2+D.\] Rearranging gives \[(A-C)x^2=D-B.\]

Step 2: Use the fact that x squared is nonnegative

Because $A\ne C$, an intersection exists exactly when \[\frac{D-B}{A-C}\ge0.\] In other words, $D-B$ and $A-C$ must have the same sign.

Step 3: Count ordered assignments first

There are $6\cdot5\cdot4\cdot3=360$ ordered choices for $A,B,C,D$.

Step 4: Use symmetry for the sign condition

For any four distinct selected values, exactly half of the assignments have $A-C$ and $D-B$ with the same sign. So there are $180$ ordered assignments that work.

Step 5: Account for unordered curves

The order of the two parabolas does not matter, so each valid pair has been counted twice. Thus the number is \[\frac{180}{2}=90.\]

Step 6: Conclude

The answer is $\boxed{90}$.

Key Idea

Translate curve intersection into a sign condition.
