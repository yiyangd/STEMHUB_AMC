Problem Statement

A basketball player made $5$ baskets during a game. Each basket was worth either $2$ or $3$ points. How many different numbers could represent the total points scored by the player?

Choices

  1. A$2$
  2. B$3$
  3. C$4$
  4. D$5$
  5. E$6$

Answer

E. 6

Solution

Step 1: Identify the flexible choice

The player made exactly $5$ baskets. The only thing that can change is how many of those baskets were worth $3$ points instead of $2$ points.

Step 2: Start from the lowest possible total

If all $5$ baskets were worth $2$ points, the total would be $5\cdot2=10$ points.

Step 3: See how each 3-point basket changes the total

Changing one basket from $2$ points to $3$ points adds exactly $1$ point. If the player made $k$ three-point baskets, where $k=0,1,2,3,4,5$, the total is $10+k$.

Step 4: Count the possible values

The six possible totals are $10,11,12,13,14,15$.

Step 5: Answer

There are $\boxed{6}$ different possible totals.

Key Idea

Count possible totals by tracking how many 3-point baskets were made.
