2020 AMC 10A Problem 9

2020AMC 10AProblem 9数论整数构造整数构造

Problem Statement

A single bench section can hold either $7$ adults or $11$ children. When $N$ bench sections are connected end to end, an equal number of adults and children seated together will occupy all the bench space. What is the least possible positive integer value of $N$?

Choices

  1. A9
  2. B18
  3. C27
  4. D36
  5. E77

Answer

B. 18

Solution

Step 1: Convert seating to section fractions

One adult uses $\frac17$ of a bench section, and one child uses $\frac1{11}$ of a section.

Step 2: Use equal numbers

If there are $x$ adults and $x$ children, then the number of sections used is \[\frac{x}{7}+\frac{x}{11}=\frac{18x}{77}.\]

Step 3: Make N an integer

We need \[N=\frac{18x}{77}\] to be a positive integer. Since $\gcd(18,77)=1$, the smallest possible $x$ is $77$.

Step 4: Compute N

Then \[N=\frac{18\cdot77}{77}=18.\]

Step 5: Conclude

The least possible value is $\boxed{18}$.

Key Idea

Use a least common multiple condition for equal counts.
