2006 AMC 10A Problem 13

2006AMC 10AProblem 13概率与统计组合概率概率计数

Problem Statement

A player pays $5$ dollars to play a game. A die is rolled. If the number on the die is odd, the game is lost. If the number is even, the die is rolled again. In this case the player wins if the second number matches the first and loses otherwise. How much should the player win if the game is fair?

Choices

  1. A$12$
  2. B$30$
  3. C$50$
  4. D$60$
  5. E$100$

Answer

D. 60

Solution

Step 1: Find the probability of reaching the second roll

The first roll must be even. A fair die has $3$ even faces out of $6$, so this happens with probability $1/2$.

Step 2: Find the probability of matching

Once the first roll is fixed, the second roll must match that exact number. This has probability $1/6$.

Step 3: Find the win probability

Therefore the probability of winning is $\frac12\cdot\frac16=\frac1{12}$.

Step 4: Use fairness

For a fair game, expected winnings equal the $5$ dollar cost. If the prize is $W$, then $\frac1{12}W=5$.

Step 5: Answer

Solving gives $W=60$, so the player should win $\boxed{60}$ dollars.

Key Idea

Compute the probability of winning and set expected payout equal to the cost.
