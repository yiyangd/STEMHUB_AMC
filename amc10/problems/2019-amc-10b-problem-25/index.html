2019 AMC 10B Problem 25

2019AMC 10BProblem 25组合数学递推与序列计数递推序列

Problem Statement

How many sequences of $0$s and $1$s of length $19$ begin with a $0$, end with a $0$, contain no two consecutive $0$s, and contain no three consecutive $1$s?

Choices

  1. A55
  2. B60
  3. C65
  4. D70
  5. E75

Answer

C. 65

Solution

Step 1: Translate the restrictions into gaps

The sequence begins and ends with $0$, and no two zeros are consecutive. Therefore between consecutive zeros there must be a block of $1$s.

Step 2: Use the no-three-ones condition

Because no three consecutive $1$s are allowed, each block between zeros has length either $1$ or $2$.

Step 3: Set up variables

Suppose there are $k$ gaps between zeros. Then there are $k+1$ zeros. If $t$ of the gaps have length $2$ and the rest have length $1$, the total length is \[(k+1)+(k+t)=2k+t+1.\]

Step 4: Use length 19

We need \[2k+t+1=19,\] so \[t=18-2k.\] Also $0\le t\le k$.

Step 5: Count possibilities

The possible values are $k=6,7,8,9$, giving \[\binom66+\binom74+\binom82+\binom90=1+35+28+1=65.\]

Step 6: Conclude

The answer is $\boxed{65}$.

Key Idea

Represent the sequence as gaps of one or two 1s between zeros.
