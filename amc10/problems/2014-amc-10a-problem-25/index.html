2014 AMC 10A Problem 25

2014AMC 10AProblem 25数论整数构造整数构造

Problem Statement

The number $5^{867}$ is between $2^{2013}$ and $2^{2014}$. How many pairs of integers $(m,n)$ are there such that $1\le m\le2012$ and $5^n<2^m<2^{m+2}<5^{n+1}$?

Choices

  1. A278
  2. B279
  3. C280
  4. D281
  5. E282

Answer

B. 279

Solution

Step 1: Translate with logarithms

Let $\alpha=\log_2 5$. The inequality $5^n<2^m<2^{m+2}<5^{n+1}$ becomes \[n\alpha<m<m+2<(n+1)\alpha.\]

Step 2: Understand how many m values are possible

Since $\alpha$ is a little more than $2$, the possible integer $m$ for a fixed $n$ can only be the first integer greater than $n\alpha$. Such an $m$ works exactly when the fractional part of $n\alpha$ is greater than $3-\alpha$.

Step 3: Remove the integer part of alpha

Write $\alpha=2+\beta$, where $\beta=\log_2(5/4)$. The condition becomes $\{n\beta\}>1-\beta$, which is equivalent to $\lfloor(n+1)\beta\rfloor=\lfloor n\beta\rfloor+1$.

Step 4: Count the jumps

For $1\le m\le2012$, the relevant values are $n=1$ through $866$. The number of jumps is \[\lfloor867\beta\rfloor.\]

Step 5: Use the given estimate

The given fact says $2^{2013}<5^{867}<2^{2014}$, so $2013<867\alpha<2014$. Subtracting $2\cdot867=1734$ gives $279<867\beta<280$.

Step 6: Conclude

Therefore $\lfloor867\beta\rfloor=279$, so the answer is $\boxed{279}$.

Key Idea

Convert the exponential inequalities into fractional-part counting with logarithms.
