2017 AMC 10B Problem 16

2017AMC 10BProblem 16数论进制与数字数字进制

Problem Statement

How many of the base-ten numerals for the positive integers less than or equal to $2017$ contain the digit $0$?

Choices

  1. A469
  2. B471
  3. C475
  4. D478
  5. E481

Answer

A. 469

Solution

Step 1: Count the complement

It is easier to count positive integers up to $2017$ whose numerals do not contain $0$, then subtract from $2017$.

Step 2: Count 1 to 999 without zero

For one-, two-, and three-digit numbers, the counts are \[9+9^2+9^3=819.\]

Step 3: Count 1000 to 1999 without zero

The thousands digit is $1$, and the other three digits can each be $1$ through $9$, giving $9^3=729$ numbers.

Step 4: Handle 2000 to 2017

Every number from $2000$ to $2017$ contains a $0$ in the hundreds digit, so none are counted in the no-zero complement.

Step 5: Subtract

The number without zero is $819+729=1548$. Therefore the number containing $0$ is \[2017-1548=469.\]

Step 6: Conclude

The answer is $\boxed{469}$.

Key Idea

Count the complement: numerals with no zero.
