2024 AMC 10B Problem 3 数论 整数构造 整数构造

Problem Statement

For how many integer values of $x$ is $|2x| \le 7\pi$?

Choices

  1. A16
  2. B17
  3. C19
  4. D20
  5. E21

Answer

E. 21

Solution

Step 1: Identify what is being counted

The problem asks for the number of integer values of $x$, not for a range length. So after solving the inequality, we must count integers carefully, including both negative and positive values.

Step 2: Isolate $x$ inside the absolute value inequality

The inequality is \[ |2x|\le 7\pi. \] Because $|2x|=2|x|$, divide both sides by $2$ to get \[ |x|\le \frac{7\pi}{2}. \] This means $x$ must lie between $-\frac{7\pi}{2}$ and $\frac{7\pi}{2}$.

Step 3: Estimate the boundary without overdoing decimals

We only need to know which integers fit. Since $\pi$ is a little more than $3$, $\frac{7\pi}{2}$ is a little more than $\frac{21}{2}=10.5$. Since $\pi<\frac{22}{7}$, we also have $\frac{7\pi}{2}<11$. So the cutoff is between $10.5$ and $11$.

Step 4: List the possible integers in a structured way

Because the cutoff is greater than $10$ but less than $11$, the allowed integers are \[ -10,-9,\ldots,-1,0,1,\ldots,9,10. \] That is $10$ negative integers, $0$, and $10$ positive integers.

Step 5: Count and check the endpoints

The total number of integers is $10+1+10=21$. The endpoint $11$ is not allowed because the cutoff is less than $11$, while $10$ is allowed because the cutoff is greater than $10$. Therefore the answer is $\boxed{21}$.

Key Idea

Convert the absolute value inequality into an interval for integer values.
