Problem Statement

Consider the following $100$ sets of $10$ elements each: $\{1,2,\ldots,10\},\{11,12,\ldots,20\},\ldots,\{991,992,\ldots,1000\}$. How many of these sets contain exactly two multiples of $7$?

Choices

  1. A40
  2. B42
  3. C43
  4. D49
  5. E50

Answer

B. 42

Solution

Step 1: Convert each set into an interval

The sets are the intervals \[10t+1,10t+2,\ldots,10t+10\] for $t=0,1,\ldots,99$.

Step 2: Use residues modulo 7

A length-$10$ interval contains either one or two multiples of $7$. It contains two exactly when the first multiple of $7$ occurs within the first $3$ positions of the interval.

Step 3: Track the starting residue

The number before the interval is $10t$, which has residue $3t\pmod7$. The first multiple occurs in positions $1,2,$ or $3$ exactly when $3t\equiv6,5,$ or $4\pmod7$.

Step 4: Count good residues

As $t$ runs through a full cycle modulo $7$, exactly $3$ of the $7$ residues work.

Step 5: Count among 100 intervals

There are $98$ intervals in $14$ full cycles, giving $14\cdot3=42$ good intervals. The last two values of $t$ do not add another good residue.

Step 6: Conclude

The answer is $\boxed{42}$.

Key Idea

Use residues modulo 7 across length-10 blocks.
