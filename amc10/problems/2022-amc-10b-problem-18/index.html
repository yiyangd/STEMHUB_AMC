Problem Statement

Consider systems of three linear equations in $x,y,z$, where each coefficient is either $0$ or $1$. The three equations need not be distinct, and two systems containing the same equations in a different order are considered different. How many such systems have a solution other than $x=y=z=0$?

Choices

  1. A302
  2. B338
  3. C340
  4. D343
  5. E344

Answer

B. 338

Solution

Step 1: Turn the system into a matrix question

A nonzero solution exists exactly when the $3\times3$ coefficient matrix is singular. There are $8$ possible rows, so there are \[8^3=512\] ordered systems in all.

Step 2: Count the nonsingular systems instead

It is cleaner to count matrices with linearly independent rows and subtract. The first row can be any nonzero $0$-$1$ row, giving $7$ choices.

Step 3: Choose the second row

The second row must not be $0$ or equal to the first row. For $0$-$1$ rows, those are the only dependent choices with one nonzero row, so there are $6$ choices. Thus there are $7\cdot6=42$ ordered independent pairs of first two rows.

Step 4: Count the third row by plane type

For most of these $42$ ordered pairs, the plane they span contains $4$ of the $8$ possible $0$-$1$ rows, so the third row has $8-4=4$ independent choices. There are $36$ such pairs.

Step 5: Handle the special pairs

The remaining $6$ ordered pairs are formed by choosing two of $(1,1,0),(1,0,1),(0,1,1)$. Their span contains only $3$ cube vertices, so the third row has $8-3=5$ independent choices.

Step 6: Subtract

The number of nonsingular systems is \[36\cdot4+6\cdot5=174.\] Therefore the number with a nonzero solution is \[512-174=338.\] The answer is $\boxed{338}$.

Key Idea

Count singular 0-1 coefficient matrices by subtracting nonsingular matrices.
