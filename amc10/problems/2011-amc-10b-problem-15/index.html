2011 AMC 10B Problem 15

2011AMC 10BProblem 15概率与统计平均数与数据集平均数数据

Problem Statement

Let $@$ denote the 'averaged with' operation: $a@b=\frac{a+b}{2}$. Which of the following distributive laws hold for all numbers $x,y,z$? I. $x@(y+z)=(x@y)+(x@z)$ II. $x+(y@z)=(x+y)@(x+z)$ III. $x@(y@z)=(x@y)@(x@z)$

Choices

  1. AI only
  2. BII only
  3. CIII only
  4. DI and III only
  5. EII and III only

Answer

E. II and III only

Solution

Step 1: Translate the operation

The operation $a@b$ means $\frac{a+b}{2}$. The safest way to test these laws is to expand both sides.

Step 2: Test statement I

The left side is $x@(y+z)=\frac{x+y+z}{2}$. The right side is $(x@y)+(x@z)=\frac{x+y}{2}+\frac{x+z}{2}=x+\frac{y+z}{2}$. These are not always equal, so I is false.

Step 3: Test statement II

The left side is $x+(y@z)=x+\frac{y+z}{2}$. The right side is $(x+y)@(x+z)=\frac{x+y+x+z}{2}=x+\frac{y+z}{2}$. These match, so II is true.

Step 4: Test statement III

The left side is $x@(y@z)=\frac{x+\frac{y+z}{2}}{2}=\frac{x}{2}+\frac{y}{4}+\frac{z}{4}$. The right side is $(x@y)@(x@z)=\frac{\frac{x+y}{2}+\frac{x+z}{2}}{2}=\frac{x}{2}+\frac{y}{4}+\frac{z}{4}$. These match, so III is true.

Step 5: Conclude

Exactly statements II and III hold. The answer is $\boxed{\text{II and III only}}$.

Key Idea

Expand the averaging operation algebraically and compare both sides of each identity.
