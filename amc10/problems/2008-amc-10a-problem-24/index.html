2008 AMC 10A Problem 24

2008AMC 10AProblem 24数论进制与数字数字进制

Problem Statement

Let $k=2008^2+2^{2008}$. What is the units digit of $k^2+2k$?

Choices

  1. A$0$
  2. B$2$
  3. C$4$
  4. D$6$
  5. E$8$

Answer

A. 0

Solution

Step 1: Work only with units digits

The expression asks for the units digit, so we do not need the full value of $k$. We only need $k$ modulo $10$.

Step 2: Find the units digit of $2008^2$

The units digit of $2008$ is $8$, so the units digit of $2008^2$ is the units digit of $8^2=64$, which is $4$.

Step 3: Find the units digit of $2^{2008}$

Powers of $2$ repeat in units digit with cycle $2,4,8,6$. Since $2008$ is divisible by $4$, the units digit of $2^{2008}$ is the fourth digit in the cycle, $6$.

Step 4: Find the units digit of $k$

Therefore $k=2008^2+2^{2008}$ has units digit $4+6=10$, so $k$ is congruent to $0$ modulo $10$.

Step 5: Use that in the final expression

If $k\equiv 0\pmod{10}$, then $k^2\equiv 0\pmod{10}$ and $2k\equiv 0\pmod{10}$. Hence $k^2+2k$ also has units digit $0$.

Step 6: Answer

The units digit is $\boxed{0}$.

Key Idea

Use units digits and modular arithmetic instead of computing large powers.
