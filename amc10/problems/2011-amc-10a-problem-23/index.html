2011 AMC 10A Problem 23

2011AMC 10AProblem 23概率与统计组合概率概率计数

Problem Statement

Seven students count from $1$ to $1000$ as follows. Alice says all the numbers except the middle number in each consecutive group of three numbers. Barbara says all of the numbers Alice does not say, except she also skips the middle number in each consecutive group of three numbers. Candice, Debbie, Eliza, and Fatima continue the same process in alphabetical order. Finally, George says the only number that no one else says. What number does George say?

Choices

  1. A37
  2. B242
  3. C365
  4. D728
  5. E998

Answer

C. 365

Solution

Step 1: See what each student leaves behind

Each student says all available numbers except the middle number in each consecutive group of three. So after a student is done, the numbers left are exactly the $2$nd, $5$th, $8$th, and so on in that student's current list.

Step 2: Track positions, not all numbers

If a number is the $k$th number in the next remaining list, then before that round it was in position $3k-1$. This gives a simple reverse recurrence: go backward by replacing $k$ with $3k-1$.

Step 3: Count the rounds

Alice, Barbara, Candice, Debbie, Eliza, and Fatima each perform this skipping process. George receives the one number left after six such rounds.

Step 4: Work backward from the final number

Start with final position $1$ and apply $k\mapsto3k-1$ six times: \[1\to2\to5\to14\to41\to122\to365.\]

Step 5: Conclude

So George says the number $\boxed{365}$.

Key Idea

Repeatedly keeping the middle number in each group of three creates a base-3 recurrence.
