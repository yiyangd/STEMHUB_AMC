2003 AMC 10B Problem 10

2003AMC 10BProblem 10组合数学递推与序列计数递推序列

Problem Statement

Nebraska changed its license plate scheme. Each old license plate consisted of a letter followed by four digits. Each new license plate consists of three letters followed by three digits. By how many times has the number of possible license plates increased?

Choices

  1. A$\frac{26}{10}$
  2. B$\frac{26^2}{10^2}$
  3. C$\frac{26^2}{10}$
  4. D$\frac{26^3}{10^3}$
  5. E$\frac{26^3}{10^2}$

Answer

C. \frac{26^2}{10}

Solution

Step 1: Read the format as a counting problem

The old format has one letter and four digits, while the new format has three letters and three digits. Since each position can be chosen independently, multiplication is the natural counting tool.

Step 2: Count the old plates

There are $26$ choices for the letter and $10$ choices for each digit. Therefore the number of old plates is $26\cdot 10^4$.

Step 3: Count the new plates

The new format has $26^3$ choices for the three letters and $10^3$ choices for the three digits. So the number of new plates is $26^3\cdot 10^3$.

Step 4: Compare by division

The question asks how many times larger the new count is, so divide new by old: \[\frac{26^3\cdot 10^3}{26\cdot 10^4}=\frac{26^2}{10}.\]

Step 5: Choose the matching option

The increase factor is $\frac{26^2}{10}$, which is choice $\boxed{\text{C}}$.

Key Idea

Count old and new plate formats separately, then divide to get the increase factor.
