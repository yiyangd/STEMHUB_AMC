2024 AMC 10A Problem 18

2024AMC 10AProblem 18数论进制与数字数字进制

Problem Statement

There are exactly $K$ positive integers $b$ with $5\le b\le2024$ such that the base-$b$ integer $2024_b$ is divisible by $16$ in base ten. What is the sum of the digits of $K$?

Choices

  1. A16
  2. B17
  3. C18
  4. D20
  5. E21

Answer

D. 20

Solution

Step 1: Convert the base-b number

The base-$b$ integer $2024_b$ has value \[2b^3+0b^2+2b+4=2b^3+2b+4.\]

Step 2: Reduce the divisibility condition

We need \[2b^3+2b+4\equiv0\pmod{16}.\] Dividing by $2$, this is equivalent to \[b^3+b+2\equiv0\pmod8.\]

Step 3: Check residues modulo 8

If $b$ is odd, then $b^3\equiv b\pmod8$, so the condition becomes \[2b+2\equiv0\pmod8,\] which gives $b\equiv3$ or $7\pmod8$. If $b$ is even, checking $0,2,4,6$ modulo $8$ shows only $b\equiv6\pmod8$ works.

Step 4: Count b values

So the valid residues are \[3,6,7\pmod8.\] From $5$ through $2024$, there are $2020$ integers, which is $252$ complete blocks of $8$ plus $4$ extra integers.

Step 5: Finish the count

Each full block contributes $3$ valid residues, giving $252\cdot3=756$. The extra residues are $5,6,7,0$, contributing $2$ more. Thus $K=758$.

Step 6: Conclude

The sum of the digits of $758$ is \[7+5+8=20.\] The answer is $\boxed{20}$.

Key Idea

Convert the base-b number to base ten and count residues modulo 8.
