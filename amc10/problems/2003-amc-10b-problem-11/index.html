Problem Statement

A line with slope $3$ intersects a line with slope $5$ at the point $(10,15)$. What is the distance between the $x$-intercepts of these two lines?

Choices

  1. A$2$
  2. B$5$
  3. C$7$
  4. D$12$
  5. E$20$

Answer

A. 2

Solution

Step 1: Focus on what an x-intercept means

An $x$-intercept is where a line crosses the $x$-axis, so its $y$-coordinate is $0$. The slopes and the common point give us enough information to write each line.

Step 2: Write the line with slope 3

Using point-slope form through $(10,15)$, the first line is $y-15=3(x-10)$. Set $y=0$ because we want the $x$-intercept: $-15=3(x-10)$, so $x=5$.

Step 3: Write the line with slope 5

For the second line, $y-15=5(x-10)$. Again set $y=0$: $-15=5(x-10)$, so $x=7$.

Step 4: Take the distance on the x-axis

The two intercepts are at $x=5$ and $x=7$. Their distance is $|7-5|=2$.

Step 5: Check the answer

The steeper line reaches the $x$-axis over a shorter horizontal distance, which matches the intercept $7$ being closer to $10$ than $5$ is. The answer is $\boxed{2}$.

Key Idea

Use the point-slope form of each line and set y=0 to find the x-intercepts.
