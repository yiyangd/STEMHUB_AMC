2002 AMC 10B Problem 3

2002AMC 10BProblem 3概率与统计平均数与数据集平均数数据

Problem Statement

The arithmetic mean of the nine numbers in the set {9, 99, 999, 9999, ..., 999999999} is a 9-digit number M , all of whose digits are distinct. The number M does not contain the digit

Choices

  1. A0
  2. B2
  3. C4
  4. D6
  5. E8

Answer

A. 0

Solution

Step 1: Understand the numbers

The set is $9,99,999,\ldots,999999999$, one number with each length from $1$ to $9$.

Step 2: Sum efficiently

Their sum is $1,111,111,101$. Dividing by $9$ gives the mean $123,456,789$.

Step 3: Read the digits

The number $123,456,789$ contains each digit from $1$ through $9$ exactly once.

Step 4: Answer

It does not contain $0$, so the answer is $\boxed{0}$.

Key Idea

把平均数、总和或中位数条件转化为代数约束。
