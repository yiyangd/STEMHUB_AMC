2019 AMC 10B Problem 10

2019AMC 10BProblem 10几何面积与相似面积比例

Problem Statement

In a given plane, points $A$ and $B$ are $10$ units apart. How many points $C$ are there in the plane such that the perimeter of $\triangle ABC$ is $50$ units and the area of $\triangle ABC$ is $100$ square units?

Choices

  1. A0
  2. B2
  3. C4
  4. D8
  5. Einfinitely many

Answer

A. 0

Solution

Step 1: Use the area to find the height

Take $AB$ as the base. Since $AB=10$ and the area is $100$, the height from $C$ to line $AB$ must satisfy \[\frac12\cdot10\cdot h=100.\] Thus $h=20$.

Step 2: Use the perimeter condition

The perimeter is $50$, so \[AC+BC=40.\]

Step 3: Find the smallest possible AC+BC at height 20

For points $C$ at distance $20$ from line $AB$, the shortest possible value of $AC+BC$ occurs above the midpoint of $AB$. That minimum is \[2\sqrt{5^2+20^2}=2\sqrt{425}>40.\]

Step 4: Compare

Even the smallest possible value of $AC+BC$ is greater than $40$, so the perimeter condition cannot be met.

Step 5: Conclude

There are $\boxed{0}$ possible points $C$.

Key Idea

Use base-height area and the triangle inequality.
