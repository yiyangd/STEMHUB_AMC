2019 AMC 12B Problem 3

2019AMC 12BProblem 3几何坐标几何坐标几何

Problem Statement

Which one of the following rigid transformations maps the line segment $AB$ onto the line segment $A'B'$ so that the image of $A(-2,1)$ is $A'(2,-1)$ and the image of $B(-1,4)$ is $B'(1,-4)$?

Choices

  1. Areflection in the $y$-axis
  2. Bcounterclockwise rotation around the origin by $90^\circ$
  3. Ctranslation by $3$ units to the right and $5$ units down
  4. Dreflection in the $x$-axis
  5. Eclockwise rotation about the origin by $180^\circ$

Answer

E. 180-degree rotation about the origin

Solution

Step 1: Look for the coordinate rule

The point $A(-2,1)$ goes to $(2,-1)$. Both coordinates changed sign. The same happens for $B(-1,4)$, which goes to $(1,-4)$.

Step 2: Recognize the transformation

The rule \[(x,y)\mapsto(-x,-y)\] is a rotation by $180^\circ$ about the origin. It is not a reflection in one axis, because both coordinates change sign.

Step 3: Check both endpoints

Applying the rule to $A$ gives \[(-2,1)\mapsto(2,-1),\] and applying it to $B$ gives \[(-1,4)\mapsto(1,-4).\] Both match the required images.

Step 4: Use rigidity

A rigid transformation is determined by how it moves the endpoints of the segment here, so this transformation maps the whole segment correctly.

Step 5: Conclude

The answer is $\boxed{\text{E}}$, a $180^\circ$ rotation about the origin.

Key Idea

Match both coordinates under each rigid transformation.
