2011 AMC 12A Problem 14

2011AMC 12AProblem 14概率与统计独立性独立事件概率

Problem Statement

Suppose $a$ and $b$ are single-digit positive integers chosen independently and at random. What is the probability that the point $(a,b)$ lies above the parabola $y=ax^2-bx$?

Choices

  1. A$\frac{11}{81}$
  2. B$\frac{13}{81}$
  3. C$\frac5{27}$
  4. D$\frac{17}{81}$
  5. E$\frac{19}{81}$

Answer

E. \frac{19}{81}

Solution

Step 1: Substitute the point

The point is $(a,b)$, so plug $x=a$ and $y=b$ into the condition of lying above the parabola: \[b>a\cdot a^2-ba.\] This is \[b>a^3-ab.\]

Step 2: Rearrange the inequality

Move the $ab$ term to the left: \[b+ab>a^3,\] so \[b(a+1)>a^3.\]

Step 3: Count b values for each a

For $a=1$, all $9$ values of $b$ work. For $a=2$, values $b=3,4,\ldots,9$ work, giving $7$. For $a=3$, values $b=7,8,9$ work, giving $3$. For $a\ge4$, no single-digit positive $b$ is large enough.

Step 4: Add favorable pairs

The number of favorable pairs is \[9+7+3=19.\]

Step 5: Compute the probability

There are $9\cdot9=81$ equally likely pairs $(a,b)$.

Step 6: Conclude

The probability is \[\boxed{\frac{19}{81}}.\]

Key Idea

Substitute the random point into the parabola inequality and count pairs.
