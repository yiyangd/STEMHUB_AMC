2016 AMC 12A Problem 20

2016AMC 12AProblem 20数论质因数与整除质因数整除

Problem Statement

A binary operation $\diamond$ has the properties that $a\diamond(b\diamond c)=(a\diamond b)\cdot c$ and that $a\diamond a=1$ for all nonzero real numbers $a$, $b$, and $c$. The solution to the equation $2016\diamond(6\diamond x)=100$ can be written as $\frac pq$, where $p$ and $q$ are relatively prime positive integers. What is $p+q$?

Choices

  1. A109
  2. B201
  3. C301
  4. D3049
  5. E33601

Answer

A. 109

Solution

Step 1: Guess the operation from a diamond a

The condition $a\diamond a=1$ strongly suggests that $a\diamond b$ may behave like a quotient, because $a/a=1$.

Step 2: Verify the quotient operation

If \(a\diamond b=\frac ab\), then \[a\diamond(b\diamond c)=a\diamond\left(\frac bc\right)=\frac{a}{b/c}=\frac{ac}{b},\] while \[(a\diamond b)\cdot c=\frac ab\cdot c=\frac{ac}{b}.\] So division satisfies both given properties.

Step 3: Use the operation in the equation

Now compute the inside expression: \[6\diamond x=\frac6x.\] Then \[2016\diamond(6\diamond x)=2016\diamond\frac6x=\frac{2016}{6/x}=336x.\]

Step 4: Solve for x

The equation becomes \[336x=100,\] so \[x=\frac{100}{336}=\frac{25}{84}.\]

Step 5: Add numerator and denominator

The fraction is already in lowest terms, so \(p=25\) and \(q=84\). Therefore \[p+q=25+84=109.\]

Step 6: Conclude

The answer is $\boxed{109}$.

Key Idea

Recognize that the operation behaves like division, then solve the resulting equation.
