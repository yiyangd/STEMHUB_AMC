Problem Statement

Integers $a$, $b$, and $c$ satisfy $ab+c=100$, $bc+a=87$, and $ca+b=60$. What is $ab+bc+ca$?

Choices

  1. A212
  2. B247
  3. C258
  4. D276
  5. E284

Answer

D. 276

Solution

Step 1: Create smaller equations by subtracting

The equations are large, but subtracting them creates factors. From

\[ab+c=100\quad\text{and}\quad bc+a=87,\]

we get

\[ab-bc+c-a=13.\]

This factors as

\[(a-c)(b-1)=13.\]

Step 2: Use the fact that 13 has few divisors

Since $a$, $b$, and $c$ are integers, both factors are integers. Therefore $b-1$ must be one of

\[1,13,-1,-13.\]

So

\[b\in\{2,14,0,-12\}.\]

This turns a three-variable problem into a few cases.

Step 3: Test the possible values of $b$

Substituting each possible value of $b$ into the original system, only $b=-12$ gives an integer solution satisfying all three equations. The corresponding values are

\[a=-9,\qquad b=-12,\qquad c=-8.\]

This is much safer than trying to solve the full nonlinear system directly.

Step 4: Compute the requested expression

Now calculate

\[ab+bc+ca=(-9)(-12)+(-12)(-8)+(-8)(-9).\]

That is

\[108+96+72=276.\]

Step 5: Check against the original equations

The values give $ab+c=108-8=100$, $bc+a=96-9=87$, and $ca+b=72-12=60$. So the solution is consistent, and the answer is $276$.

Key Idea

Subtract the equations to force a small divisor condition, then check the resulting integer cases.
