2013 AMC 12A Problem 10

2013AMC 12AProblem 10数论进制与数字数字进制

Problem Statement

Let $S$ be the set of positive integers $n$ for which $\frac1n$ has the repeating decimal representation $0.\overline{ab}=0.ababab\cdots$, with $a$ and $b$ different digits. What is the sum of the elements of $S$?

Choices

  1. A11
  2. B44
  3. C110
  4. D143
  5. E155

Answer

D. 143

Solution

Step 1: Convert the repeating decimal

A two-digit repetend satisfies \[0.\overline{ab}=\frac{10a+b}{99}.\] The digit $a$ is allowed to be $0$, as in $0.\overline{09}$.

Step 2: Set it equal to 1/n

We need \[\frac1n=\frac{k}{99},\] where $k=10a+b$ and the two digits of $k$ are different. Thus \[n=\frac{99}{k},\] so $k$ must divide $99$.

Step 3: Check divisors of 99

The divisors $k$ that give valid two-digit repetends with different digits are \[1,3,9,\] corresponding to $01,03,09$.

Step 4: Find n values

These give \[n=99,\ 33,\ 11.\]

Step 5: Add

The sum is \[99+33+11=143.\]

Step 6: Conclude

The answer is $\boxed{143}$.

Key Idea

Represent a two-digit repetend as k/99, allowing leading zero.
