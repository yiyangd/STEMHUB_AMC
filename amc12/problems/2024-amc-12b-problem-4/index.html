2024 AMC 12B Problem 4

2024 AMC 12B Problem 4 组合数学 周期与递推计数 周期三角数分组

Problem Statement

Balls numbered $1,2,3,\ldots$ are deposited in $5$ bins, labeled A, B, C, D, and E, using blocks of sizes $1,2,3,4,\ldots$ cyclically through the bins. In which bin is ball $2024$ deposited?

Choices

  1. AA
  2. BB
  3. CC
  4. DD
  5. EE

Answer

D. D

Solution

Step 1

At step $n$, exactly $n$ balls are deposited, so after step $n$ the number of deposited balls is $T_n=\frac{n(n+1)}{2}$.

Step 2

We find $T_{63}=2016$ and $T_{64}=2080$, so ball $2024$ is deposited during step $64$.

Step 3

The bins cycle A, B, C, D, E by step number. Since $64\equiv 4\pmod 5$, step $64$ uses bin D. Thus the answer is $\boxed{D}$.

Key Idea

Use triangular numbers to locate the block containing the target ball, then reduce the block number modulo $5$.
