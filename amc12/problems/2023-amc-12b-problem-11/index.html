2023 AMC 12B Problem 11

2023AMC 12BProblem 11几何面积与相似面积比例

Problem Statement

What is the maximum area of an isosceles trapezoid that has legs of length $1$ and one base twice as long as the other?

Choices

  1. A$\frac{\sqrt5}{3}$
  2. B$\frac{\sqrt8}{4}$
  3. C$\frac{5\sqrt2}{4}$
  4. D$\frac32$
  5. E$\frac{3\sqrt3}{4}$

Answer

D. $\frac32$

Solution

Step 1: Name the shorter base

Let the shorter base be $x$, so the longer base is $2x$. In an isosceles trapezoid, the horizontal offset on each side is $\frac{x}{2}$.

Step 2: Find the height

Each leg has length $1$, so the height is \[h=\sqrt{1-\left(\frac{x}{2}\right)^2}.\]

Step 3: Write the area

The area is \[A=\frac{x+2x}{2}\cdot h=\frac{3x}{2}\sqrt{1-\frac{x^2}{4}}.\]

Step 4: Maximize

Maximize $A^2=\frac94x^2\left(1-\frac{x^2}{4}\right)$. Let $u=x^2$; then this is proportional to \[u-\frac{u^2}{4},\] which is maximized at $u=2$.

Step 5: Compute the maximum

When $x=\sqrt2$, the height is $\frac1{\sqrt2}$, so \[A=\frac{3\sqrt2}{2}\cdot\frac1{\sqrt2}=\frac32.\]

Step 6: Conclude

The answer is $\boxed{\frac32}$.

Key Idea

Express trapezoid area in terms of the shorter base and maximize.
