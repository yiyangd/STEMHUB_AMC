2018 AMC 12B Problem 10

2018AMC 12BProblem 10数论整除与同余同余余数

Problem Statement

A list of \(2018\) positive integers has a unique mode, which occurs exactly \(10\) times. What is the least number of distinct values that can occur in the list?

Choices

  1. A202
  2. B223
  3. C224
  4. D225
  5. E234

Answer

D. 225

Solution

Step 1: Use the unique mode condition

The mode occurs exactly \(10\) times. Every other value must occur at most \(9\) times, otherwise the mode would not be unique.

Step 2: Fill the remaining entries efficiently

After the \(10\) copies of the mode, there are \[2018-10=2008\] entries left.

Step 3: Minimize distinct values

To use as few other values as possible, each other value should appear \(9\) times, except possibly one leftover group. We need \[\left\lceil\frac{2008}{9}\right\rceil=224\] other distinct values.

Step 4: Add the mode value

Including the mode itself, the least number of distinct values is \[224+1=225.\]

Step 5: Conclude

The answer is $\boxed{225}$.

Key Idea

Pack all non-mode values in groups of at most nine.
