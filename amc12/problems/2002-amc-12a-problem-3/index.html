Problem Statement

According to the standard convention for exponentiation, \(2^{2^{2^2}}=2^{16}=65{,}536\). If the order in which the exponentiations in \(2^2^2^2\) are performed is changed, how many other values are possible?

Choices

  1. A0
  2. B1
  3. C2
  4. D3
  5. E4

Answer

B. 1

Solution

Step 1: Understand the standard value

Exponentiation is normally evaluated from the top down, so \[2^2^2^2=2^{(2^{(2^2)})}=2^{16}=65536.\]

Step 2: Look for genuinely different groupings

Changing parentheses can make the expression behave like \[((2^2)^2)^2\] or \[(2^{2^2})^2.\] Both of these equal \[16^2=256.\]

Step 3: Check the remaining groupings

Other parenthesizations either reproduce \(2^{16}\) or \(256\); they do not create a third value.

Step 4: Count other values

The standard value is \(65536\). The only other possible value is \(256\).

Step 5: Conclude

There is $\boxed{1}$ other value.

Key Idea

Compare possible parenthesizations of repeated exponentiation.
