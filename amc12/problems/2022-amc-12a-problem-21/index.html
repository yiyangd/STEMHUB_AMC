2022 AMC 12A Problem 21

2022AMC 12AProblem 21代数多项式与根多项式根

Problem Statement

Let \[P(x)=x^{2022}+x^{1011}+1.\] Which of the following polynomials is a factor of $P(x)$?

Choices

  1. A$x^2-x+1$
  2. B$x^2+x+1$
  3. C$x^4+1$
  4. D$x^6-x^3+1$
  5. E$x^6+x^3+1$

Answer

E. $x^6+x^3+1$

Solution

Step 1: Look for a substitution

The exponents $2022$ and $1011$ suggest setting \[y=x^{1011}.\] Then \[P(x)=y^2+y+1.\]

Step 2: Connect to a candidate factor

The polynomial $x^6+x^3+1$ has the same shape if we set $u=x^3$: \[x^6+x^3+1=u^2+u+1.\]

Step 3: Use the roots of the candidate factor

If $x^6+x^3+1=0$, then with $u=x^3$ we have \[u^2+u+1=0.\] This means $u^3=1$ and $u\ne1$.

Step 4: Reduce the large exponent

Since $x^{1011}=(x^3)^{337}=u^{337}$, and $337\equiv1\pmod3$, we get \[x^{1011}=u.\]

Step 5: Evaluate P at those roots

Then \[P(x)=x^{2022}+x^{1011}+1=u^2+u+1=0.\] So every root of $x^6+x^3+1$ is a root of $P(x)$.

Step 6: Conclude

Therefore $x^6+x^3+1$ is a factor. The answer is $\boxed{x^6+x^3+1}$.

Key Idea

Use roots of the proposed factor and reduce the exponent modulo 3.
