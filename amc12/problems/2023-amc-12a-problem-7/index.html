2023 AMC 12A Problem 7

2023AMC 12AProblem 7数论进制与数字数字进制

Problem Statement

A digital display shows the current date as an $8$-digit integer consisting of a $4$-digit year, followed by a $2$-digit month, followed by a $2$-digit date within the month. For example, Arbor Day in $2023$ is displayed as $20230428$. For how many dates in $2023$ will each digit appear an even number of times in the $8$-digit display for that date?

Choices

  1. A5
  2. B6
  3. C7
  4. D8
  5. E9

Answer

E. 9

Solution

Step 1: Start with the fixed year

The year $2023$ contributes two $2$s, one $0$, and one $3$. The two $2$s already occur an even number of times, so the month-day digits must contribute an odd number of $0$s and $3$s, and an even number of every other digit.

Step 2: Search by valid dates

The month-day part has only four digits, so we can systematically list valid month-day strings that satisfy the parity requirement and are real dates in $2023$.

Step 3: List the valid month-days

The valid strings are \[0113,0131,0223,0311,0322,1013,1031,1103,1130.\]

Step 4: Count

These are $9$ valid dates.

Step 5: Conclude

The answer is $\boxed{9}$.

Key Idea

Track digit parity in the fixed year 2023 and list valid month-day strings.
