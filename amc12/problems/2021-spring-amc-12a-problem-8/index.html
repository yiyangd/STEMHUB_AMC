2021 Spring AMC 12A Problem 8

2021 SpringAMC 12AProblem 8代数数列与递推数列递推

Problem Statement

A sequence is defined by $D_0=0$, $D_1=0$, $D_2=1$, and $D_n=D_{n-1}+D_{n-3}$ for $n\ge3$. What are the parities of $(D_{2021},D_{2022},D_{2023})$, where $E$ denotes even and $O$ denotes odd?

Choices

  1. A(O, E, O)
  2. B(E, E, O)
  3. C(E, O, E)
  4. D(O, O, E)
  5. E(O, O, O)

Answer

C. (E, O, E)

Solution

Step 1: Work only modulo 2

We only need parity, so compute the recurrence modulo $2$. The initial values are \[0,0,1.\]

Step 2: Find the pattern

Using \[D_n\equiv D_{n-1}+D_{n-3}\pmod2,\] the parity pattern begins \[0,0,1,1,1,0,1,\] and then repeats with period $7$.

Step 3: Reduce the indices

Since \[2021\equiv5\pmod7,\quad 2022\equiv6\pmod7,\quad 2023\equiv0\pmod7,\] we read positions $5,6,0$ of the period.

Step 4: Read the parities

These are \[0,1,0,\] which means \[(E,O,E).\]

Step 5: Conclude

The answer is $\boxed{(E,O,E)}$.

Key Idea

Find the parity period of the recurrence.
