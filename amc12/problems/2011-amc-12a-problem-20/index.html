2011 AMC 12A Problem 20

2011AMC 12AProblem 20数论整数构造整数构造

Problem Statement

Let $f(x)=ax^2+bx+c$, where $a,b,$ and $c$ are integers. Suppose that $f(1)=0$, $50<f(7)<60$, $70<f(8)<80$, and $5000k<f(100)<5000(k+1)$ for some integer $k$. What is $k$?

Choices

  1. A1
  2. B2
  3. C3
  4. D4
  5. E5

Answer

C. 3

Solution

Step 1: Use f(1)=0

Since $f(1)=a+b+c=0$, the values $f(n)$ for $n\ne1$ can be written as \[f(n)=a(n^2-1)+b(n-1)=(n-1)(a(n+1)+b).\]

Step 2: Use f(7)

We have \[f(7)=6(8a+b).\] The only multiple of $6$ strictly between $50$ and $60$ is $54$, so \[8a+b=9.\]

Step 3: Use f(8)

We have \[f(8)=7(9a+b).\] The only multiple of $7$ strictly between $70$ and $80$ is $77$, so \[9a+b=11.\]

Step 4: Solve for a and b

Subtracting the equations gives $a=2$. Then $8a+b=9$ gives $b=-7$. Since $a+b+c=0$, we get $c=5$.

Step 5: Compute f(100)

Now \[f(100)=2(100)^2-7(100)+5=20000-700+5=19305.\] This lies between $15000$ and $20000$, so $k=3$.

Step 6: Conclude

The answer is $\boxed{3}$.

Key Idea

Use divisibility from f(7) and f(8) to determine the quadratic.
