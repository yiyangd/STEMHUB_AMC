2014 AMC 12B Problem 23

2014AMC 12BProblem 23数论整除与同余同余余数

Problem Statement

The number $2017$ is prime. Let \[S=\sum_{k=0}^{62}\binom{2014}{k}.\] What is the remainder when $S$ is divided by $2017$?

Choices

  1. A32
  2. B684
  3. C1024
  4. D1576
  5. E2016

Answer

C. 1024

Solution

Step 1: Reduce the top number modulo 2017

Since $2017$ is prime and \[2014\equiv -3\pmod{2017},\] we can work with binomial coefficients modulo $2017$.

Step 2: Use the negative binomial identity

For $0\le k<2017$, \[\binom{2014}{k}\equiv \binom{-3}{k}\pmod{2017}.\] Also \[\binom{-3}{k}=(-1)^k\binom{k+2}{2}.\]

Step 3: Rewrite the sum

Thus \[S\equiv \sum_{k=0}^{62}(-1)^k\binom{k+2}{2}\pmod{2017}.\]

Step 4: Pair terms

Pair $k=2j$ and $k=2j+1$. The pair contribution is \[\binom{2j+2}{2}-\binom{2j+3}{2}=-(2j+2).\] There are $31$ such pairs from $k=0$ to $61$.

Step 5: Add the last term

The paired sum is \[-\sum_{j=0}^{30}(2j+2)=-2(1+2+\cdots+31)=-992.\] The last term for $k=62$ is \[\binom{64}{2}=2016.\] So \[S\equiv -992+2016=1024.\]

Step 6: Conclude

The remainder is $\boxed{1024}$.

Key Idea

Use binomial coefficients modulo the prime 2017.
