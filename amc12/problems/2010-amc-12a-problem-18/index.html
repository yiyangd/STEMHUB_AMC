2010 AMC 12A Problem 18

2010AMC 12AProblem 18组合数学图形计数网格计数

Problem Statement

A $16$-step path is to go from $(-4,-4)$ to $(4,4)$ with each step increasing either the $x$-coordinate or the $y$-coordinate by $1$. How many such paths stay outside or on the boundary of the square $-2\le x\le2$, $-2\le y\le2$ at each step?

Choices

  1. A92
  2. B144
  3. C1568
  4. D1698
  5. E12,800

Answer

D. 1698

Solution

Step 1: Identify the forbidden lattice points

The path may touch the boundary of the square, but it may not go strictly inside it. Since the path uses integer lattice points, the forbidden points are those with \[-1\le x\le1,\qquad -1\le y\le1.\]

Step 2: Set up dynamic programming

Let $N(x,y)$ be the number of valid paths from $(-4,-4)$ to $(x,y)$. For allowed points, \[N(x,y)=N(x-1,y)+N(x,y-1),\] because the last step came either from the left or from below. For forbidden points, set $N(x,y)=0$.

Step 3: Fill values around the obstacle

Starting from $N(-4,-4)=1$, the recurrence fills the grid row by row. The key is that the $3\times3$ forbidden block in the middle contributes zeros, forcing paths to go around it.

Step 4: Record the final rows

The top two rows of counts become \[1,8,36,64,92,120,176,352,849\] and then \[1,9,45,109,201,321,497,849,1698.\] The last entry is the count at $(4,4)$.

Step 5: Conclude

Therefore the number of valid paths is \[\boxed{1698}.\]

Key Idea

Use dynamic programming on allowed lattice points around the forbidden interior square.
