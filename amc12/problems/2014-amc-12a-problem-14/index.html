2014 AMC 12A Problem 14

2014AMC 12AProblem 14数论整数构造整数构造

Problem Statement

Let $a<b<c$ be three integers such that $a,b,c$ is an arithmetic progression and $a,c,b$ is a geometric progression. What is the smallest possible value of $c$?

Choices

  1. A-2
  2. B1
  3. C2
  4. D4
  5. E6

Answer

C. 2

Solution

Step 1: Parameterize the arithmetic progression

Since $a,b,c$ is an arithmetic progression, write \[b=a+d,\qquad c=a+2d,\] where $d>0$.

Step 2: Use the geometric progression

The sequence $a,c,b$ is geometric, so \[\frac{c}{a}=\frac{b}{c},\] or \[c^2=ab.\]

Step 3: Substitute

\[(a+2d)^2=a(a+d).\] Expanding gives \[a^2+4ad+4d^2=a^2+ad,\] so \[3ad+4d^2=0.\]

Step 4: Solve the integer condition

Because $d>0$, we get \[3a+4d=0,\] so \[a=-\frac{4d}{3}.\] Thus $d$ must be a multiple of $3$.

Step 5: Minimize c

Let $d=3t$. Then \[a=-4t,\quad b=-t,\quad c=2t.\] The smallest positive integer choice is $t=1$, giving $c=2$.

Step 6: Conclude

The answer is $\boxed{2}$.

Key Idea

Parameterize the arithmetic progression and impose the geometric progression condition.
