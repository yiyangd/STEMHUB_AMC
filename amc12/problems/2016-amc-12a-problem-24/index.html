2016 AMC 12A Problem 24

2016AMC 12AProblem 24代数多项式与根多项式根

Problem Statement

There is a smallest positive real number $a$ such that there exists a positive real number $b$ for which all the roots of the polynomial \[x^3-ax^2+bx-a\] are real. In fact, for this value of $a$, the value of $b$ is unique. What is this value of $b$?

Choices

  1. A8
  2. B9
  3. C10
  4. D11
  5. E12

Answer

B. 9

Solution

Step 1: Use Vieta's formulas

Let the real roots be $r,s,t$. From \[x^3-ax^2+bx-a,\] Vieta's formulas give \[r+s+t=a,\quad rs+rt+st=b,\quad rst=a.\] Thus \[r+s+t=rst=a.\]

Step 2: Use the positivity of b

The problem requires $b>0$. If two roots were negative and one positive, then \(rs+rt+st\) would be negative under the condition \(r+s+t=rst>0\). So the roots must be positive for the minimizing case.

Step 3: Apply AM-GM

For positive roots, \[r+s+t\ge3\sqrt[3]{rst}.\] Since \(r+s+t=rst=a\), this becomes \[a\ge3\sqrt[3]{a}.\]

Step 4: Find the smallest possible a

Dividing by \(\sqrt[3]{a}\) gives \[a^{2/3}\ge3,\] so \[a\ge3\sqrt3.\] Equality occurs when \[r=s=t=\sqrt3.\]

Step 5: Find the corresponding b

When all three roots are $\sqrt3$, we have \[b=rs+rt+st=3(\sqrt3)^2=9.\] This also shows the value of $b$ is unique at the minimum.

Step 6: Conclude

The required value is $\boxed{9}$.

Key Idea

Use Vieta's formulas and AM-GM on the real roots with positive b.
