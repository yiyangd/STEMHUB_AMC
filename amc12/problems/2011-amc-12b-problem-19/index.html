2011 AMC 12B Problem 19

2011AMC 12BProblem 19数论整数构造整数构造

Problem Statement

A lattice point in an $xy$-coordinate system is any point $(x,y)$ where both $x$ and $y$ are integers. The graph of $y=mx+2$ passes through no lattice point with $0<x\le100$ for all $m$ such that \[\frac12<m<a.\] What is the maximum possible value of $a$?

Choices

  1. A$\frac{51}{101}$
  2. B$\frac{50}{99}$
  3. C$\frac{51}{100}$
  4. D$\frac{52}{101}$
  5. E$\frac{13}{25}$

Answer

B. \frac{50}{99}

Solution

Step 1: Translate lattice points into rational slopes

The line is \[y=mx+2.\] Since $2$ is already an integer, the point with integer $x$ has integer $y$ exactly when $mx$ is an integer.

Step 2: Understand the forbidden slopes

For some integer $x$ with $1\le x\le100$, this happens when \[m=\frac{k}{x}\] for an integer $k$. So we need the interval \((\frac12,a)\) to contain no fraction with denominator at most $100$.

Step 3: Find the first such fraction above one half

For each denominator $x$, the smallest numerator greater than $\frac{x}{2}$ gives the first fraction above $\frac12$. The closest one occurs when $x$ is as large as possible and odd: \[x=99,\quad k=50.\] This gives \[\frac{50}{99}.\]

Step 4: Check nearby denominators

For $x=100$, the next fraction above $\frac12$ is $\frac{51}{100}$, which is larger. Any smaller denominator gives an even larger gap above $\frac12$.

Step 5: Conclude

The largest possible value of $a$ is \[\boxed{\frac{50}{99}}.\]

Key Idea

Find the first rational slope above 1/2 with denominator at most 100.
