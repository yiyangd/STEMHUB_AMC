2013 AMC 12B Problem 10

2013AMC 12BProblem 10代数运算与化简代数化简

Problem Statement

Alex has $75$ red tokens and $75$ blue tokens. There is a booth where Alex can give two red tokens and receive in return a silver token and a blue token, and another booth where Alex can give three blue tokens and receive in return a silver token and a red token. Alex continues to exchange tokens until no more exchanges are possible. How many silver tokens will Alex have at the end?

Choices

  1. A62
  2. B82
  3. C83
  4. D102
  5. E103

Answer

E. 103

Solution

Step 1: Let x and y count exchanges

Let $x$ be the number of red-token exchanges and $y$ be the number of blue-token exchanges. Each red exchange changes $(R,B)$ by $(-2,+1)$, and each blue exchange changes $(R,B)$ by $(+1,-3)$.

Step 2: Write final token counts

Starting from $(75,75)$, the final counts are \[R=75-2x+y,\qquad B=75+x-3y.\] At the end, no exchange is possible, so \[R<2,\qquad B<3.\]

Step 3: Find the terminal state

The exchange process preserves the reachable terminal state; solving the equations with $R\in\{0,1\}$ and $B\in\{0,1,2\}$ gives the reachable terminal state \[R=1,\qquad B=2.\]

Step 4: Solve for exchange counts

Use \[75-2x+y=1,\qquad 75+x-3y=2.\] Solving gives \[x=59,\qquad y=44.\]

Step 5: Count silver tokens

Each exchange creates one silver token, so the number of silver tokens is \[x+y=59+44=103.\]

Step 6: Conclude

The answer is $\boxed{103}$.

Key Idea

Track the terminal token state with exchange counts.
