2009 AMC 12B Problem 21

2009AMC 12BProblem 21组合数学排列组合排列组合计数

Problem Statement

Ten women sit in $10$ seats in a line. All of the $10$ get up and then reseat themselves using all $10$ seats, each sitting in the seat she was in before or a seat next to the one she occupied before. In how many ways can the women be reseated?

Choices

  1. A89
  2. B90
  3. C120
  4. D$2^{10}$
  5. E$2^2\cdot3^8$

Answer

A. 89

Solution

Step 1: Translate the seating rule

Each woman may stay in her own seat or move one seat left or right. Since all seats must be used, a woman can move only if she swaps with a neighboring woman. Longer cycles are impossible because someone would have to move more than one seat.

Step 2: See the structure as blocks

So the reseating is built from two kinds of blocks along the row: a single seat where the woman stays put, or a pair of adjacent seats where the two women swap. This is exactly the same structure as tiling a row with monominoes and dominoes.

Step 3: Set up a recurrence

Let $a_n$ be the number of valid reseatings for $n$ seats. The first woman either stays, leaving $a_{n-1}$ possibilities, or swaps with the second woman, leaving $a_{n-2}$ possibilities. Thus \[a_n=a_{n-1}+a_{n-2}.\]

Step 4: Start the recurrence

For one seat, $a_1=1$. For two seats, either both stay or they swap, so $a_2=2$. Continuing gives \[a_3=3,\ a_4=5,\ldots,\ a_{10}=89.\]

Step 5: Conclude

There are $\boxed{89}$ possible reseatings.

Key Idea

Count permutations with displacement at most one as tilings by fixed points and adjacent swaps.
