2007 AMC 12A Problem 24

2007AMC 12AProblem 24数论整数构造整数构造

Problem Statement

For each integer \(n>1\), let \(F(n)\) be the number of solutions of the equation \(\sin x=\sin nx\) on the interval \([0,\pi]\). What is \[\sum_{n=2}^{2007}F(n)?\]

Choices

  1. A2,014,524
  2. B2,015,028
  3. C2,015,033
  4. D2,016,532
  5. E2,017,033

Answer

D. 2,016,532

Solution

Step 1: Use the two ways sine values can match

The equation \(\sin x=\sin nx\) means either the angles are congruent modulo \(2\pi\), or they are supplementary modulo \(2\pi\). These two cases organize all possible solutions.

Step 2: Count the first family

From \(x=nx+2k\pi\), we get \((n-1)x=-2k\pi\), so the solutions in \([0,\pi]\) have the form \[x=\frac{2j\pi}{n-1}.\] This gives one set of evenly spaced candidates.

Step 3: Count the second family

From \(x=\pi-nx+2k\pi\), we get \[(n+1)x=(2k+1)\pi,\] so the solutions have the form \[x=\frac{(2k+1)\pi}{n+1}.\] This gives the odd multiples of \(\frac{\pi}{n+1}\) in the interval.

Step 4: Account for overlap

Together these families usually give \(n+1\) distinct solutions. The only time one solution is counted twice is when \(n\equiv1\pmod4\); then the overlap removes one solution, so \(F(n)=n\) instead of \(n+1\).

Step 5: Sum the main contribution

If every \(n\) from \(2\) to \(2007\) contributed \(n+1\), the sum would be \[\sum_{n=2}^{2007}(n+1)=2,017,033.\]

Step 6: Subtract the overlaps

The integers \(n\equiv1\pmod4\) from \(2\) through \(2007\) are \(5,9,\ldots,2005\), a total of \(501\) integers. Therefore the desired sum is \[2,017,033-501=2,016,532.\]

Step 7: Conclude

The answer is \(\boxed{2,016,532}\).

Key Idea

Count solutions from the two sine-angle cases and handle overlaps.
