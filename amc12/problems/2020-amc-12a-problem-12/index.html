2020 AMC 12A Problem 12

2020AMC 12AProblem 12几何坐标几何坐标几何

Problem Statement

Line $\ell$ in the coordinate plane has equation $3x-5y+40=0$. This line is rotated $45^\circ$ counterclockwise about the point $(20,20)$ to obtain line $k$. What is the $x$-coordinate of the $x$-intercept of line $k$?

Choices

  1. A10
  2. B15
  3. C20
  4. D25
  5. E30

Answer

B. 15

Solution

Step 1: Notice the center point lies on the line

Substitute $(20,20)$ into $3x-5y+40=0$: \[60-100+40=0.\] So the rotation point is on the original line, and the rotated line will still pass through $(20,20)$.

Step 2: Find the original slope

The line equation gives \[y=\frac35x+8,\] so its slope is $\frac35$.

Step 3: Rotate the slope by 45 degrees

If a line with slope $m$ is rotated by $45^\circ$, the new slope is \[\frac{m+1}{1-m}.\] With $m=\frac35$, this becomes \[\frac{\frac35+1}{1-\frac35}=4.\]

Step 4: Write the new line

Line $k$ passes through $(20,20)$ with slope $4$, so \[y-20=4(x-20).\]

Step 5: Find the x-intercept

Set $y=0$: \[-20=4(x-20),\] so $x=15$. The answer is $\boxed{15}$.

Key Idea

Rotate the line's slope about a point that lies on the line.
