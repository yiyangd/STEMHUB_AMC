2003 AMC 12A Problem 22

2003AMC 12AProblem 22概率与统计几何概率几何概率面积

Problem Statement

Objects \(A\) and \(B\) move simultaneously in the coordinate plane via a sequence of steps, each of length \(1\). Object \(A\) starts at \((0,0)\), and each of its steps is either right or up, equally likely. Object \(B\) starts at \((5,7)\), and each of its steps is either left or down, equally likely. Which is closest to the probability that the objects meet?

Choices

  1. A0.10
  2. B0.15
  3. C0.20
  4. D0.25
  5. E0.30

Answer

C. 0.20

Solution

Step 1: Find when meeting is possible

After \(t\) steps, object A has moved \(r\) steps right and \(t-r\) steps up. Object B has moved \(l\) steps left and \(t-l\) steps down.

Step 2: Set coordinates equal

A is at \((r,t-r)\). B is at \((5-l,7-(t-l))\). Meeting requires \[r=5-l\quad\text{and}\quad t-r=7-t+l.\]

Step 3: Solve for t

The first equation gives \(r+l=5\). Substitute into the second equation to get \(2t=7+r+l=12\), so \(t=6\).

Step 4: Count favorable path pairs

At time \(6\), we need \(r+l=5\). The number of path pairs is \[\sum_{r=0}^{5}\binom6r\binom6{5-r}=\binom{12}{5}=792.\]

Step 5: Divide by all path pairs

Each object has \(2^6\) possible six-step paths, so the probability is \[\frac{792}{2^{12}}=\frac{792}{4096}\approx0.193.\]

Step 6: Conclude

The closest choice is $\boxed{0.20}$.

Key Idea

Find the only time step when the walkers can meet and count paths.
