2013 AMC 12A Problem 20

2013AMC 12AProblem 20概率与统计平均数与数据集平均数数据

Problem Statement

Let $S=\{1,2,3,\ldots,19\}$. For $a,b\in S$, define $a\succ b$ to mean that either $0<a-b\le9$ or $b-a>9$. How many ordered triples $(x,y,z)$ of elements of $S$ have the property that $x\succ y$, $y\succ z$, and $z\succ x$?

Choices

  1. A810
  2. B855
  3. C900
  4. D950
  5. E988

Answer

B. 855

Solution

Step 1: Turn the relation into a cycle

Place the numbers $1,2,\ldots,19$ around a circle. The condition $a\succ b$ means that $b$ is one of the $9$ positions immediately before $a$ in this cyclic order.

Step 2: Fix x by symmetry

For each fixed $x$, there are $9$ choices for $y$. Write the cyclic distance from $x$ back to $y$ as $i$, where $1\le i\le9$.

Step 3: Count possible z values

Similarly, $y\succ z$ means the distance from $y$ back to $z$ is some $j$ with $1\le j\le9$. For $z\succ x$ to hold, the total backward distance $i+j$ must pass $x$ but not go too far; equivalently \[10\le i+j\le18.\]

Step 4: Count pairs i,j

There are $9\cdot9=81$ pairs $(i,j)$. The pairs with $i+j\le9$ are \[1+2+\cdots+8=36,\] so the valid number is \[81-36=45.\]

Step 5: Multiply by x choices

There are $19$ possible choices of $x$, so the number of ordered triples is \[19\cdot45=855.\]

Step 6: Conclude

The answer is $\boxed{855}$.

Key Idea

Reinterpret the relation as a cyclic order on 19 equally spaced positions.
