2020 AMC 12A Problem 4

2020AMC 12AProblem 4数论进制与数字数字进制

Problem Statement

How many $4$-digit positive integers having only even digits are divisible by $5$?

Choices

  1. A80
  2. B100
  3. C125
  4. D200
  5. E500

Answer

B. 100

Solution

Step 1: List the allowed digits

The even digits are $0,2,4,6,8$. A $4$-digit number cannot start with $0$, so the thousands digit has $4$ choices.

Step 2: Use divisibility by 5

A number divisible by $5$ ends in $0$ or $5$. Since only even digits are allowed, the last digit must be $0$.

Step 3: Count the middle digits

The hundreds and tens digits can be any of the $5$ even digits, giving $5\cdot5$ choices.

Step 4: Multiply the choices

The total number is \[4\cdot5\cdot5\cdot1=100.\]

Step 5: Conclude

There are $\boxed{100}$ such integers.

Key Idea

Use digit choices and the divisibility rule for 5.
