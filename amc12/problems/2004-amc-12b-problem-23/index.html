2004 AMC 12B Problem 23

2004AMC 12BProblem 23数论整数构造整数构造

Problem Statement

The polynomial \(x^3-2004x^2+mx+n\) has integer coefficients and three distinct positive zeroes. Exactly one of these is an integer, and it is the sum of the other two. How many values of \(n\) are possible?

Choices

  1. A250,000
  2. B250,250
  3. C250,500
  4. D250,750
  5. E251,000

Answer

C. 250,500

Solution

Step 1: Name the roots

Let the integer root be \(r\), and let the other two positive roots be \(u\) and \(v\). The problem says \(r=u+v\).

Step 2: Use the sum of roots

By Vieta's formula, \(r+u+v=2004\). Since \(r=u+v\), this gives \(2r=2004\), so \(r=1002\).

Step 3: Reduce to the other two roots

The other two roots have sum \(1002\). Since the polynomial has integer coefficients and \(r\) is an integer root, the quadratic factor has integer coefficients, so \(q=uv\) must be an integer.

Step 4: Find the possible range

The roots \(u\) and \(v\) are positive and distinct, so \[0<q<\left(\frac{1002}{2}\right)^2=251001.\] Thus \(q=1,2,\ldots,251000\).

Step 5: Exclude integer roots

The roots \(u,v\) would be integers exactly when the discriminant \(1002^2-4q\) is a perfect square. Since it is divisible by \(4\), write it as \(4k^2\). Then \(q=251001-k^2\), with \(k=1,2,\ldots,500\), giving \(500\) excluded values.

Step 6: Count n values

Each valid \(q\) gives \(n=-1002q\), so the number of possible \(n\)-values is \[251000-500=250500.\] The answer is \(\boxed{250,500}\).

Key Idea

Use Vieta's formulas and exclude perfect-square discriminants.
