2023 AMC 12A Problem 22

2023AMC 12AProblem 22数论整数构造整数构造

Problem Statement

Let $f$ be the unique function defined on the positive integers such that \[\sum_{d\mid n}d\cdot f\left(\frac nd\right)=1\] for all positive integers $n$. What is $f(2023)$?

Choices

  1. A-1536
  2. B96
  3. C108
  4. D116
  5. E144

Answer

B. 96

Solution

Step 1: Interpret the divisor sum

The equation says that the function $f$ is the Dirichlet-convolution inverse of the function $g(n)=n$ against the constant function $1$.

Step 2: Find f on prime powers

For a prime $p$, the condition for $p^a$ is \[\sum_{i=0}^{a}p^i f(p^{a-i})=1.\] For $a=1$, this gives \[f(p)+p=1,\] so \[f(p)=1-p.\] The same recurrence gives \[f(p^a)=1-p\] for all $a\ge1$.

Step 3: Use multiplicativity

The convolution equation with multiplicative functions implies that $f$ is multiplicative. Thus we can evaluate $f$ from the prime factorization of $2023$.

Step 4: Factor 2023

We have \[2023=7\cdot17^2.\] Therefore \[f(2023)=f(7)f(17^2).\]

Step 5: Compute

Using $f(p^a)=1-p$, \[f(7)=1-7=-6,\quad f(17^2)=1-17=-16.\] Hence \[f(2023)=(-6)(-16)=96.\]

Step 6: Conclude

The answer is $\boxed{96}$.

Key Idea

Recognize a Dirichlet-convolution inverse and use prime factorization.
