Problem Statement

Arjun and Beth play a game in which they take turns removing one brick or two adjacent bricks from one wall among a set of several walls of bricks, with gaps possibly creating new walls. The walls are one brick tall. Arjun plays first, and the player who removes the last brick wins. For which starting configuration is there a strategy that guarantees a win for Beth?

Choices

  1. A$(6,1,1)$
  2. B$(6,2,1)$
  3. C$(6,2,2)$
  4. D$(6,3,1)$
  5. E$(6,3,2)$

Answer

B. $(6,2,1)$

Solution

Step 1: Turn each wall into a game value

This is an impartial game: both players have the same moves, and the last move wins. For one wall of length $n$, let $g(n)$ be its Sprague-Grundy value. A position with several walls has value equal to the xor of the wall values.

Step 2: Compute the small wall values

A move from a wall can remove one brick or two adjacent bricks, possibly splitting the wall into two smaller walls. Using mex values gives

\[ g(1)=1,\quad g(2)=2,\quad g(3)=3,\quad g(4)=1,\quad g(5)=4,\quad g(6)=3. \]

Step 3: Know what a zero xor means

A position is losing for the player to move exactly when the xor of all wall values is $0$. Since Arjun moves first, Beth has a guaranteed win precisely for the answer choice whose xor is $0$.

Step 4: Evaluate the answer choices

Using the values above,

\[ \begin{aligned} (6,1,1)&: 3\oplus1\oplus1=3,\\ (6,2,1)&: 3\oplus2\oplus1=0,\\ (6,2,2)&: 3\oplus2\oplus2=3,\\ (6,3,1)&: 3\oplus3\oplus1=1,\\ (6,3,2)&: 3\oplus3\oplus2=2. \end{aligned} \]

Step 5: Choose the losing position for Arjun

Only $(6,2,1)$ has xor $0$. That means Arjun starts in a losing position if both players play optimally, so Beth has a strategy that guarantees a win.

Key Idea

Use Sprague-Grundy values for single walls and xor the wall values.
