2014 AMC 12B Problem 20

2014AMC 12BProblem 20数论整数构造整数构造

Problem Statement

For how many positive integers $x$ is \[\log_{10}(x-40)+\log_{10}(60-x)<2?\]

Choices

  1. A10
  2. B18
  3. C19
  4. D20
  5. Einfinitely many

Answer

B. 18

Solution

Step 1: Find the domain first

The logarithms require \[x-40>0\quad\text{and}\quad60-x>0.\] So \[40<x<60.\] For positive integers, this means $x=41,42,\ldots,59$.

Step 2: Combine the logarithms

Using \[\log_{10}A+\log_{10}B=\log_{10}(AB),\] the inequality becomes \[\log_{10}((x-40)(60-x))<2.\]

Step 3: Remove the logarithm

Since base $10$ is greater than $1$, this is equivalent to \[(x-40)(60-x)<100.\]

Step 4: Substitute a centered variable

Let $y=x-40$. Then $y=1,2,\ldots,19$, and \[(x-40)(60-x)=y(20-y).\]

Step 5: Count the failures

The product is at least $100$ only when $y=10$, because \[10(10)=100\] and nearby values give less than $100$ or, for $y=9,11$, give $99$.

Step 6: Conclude

There are $19$ possible integers and one is excluded, so the answer is \[\boxed{18}.\]

Key Idea

Use logarithm rules and the integer domain restrictions.
