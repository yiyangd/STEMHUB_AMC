2019 AMC 12B Problem 13

2019AMC 12BProblem 13概率与统计独立性独立事件概率

Problem Statement

A red ball and a green ball are randomly and independently tossed into bins numbered with positive integers so that for each ball, the probability that it is tossed into bin $k$ is $2^{-k}$ for $k=1,2,3,\ldots$. What is the probability that the red ball is tossed into a higher-numbered bin than the green ball?

Choices

  1. A$\frac14$
  2. B$\frac27$
  3. C$\frac13$
  4. D$\frac38$
  5. E$\frac37$

Answer

C. \frac13

Solution

Step 1: Use symmetry between the two balls

The red and green balls have the same bin distribution and are tossed independently. Therefore the probability that red is in a higher-numbered bin equals the probability that green is in a higher-numbered bin.

Step 2: Remove the tie probability

The only remaining possibility is that the two balls land in the same bin. For a fixed bin $k$, this has probability \[(2^{-k})(2^{-k})=4^{-k}.\]

Step 3: Sum the tie probability

Thus \[P(\text{same bin})=\sum_{k=1}^{\infty}4^{-k}=\frac{1/4}{1-1/4}=\frac13.\]

Step 4: Split the non-tie probability

The probability of different bins is \[1-\frac13=\frac23.\] By symmetry, half of this has red higher than green.

Step 5: Conclude

The desired probability is \[\frac12\cdot\frac23=\frac13,\] so the answer is $\boxed{\frac13}$.

Key Idea

Use symmetry and subtract the probability that both balls land in the same bin.
