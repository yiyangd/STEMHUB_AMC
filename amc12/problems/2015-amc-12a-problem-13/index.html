2015 AMC 12A Problem 13

2015AMC 12AProblem 13组合数学排列组合排列组合计数

Problem Statement

A league with $12$ teams holds a round-robin tournament, with each team playing every other team once. Games either end with one team victorious or else end in a draw. A team scores $2$ points for every game it wins and $1$ point for every game it draws. Which of the following is not a true statement about the list of $12$ scores?

Choices

  1. AThere must be an even number of odd scores.
  2. BThere must be an even number of even scores.
  3. CThere cannot be two scores of $0$.
  4. DThe sum of the scores must be at least $100$.
  5. EThe highest score must be at least $12$.

Answer

E. The highest score must be at least 12.

Solution

Step 1: Find the total score

There are \[\binom{12}{2}=66\] games. Each game contributes $2$ total points, whether it is a win-loss game or a draw. Therefore the total score is \[132.\]

Step 2: Check parity statements

Because the total score is even, the number of odd team scores must be even. Since there are $12$ teams, the number of even scores is also even.

Step 3: Check the zero-score statement

Two teams cannot both have score $0$, because they play each other. In their mutual game, at least one of them receives points.

Step 4: Check the total-score statement

The total score is exactly $132$, so it is certainly at least $100$.

Step 5: Find the false statement

It is possible for every game to be a draw. Then each team scores $11$, so the highest score is $11$, not at least $12$.

Step 6: Conclude

The statement that is not always true is $\boxed{\text{E}}$.

Key Idea

Check which score-list properties are forced by total points and parity.
