2019 AMC 12A Problem 20

2019AMC 12AProblem 20概率与统计独立性独立事件概率

Problem Statement

Real numbers between \(0\) and \(1\), inclusive, are chosen as follows. A fair coin is flipped. If it lands heads, it is flipped again and the chosen number is \(0\) if the second flip is heads and \(1\) if the second flip is tails. If the first coin flip is tails, the number is chosen uniformly at random from \([0,1]\). Two random numbers \(x\) and \(y\) are chosen independently in this manner. What is the probability that \(|x-y|>\frac12\)?

Choices

  1. A$\frac13$
  2. B$\frac7{16}$
  3. C$\frac12$
  4. D$\frac9{16}$
  5. E$\frac23$

Answer

B. \frac7{16}

Solution

Step 1: Understand the distribution

Each chosen number has probability \(\frac14\) of being \(0\), probability \(\frac14\) of being \(1\), and probability \(\frac12\) of being uniformly distributed on \([0,1]\).

Step 2: Count atom-atom wins

If one number is \(0\) and the other is \(1\), then the difference is greater than \(\frac12\). This has probability \[2\cdot\frac14\cdot\frac14=\frac18.\]

Step 3: Count atom-continuous wins

If one number is an endpoint atom and the other is uniform, the uniform number must lie in the far half of the interval. Accounting for both endpoints and both orders gives \[4\cdot\frac14\cdot\frac12\cdot\frac12=\frac14.\]

Step 4: Count continuous-continuous wins

If both numbers are uniform, the probability that their distance is greater than \(\frac12\) is \(\frac14\). Since this case has probability \((\frac12)^2=\frac14\), it contributes \[\frac14\cdot\frac14=\frac1{16}.\]

Step 5: Add the cases

The total probability is \[\frac18+\frac14+\frac1{16}=\frac{2+4+1}{16}=\frac7{16}.\]

Step 6: Conclude

The answer is \(\boxed{\frac7{16}}\).

Key Idea

Break the mixed distribution into atom-atom, atom-continuous, and continuous-continuous cases.
