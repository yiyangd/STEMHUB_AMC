2012 AMC 12B Problem 12

2012AMC 12BProblem 12组合数学递推与序列计数递推序列

Problem Statement

How many sequences of zeros and ones of length $20$ have all the zeros consecutive, or all the ones consecutive, or both?

Choices

  1. A190
  2. B192
  3. C211
  4. D380
  5. E382

Answer

E. 382

Solution

Step 1: Count sequences with consecutive zeros

If there are $k$ zeros, where $1\le k\le20$, the block of zeros can start in $21-k$ positions. This gives \[\sum_{k=1}^{20}(21-k)=210\] sequences. Also include the all-ones sequence with $k=0$, so there are $211$ sequences with all zeros consecutive.

Step 2: Use symmetry for ones

Similarly, there are $211$ sequences with all ones consecutive.

Step 3: Count the overlap

Both zeros and ones are consecutive in the all-zero sequence, the all-one sequence, and the two-block sequences \[00\cdots011\cdots1\quad\text{or}\quad11\cdots100\cdots0.\] With both symbols present, there are $19$ split points for each order, so the overlap has \[2+2\cdot19=40\] sequences.

Step 4: Apply inclusion-exclusion

The required number is \[211+211-40=382.\]

Step 5: Conclude

The answer is $\boxed{382}$.

Key Idea

Use inclusion-exclusion on sequences with consecutive zeros or consecutive ones.
