2013 AMC 12B Problem 14

2013AMC 12BProblem 14组合数学递推与序列计数递推序列

Problem Statement

Two non-decreasing sequences of nonnegative integers have different first terms. Each sequence has the property that each term beginning with the third is the sum of the previous two terms, and the seventh term of each sequence is $N$. What is the smallest possible value of $N$?

Choices

  1. A55
  2. B89
  3. C104
  4. D144
  5. E273

Answer

C. 104

Solution

Step 1: Write the sequence from its first two terms

Let a sequence begin with $a,b$. Then the next terms are \[a+b,\quad a+2b,\quad 2a+3b,\quad 3a+5b,\quad 5a+8b.\] So the seventh term is \[N=5a+8b.\]

Step 2: Use non-decreasing condition

Since the sequence is non-decreasing and starts with nonnegative integers, we need \[0\le a\le b.\]

Step 3: Look for two different first terms

We need the same value of $5a+8b$ from two different values of $a$. Since \[5a+8b=N,\] changing $a$ by $8$ can be balanced by changing $b$ by $5$.

Step 4: Find the smallest possible pair

The smallest two different first terms are therefore $a=0$ and $a=8$. For $a=8$, the condition $a\le b$ forces $b\ge8$.

Step 5: Compute N

Taking $(a,b)=(8,8)$ gives \[N=5\cdot8+8\cdot8=104.\] The matching sequence with first term $0$ is $(0,13)$, since \[5\cdot0+8\cdot13=104.\]

Step 6: Conclude

The smallest possible value is $\boxed{104}$.

Key Idea

Write the seventh term as 5a+8b and find the smallest repeated value.
