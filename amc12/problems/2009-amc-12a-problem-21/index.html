2009 AMC 12A Problem 21

2009AMC 12AProblem 21代数复数复数平面

Problem Statement

Let \(p(x)=x^3+ax^2+bx+c\), where \(a\), \(b\), and \(c\) are complex numbers. Suppose that \[p(2009+9002\pi i)=p(2009)=p(9002)=0.\] What is the number of nonreal zeros of \[x^{12}+ax^8+bx^4+c?\]

Choices

  1. A4
  2. B6
  3. C8
  4. D10
  5. E12

Answer

C. 8

Solution

Step 1: Recognize the composition

The polynomial \[x^{12}+ax^8+bx^4+c\] is exactly \(p(x^4)\), because \(p(t)=t^3+at^2+bt+c\).

Step 2: Translate zeros

The zeros occur when \[x^4=2009+9002\pi i,\quad x^4=2009,\quad\text{or}\quad x^4=9002.\]

Step 3: Count roots from the nonreal value

The equation \(x^4=2009+9002\pi i\) has four fourth roots. Since the right side is nonreal, none of these four roots is real.

Step 4: Count roots from each positive real value

For \(x^4=2009\), there are two real roots and two nonreal roots. The same is true for \(x^4=9002\).

Step 5: Add nonreal roots

The total number of nonreal zeros is \[4+2+2=8.\]

Step 6: Conclude

The answer is \(\boxed{8}\).

Key Idea

Recognize the polynomial as \(p(x^4)\) and count nonreal fourth roots.
