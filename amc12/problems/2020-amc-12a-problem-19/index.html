2020 AMC 12A Problem 19

2020AMC 12AProblem 19数论整数构造整数构造

Problem Statement

There exists a unique strictly increasing sequence of nonnegative integers $a_1<a_2<\cdots<a_k$ such that \[\frac{2^{289}+1}{2^{17}+1}=2^{a_1}+2^{a_2}+\cdots+2^{a_k}.\] What is $k$?

Choices

  1. A117
  2. B136
  3. C137
  4. D273
  5. E306

Answer

C. 137

Solution

Step 1: Recognize that this is asking for binary ones

Writing a number as

\[2^{a_1}+2^{a_2}+\cdots+2^{a_k}\]

with strictly increasing exponents is exactly its binary expansion. So $k$ is the number of $1$'s in the binary representation of the fraction.

Step 2: Use the odd power factorization

Let $y=2^{17}$. Then $2^{289}=y^{17}$, and

\[\frac{2^{289}+1}{2^{17}+1}=\frac{y^{17}+1}{y+1}.\]

Because $17$ is odd,

\[\frac{y^{17}+1}{y+1}=y^{16}-y^{15}+y^{14}-\cdots-y+1.\]

Step 3: Pair the negative terms with the following positive terms

Rewrite the alternating sum as

\[1+(y^2-y)+(y^4-y^3)+\cdots+(y^{16}-y^{15}).\]

Each paired difference is

\[y^{2r}-y^{2r-1}=y^{2r-1}(y-1).\]

Step 4: Interpret each block in binary

Since $y=2^{17}$, we have

\[y-1=2^{17}-1,\]

which is a block of $17$ ones in binary. Multiplying by $y^{2r-1}=2^{17(2r-1)}$ shifts that block without changing the number of ones.

Step 5: Count the non-overlapping blocks

There are $8$ paired differences, and each contributes a block of $17$ ones. These blocks do not overlap because each shift is by multiples of $34$ positions.

The initial $1$ contributes one more binary one. Therefore

\[k=8\cdot17+1=137.\]

Key Idea

Use the factorization of an odd power sum and then count the ones in the binary representation.
