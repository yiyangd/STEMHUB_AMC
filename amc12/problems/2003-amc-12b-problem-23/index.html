2003 AMC 12B Problem 23

2003AMC 12BProblem 23代数三角恒等式三角函数恒等式

Problem Statement

The number of \(x\)-intercepts on the graph of \(y=\sin(1/x)\) in the interval \((0.0001,0.001)\) is closest to:

Choices

  1. A2900
  2. B3000
  3. C3100
  4. D3200
  5. E3300

Answer

A. 2900

Solution

Step 1: Find zeros of sine

The graph crosses the \(x\)-axis when \[\sin(1/x)=0,\] which occurs when \[1/x=k\pi\] for a positive integer \(k\).

Step 2: Convert the interval

The condition \(0.0001<x<0.001\) becomes \[1000<\frac1x<10000.\] Thus \[1000<k\pi<10000.\]

Step 3: Count k values approximately

This means \[\frac{1000}{\pi}<k<\frac{10000}{\pi}.\] Numerically, this is approximately \[318.3<k<3183.1.\]

Step 4: Count intercepts

So \(k=319,320,\ldots,3183\), giving about \(2865\) intercepts.

Step 5: Conclude

The closest choice is $\boxed{2900}$.

Key Idea

Solve sin(1/x)=0 by counting integer multiples of pi.
