2021 Spring AMC 12A Problem 18

2021 SpringAMC 12AProblem 18数论质因数与整除质因数整除

Problem Statement

Let $f$ be a function defined on the set of positive rational numbers with the property that $f(a\cdot b)=f(a)+f(b)$ for all positive rational numbers $a$ and $b$. Suppose also that $f(p)=p$ for every prime number $p$. For which of the following numbers $x$ is $f(x)<0$?

Choices

  1. A$\frac{17}{32}$
  2. B$\frac{11}{16}$
  3. C$\frac79$
  4. D$\frac76$
  5. E$\frac{25}{11}$

Answer

E. $\frac{25}{11}$

Solution

Step 1: Find what f does to 1 and reciprocals

Using the rule with $a=1$ gives

\[f(1\cdot b)=f(1)+f(b).\]

So $f(1)=0$. Then for any positive rational $q$,

\[f(q)+f(1/q)=f(1)=0,\]

which means $f(1/q)=-f(q)$.

Step 2: Extend the rule to prime powers

If $p$ is prime, then $f(p)=p$. Repeated multiplication gives

\[f(p^e)=ef(p)=ep.\]

For a rational number, prime factors in the numerator contribute positively, and prime factors in the denominator contribute negatively.

Step 3: Evaluate the first four answer choices

Now compute:

\[f\left(\frac{17}{32}\right)=17-5\cdot2=7,\] \[f\left(\frac{11}{16}\right)=11-4\cdot2=3,\] \[f\left(\frac79\right)=7-2\cdot3=1,\] \[f\left(\frac76\right)=7-2-3=2.\]

All four are positive.

Step 4: Evaluate the remaining choice

For the last choice,

\[\frac{25}{11}=\frac{5^2}{11}.\]

Therefore

\[f\left(\frac{25}{11}\right)=2\cdot5-11=-1.\]

Step 5: Choose the only negative value

The only answer choice for which $f(x)<0$ is

\[x=\frac{25}{11}.\]

So the answer is $\frac{25}{11}$.

Key Idea

Use the multiplicative-to-additive rule to evaluate f from prime factorizations.
