2011 AMC 12A Problem 19

2011AMC 12AProblem 19代数对数与指数对数指数

Problem Statement

At a competition with $N$ players, the number of players given elite status is equal to \[2^{1+\lfloor\log_2(N-1)\rfloor}-N.\] Suppose that $19$ players are given elite status. What is the sum of the two smallest possible values of $N$?

Choices

  1. A38
  2. B90
  3. C154
  4. D406
  5. E1024

Answer

C. 154

Solution

Step 1: Introduce the floor value

Let \[m=\lfloor\log_2(N-1)\rfloor.\] Then \[2^m\le N-1<2^{m+1}.\] The elite count equation becomes \[2^{m+1}-N=19,\] so \[N=2^{m+1}-19.\]

Step 2: Apply the floor condition

Substitute this expression for $N$: \[2^m\le 2^{m+1}-20<2^{m+1}.\] The right inequality is automatic, and the left inequality gives \[2^m\ge20.\]

Step 3: Find the two smallest m values

The smallest possible $m$ is $5$, then the next is $6$.

Step 4: Compute the corresponding N values

For $m=5$, \[N=2^6-19=64-19=45.\] For $m=6$, \[N=2^7-19=128-19=109.\]

Step 5: Add them

The sum of the two smallest possible values is \[45+109=154.\]

Step 6: Conclude

The answer is $\boxed{154}$.

Key Idea

Analyze the floor-log interval for N.
