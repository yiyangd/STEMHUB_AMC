2017 AMC 12B Problem 7

2017AMC 12BProblem 7代数三角恒等式三角函数恒等式

Problem Statement

The functions $\sin x$ and $\cos x$ are periodic with least period \(2\pi\). What is the least period of the function \(\cos(\sin x)\)?

Choices

  1. A$\frac{\pi}{2}$
  2. B$\pi$
  3. C$2\pi$
  4. D$4\pi$
  5. EIt is not periodic.

Answer

B. \pi

Solution

Step 1: Use the sine shift by pi

We know \[\sin(x+\pi)=-\sin x.\]

Step 2: Use cosine symmetry

Cosine is even, so \[\cos(-u)=\cos u.\] Therefore \[\cos(\sin(x+\pi))=\cos(-\sin x)=\cos(\sin x).\]

Step 3: Show pi is a period

The function repeats after adding \(\pi\), so \(\pi\) is a period.

Step 4: Check that a smaller listed period does not work

For example, adding \(\frac{\pi}{2}\) changes \(\sin x\) to \(\cos x\), and \(\cos(\cos x)\) is not always equal to \(\cos(\sin x)\).

Step 5: Conclude

The least period is \(\boxed{\pi}\).

Key Idea

Use the symmetry cos(-u)=cos(u) together with sin(x+pi)=-sin x.
