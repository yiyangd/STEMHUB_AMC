2004 AMC 12B Problem 25

2004AMC 12BProblem 25数论进制与数字数字进制

Problem Statement

Given that \(2^{2004}\) is a \(604\)-digit number whose first digit is \(1\), how many elements of the set \(S=\{2^0,2^1,2^2,\ldots,2^{2003}\}\) have a first digit of \(4\)?

Choices

  1. A194
  2. B195
  3. C196
  4. D197
  5. E198

Answer

B. 195

Solution

Step 1: Use digit-length blocks

Since \(2^{2004}\) is a \(604\)-digit number beginning with \(1\), the powers \(2^0,2^1,\ldots,2^{2003}\) cover digit lengths \(1\) through \(603\). For each digit length, the first power of \(2\) with that length begins with \(1\). Thus \(603\) elements begin with \(1\).

Step 2: Double leading digits

Doubling a number beginning with \(1\) produces a number beginning with \(2\) or \(3\). Doubling again produces a number beginning with \(4,5,6,\) or \(7\).

Step 3: Count three large groups

Therefore \(603\) elements begin with \(1\), \(603\) begin with \(2\) or \(3\), and \(603\) begin with \(4,5,6,\) or \(7\).

Step 4: Find the remaining group

The set has \(2004\) elements, so the number beginning with \(8\) or \(9\) is \[2004-3\cdot603=195.\]

Step 5: Relate 4 to 8 or 9

A power of \(2\) begins with \(4\) exactly when the next power begins with \(8\) or \(9\). This pairing stays inside the given range.

Step 6: Conclude

Thus \(195\) elements begin with \(4\), so the answer is \(\boxed{195}\).

Key Idea

Group powers of two by leading digit after successive doublings.
