2015 AMC 12A Problem 19

2015AMC 12AProblem 19几何面积与相似面积比例

Problem Statement

For some positive integers $p$, there is a quadrilateral $ABCD$ with positive integer side lengths, perimeter $p$, right angles at $B$ and $C$, $AB=2$, and $CD=AD$. How many different values of $p<2015$ are possible?

Choices

  1. A30
  2. B31
  3. C61
  4. D62
  5. E63

Answer

B. 31

Solution

Step 1: Set up coordinates

Place \[B=(0,0),\quad C=(u,0),\quad A=(0,2).\] Because the angle at $C$ is right, let \[D=(u,v).\] Then $BC=u$ and $CD=v$.

Step 2: Use CD equals AD

The condition $CD=AD$ gives \[v^2=u^2+(v-2)^2.\] Expanding and simplifying, \[v^2=u^2+v^2-4v+4,\] so \[u^2=4(v-1).\]

Step 3: Parameterize integer solutions

Since $u$ is an integer, write $u=2t$. Then \[4t^2=4(v-1),\] so \[v=t^2+1.\]

Step 4: Write the perimeter

The perimeter is \[p=AB+BC+CD+AD=2+u+v+v.\] Substituting gives \[p=2+2t+2(t^2+1)=2t^2+2t+4.\]

Step 5: Count valid t

We need \[2t^2+2t+4<2015.\] Testing the boundary, $t=31$ gives $p=1988$, while $t=32$ gives $p=2116$. Thus $t=1,2,\ldots,31$ are possible.

Step 6: Conclude

There are $\boxed{31}$ possible values of $p$.

Key Idea

Use coordinates for the right-angle quadrilateral and parameterize integer side lengths.
