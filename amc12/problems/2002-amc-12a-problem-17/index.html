2002 AMC 12A Problem 17

2002AMC 12AProblem 17数论进制与数字数字进制

Problem Statement

Several sets of prime numbers, such as $\{7,83,421,659\}$, use each of the nine nonzero digits exactly once. What is the smallest possible sum such a set of primes could have?

Choices

  1. A193
  2. B207
  3. C225
  4. D252
  5. E447

Answer

B. 207

Solution

Step 1: Use small single-digit primes

To keep the sum small, it is helpful to use small one-digit primes when possible. The digits \(2,3,5\) can each stand alone as primes.

Step 2: Find a strong construction

Using the remaining digits \(1,4,6,7,8,9\), one low-sum prime grouping is \[41,\ 67,\ 89.\] Together with \(2,3,5\), the set is \[\{2,3,5,41,67,89\}.\]

Step 3: Compute its sum

The sum is \[2+3+5+41+67+89=207.\]

Step 4: Explain minimality

A case check by the number of one-digit primes shows that any arrangement below $207$ would need even smaller two-digit primes from the remaining digits, but the digit and prime-ending restrictions prevent this. In particular, the last digit of any multi-digit prime cannot be even or $5$.

Step 5: Conclude

The smallest possible sum is $\boxed{207}$.

Key Idea

Partition digits into primes and minimize place-value contribution.
