2017 AMC 12A Problem 20

2017AMC 12AProblem 20数论整数构造整数构造

Problem Statement

How many ordered pairs $(a,b)$ such that $a$ is a positive real number and $b$ is an integer between $2$ and $200$, inclusive, satisfy the equation \[(\log_b a)^{2017}=\log_b(a^{2017})?\]

Choices

  1. A198
  2. B199
  3. C398
  4. D399
  5. E597

Answer

E. 597

Solution

Step 1: Substitute one variable

Let \[x=\log_b a.\] Then \(\log_b(a^{2017})=2017\log_b a=2017x\).

Step 2: Solve the equation in x

The equation becomes \[x^{2017}=2017x,\] or \[x(x^{2016}-2017)=0.\]

Step 3: Count possible x values

There are three real solutions: \[x=0,\quad x=2017^{1/2016},\quad x=-2017^{1/2016}.\]

Step 4: Convert back to a

For each allowed integer base \(b\), each real value of \(x\) gives exactly one positive value \(a=b^x\).

Step 5: Count bases

The integer \(b\) can be any value from $2$ through $200$, inclusive, giving \(199\) choices. With $3$ choices of \(x\) for each base, the total is \[3\cdot199=597.\]

Step 6: Conclude

The answer is $\boxed{597}$.

Key Idea

Let x equal log base b of a and solve the resulting power equation.
