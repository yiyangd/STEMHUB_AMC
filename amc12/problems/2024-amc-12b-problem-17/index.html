2024 AMC 12B Problem 17

2024AMC 12BProblem 17概率与统计代数概率多项式根整数根概率计数

Problem Statement

Integers $a$ and $b$ are randomly chosen without replacement from the set of integers with absolute value not exceeding $10$. What is the probability that the polynomial $x^3+ax^2+bx+6$ has $3$ distinct integer roots?

Choices

  1. A$\frac1{240}$
  2. B$\frac1{221}$
  3. C$\frac1{105}$
  4. D$\frac1{84}$
  5. E$\frac1{63}$

Answer

C. $\frac1{105}$

Solution

Step 1: Translate integer roots into coefficients

If the roots are distinct integers $r,s,t$, then

\[x^3+ax^2+bx+6=(x-r)(x-s)(x-t).\]

The constant term gives

\[-rst=6,\]

so $rst=-6$.

Step 2: List the possible distinct root sets

The unordered distinct integer triples with product $-6$ are

\[\{-1,1,6\},\quad \{-1,2,3\},\quad \{1,-2,3\},\quad \{1,2,-3\}.\]

These are the only distinct ways to use integer factors of $6$.

Step 3: Convert each root set to an ordered pair (a,b)

For roots $r,s,t$, we have

\[a=-(r+s+t),\qquad b=rs+rt+st.\]

The four root sets produce four valid pairs $(a,b)$ in the allowed range from $-10$ to $10$, and in each pair $a\ne b$.

Step 4: Count all possible choices of a and b

The set of possible integers has $21$ elements, from $-10$ to $10$. Since $a$ and $b$ are chosen without replacement and in order, there are

\[21\cdot20=420\]

possible outcomes.

Step 5: Compute the probability

There are $4$ favorable outcomes, so the probability is

\[\frac4{420}=\frac1{105}.\]

Thus the answer is $\frac1{105}$.

Key Idea

Enumerate distinct integer root triples whose product is -6, then translate them into coefficient pairs.
