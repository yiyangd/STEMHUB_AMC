2017 AMC 12A Problem 21

2017AMC 12AProblem 21数论整数构造整数构造

Problem Statement

A set $S$ is constructed as follows. To begin, $S=\{0,10\}$. Repeatedly, as long as possible, if $x$ is an integer root of some polynomial \[a_nx^n+a_{n-1}x^{n-1}+\cdots+a_1x+a_0\] for some $n\ge1$, all of whose coefficients $a_i$ are elements of $S$, then $x$ is put into $S$. When no more elements can be added to $S$, how many elements does $S$ have?

Choices

  1. A4
  2. B5
  3. C7
  4. D9
  5. E11

Answer

D. 9

Solution

Step 1: Start with a guaranteed new root

Using coefficients from \(S=\{0,10\}\), the polynomial \(10x+10\) is allowed. Its integer root is \(-1\), so \(-1\) must be added to \(S\).

Step 2: Use the rational root theorem

Any nonzero integer root of a polynomial with integer coefficients must divide the constant term. Since all constant terms must come from the current set \(S\), possible new roots are restricted to divisors of elements already in \(S\).

Step 3: Generate more roots

With \(-1\) available, the polynomial \[-x^4-x^3-x^2-x+10\] has root \(-2\), and \[-x^3-x+10\] has root \(2\). Thus \(-2\) and \(2\) enter the set.

Step 4: Generate divisors of 10

Now coefficients \(-2\) and \(2\) are available. The polynomials \(2x+10\), \(2x-2\), and \(-2x+10\) give roots \(-5\), \(1\), and \(5\), respectively.

Step 5: Add the last possible divisor

With \(1\) available, the polynomial \(x+10\) gives root \(-10\). At this point the set contains \[\{-10,-5,-2,-1,0,1,2,5,10\}.\]

Step 6: Show the process stops

The nonzero elements now all divide \(10\). Any future integer root must divide one of these possible constant terms, so it must already be in the displayed set.

Step 7: Conclude

The final set has \(\boxed{9}\) elements.

Key Idea

Use the rational root theorem and construct the closure step by step.
