2014 AMC 12A Problem 24

2014AMC 12AProblem 24代数运算与化简代数化简

Problem Statement

Let $f_0(x)=x+|x-100|-|x+100|$, and for $n\ge1$, let \[f_n(x)=|f_{n-1}(x)|-1.\] For how many values of $x$ is $f_{100}(x)=0$?

Choices

  1. A299
  2. B300
  3. C301
  4. D302
  5. E303

Answer

C. 301

Solution

Step 1: Separate the two layers of the problem

The function $f_0$ first turns $x$ into some value $y$. After that, every step applies the same rule

\[g(y)=|y|-1.\]

So the problem becomes: which starting values $y=f_0(x)$ satisfy $g^{100}(y)=0$, and how many $x$ values produce those $y$ values?

Step 2: Work backward from 0 through the repeated rule

If $g(y)=a$, then

\[|y|-1=a,\]

so

\[|y|=a+1.\]

This has solutions $y=\pm(a+1)$ whenever $a\ge -1$. Starting from $0$ and working backward repeatedly produces a clear pattern: after $100$ steps, the possible starting values are

\[-100,-98,-96,\ldots,96,98,100.\]

There are $101$ such values.

Step 3: Understand how many x-values give one y-value

Now analyze

\[f_0(x)=x+|x-100|-|x+100|.\]

Break the real line at $x=-100$ and $x=100$. This gives

\[f_0(x)=\begin{cases}x+200,&x<-100,\\-x,&-100\le x<100,\\x-200,&x\ge100.\end{cases}\]

This piecewise form lets us count preimages without drawing a complicated graph.

Step 4: Count preimages for interior and endpoint y-values

For $-100<y<100$, each of the three pieces can produce that $y$, so there are $3$ corresponding values of $x$. For $y=100$ and $y=-100$, only two pieces produce the value because of the endpoint conditions.

Step 5: Finish the count

Among the $101$ possible $y$-values, the two endpoint values $-100$ and $100$ each have $2$ preimages. The remaining $99$ values each have $3$ preimages. Therefore the number of solutions is

\[2+2+99\cdot3=301.\]

The answer is $301$.

Key Idea

Work backward through the map $y\mapsto |y|-1$, then count how many $x$ values give each starting value under $f_0$.
