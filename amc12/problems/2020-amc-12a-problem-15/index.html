2020 AMC 12A Problem 15

2020AMC 12AProblem 15代数三角恒等式三角函数恒等式

Problem Statement

In the complex plane, let $A$ be the set of solutions to $z^3-8=0$ and let $B$ be the set of solutions to $z^3-8z^2-8z+64=0$. What is the greatest distance between a point of $A$ and a point of $B$?

Choices

  1. A$2\sqrt3$
  2. B6
  3. C9
  4. D$2\sqrt{21}$
  5. E$9+\sqrt3$

Answer

D. 2\sqrt{21}

Solution

Step 1: Find the first root set

The equation $z^3-8=0$ gives the cube roots of $8$. These are \[2,\quad -1+i\sqrt3,\quad -1-i\sqrt3.\]

Step 2: Factor the second polynomial

Group the terms: \[z^3-8z^2-8z+64=z^2(z-8)-8(z-8)=(z-8)(z^2-8).\] So the second root set is \[8,\quad 2\sqrt2,\quad -2\sqrt2.\]

Step 3: Look for the farthest pair

The point $8$ is farthest to the right. The farthest points in the first set from it are \[-1\pm i\sqrt3.\]

Step 4: Compute the distance

The distance from $8$ to $-1+i\sqrt3$ is \[\sqrt{(8-(-1))^2+(0-\sqrt3)^2}=\sqrt{81+3}=\sqrt{84}=2\sqrt{21}.\]

Step 5: Conclude

The greatest distance is $\boxed{2\sqrt{21}}$.

Key Idea

Find both root sets in the complex plane and maximize pairwise distance.
