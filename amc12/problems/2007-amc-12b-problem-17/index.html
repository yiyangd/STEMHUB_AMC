2007 AMC 12B Problem 17

2007AMC 12BProblem 17概率与统计平均数与数据集平均数数据

Problem Statement

If \(a\) is a nonzero integer and \(b\) is a positive number such that \(ab^2=\log_{10}b\), what is the median of the set \(\{0,1,a,b,1/b\}\)?

Choices

  1. A0
  2. B1
  3. C\(a\)
  4. D\(b\)
  5. E\(\frac1b\)

Answer

D. b

Solution

Step 1: First rule out b=1

If \(b=1\), then \(\log_{10}b=0\), so \(ab^2=0\), forcing \(a=0\). That is not allowed, so \(b\ne1\).

Step 2: Show b cannot be greater than 1

If \(b>1\), then \(\log_{10}b>0\), so \(a>0\). But for \(b>1\), we have \(0<\log_{10}b<b^2\), so \[0<a=\frac{\log_{10}b}{b^2}<1,\] impossible for a positive integer.

Step 3: Determine the sign and size

Therefore \(0<b<1\). Then \(\log_{10}b<0\), so \(a<0\). Also, because \(0<b<1\), we have \(1/b>1\).

Step 4: Order the five numbers

The set can be ordered as \[a<0<b<1<\frac1b.\]

Step 5: Find the median

The middle number in this ordered list is \(b\).

Step 6: Conclude

The median is \(\boxed{b}\).

Key Idea

Determine the order of \(a,0,b,1,1/b\) from the logarithmic equation.
