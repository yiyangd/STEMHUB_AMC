2024 AMC 12A Problem 11

2024AMC 12AProblem 11数论进制进制表示同余计数

Problem Statement

There are exactly $K$ positive integers $b$ with $5 \le b \le 2024$ such that the base-$b$ integer $2024_b$ is divisible by $16$. What is the sum of the digits of $K$?

Choices

  1. A16
  2. B17
  3. C18
  4. D20
  5. E21

Answer

D. 20

Solution

Step 1: Translate the base notation into ordinary algebra

The notation $2024_b$ means the digits $2,0,2,4$ are written in base $b$. So the actual value is

\[2b^3+0b^2+2b+4.\]

Because the problem asks for divisibility by $16$, we want this expression to be congruent to $0$ modulo $16$.

Step 2: Simplify the divisibility condition

The expression is $2b^3+2b+4=2(b^3+b+2)$. For this to be divisible by $16$, the factor $b^3+b+2$ must be divisible by $8$.

Thus we need

\[b^3+b+2\equiv 0\pmod 8.\]

This is a good place to switch from huge values of $b$ to residues modulo $8$.

Step 3: Find the valid residue classes

Testing $b\equiv 0,1,2,\ldots,7\pmod 8$ gives the valid residues $3$, $6$, and $7$. That means every complete block of eight possible values of $b$ contributes three working values.

This residue approach avoids checking hundreds of bases individually.

Step 4: Count carefully in the requested interval

The interval $1\le b\le 2024$ contains $253$ complete blocks of eight, because $2024=8\cdot253$. That would give $3\cdot253=759$ valid bases from $1$ through $2024$.

But the problem starts at $b=5$, so the valid base $b=3$ must be removed. Therefore $K=758$.

Step 5: Finish with the requested digit sum

The problem does not ask for $K$ itself; it asks for the sum of its digits. Since

\[7+5+8=20,\]

the answer is $20$.

Key Idea

Translate the base-b number into a polynomial in b, then count valid residue classes modulo 8.
