2011 AMC 12B Problem 13

2011AMC 12BProblem 13数论整数构造整数构造

Problem Statement

Brian writes down four integers $w>x>y>z$ whose sum is $44$. The pairwise positive differences of these numbers are $1,3,4,5,6,$ and $9$. What is the sum of the possible values for $w$?

Choices

  1. A16
  2. B31
  3. C48
  4. D62
  5. E93

Answer

B. 31

Solution

Step 1: Use the largest difference

The largest pairwise difference must be \[w-z=9.\] Let \[y=z+p,\quad x=z+q,\quad w=z+9,\] where $0<p<q<9$.

Step 2: Translate the six differences

The six pairwise differences are \[p,\ q,\ 9,\ q-p,\ 9-p,\ 9-q.\] These must equal the set \[\{1,3,4,5,6,9\}.\]

Step 3: Find possible gap pairs

Checking the possible values from the set, the only pairs $(p,q)$ that work are \[(3,4)\quad\text{and}\quad(5,6).\]

Step 4: Use the sum condition

If $(p,q)=(3,4)$, then \[z+(z+3)+(z+4)+(z+9)=44,\] so $4z+16=44$ and $z=7$. This gives $w=16$.

Step 5: Use the second gap pair

If $(p,q)=(5,6)$, then \[4z+20=44,\] so $z=6$. This gives $w=15$.

Step 6: Add possible w values

The possible values of $w$ are $16$ and $15$, whose sum is \[16+15=31.\] The answer is $\boxed{31}$.

Key Idea

Represent the four numbers by their gaps and match the six pairwise differences.
