2005 AMC 12B Problem 23

2005AMC 12BProblem 23代数对数与指数对数指数

Problem Statement

Let \(S\) be the set of ordered triples \((x,y,z)\) of real numbers for which \(\log_{10}(x+y)=z\) and \(\log_{10}(x^2+y^2)=z+1\). There are real numbers \(a\) and \(b\) such that for all ordered triples \((x,y,z)\) in \(S\) we have \(x^3+y^3=a\cdot10^{3z}+b\cdot10^{2z}\). What is the value of \(a+b\)?

Choices

  1. A\(\frac{15}{2}\)
  2. B\(\frac{29}{2}\)
  3. C15
  4. D\(\frac{39}{2}\)
  5. E24

Answer

B. \frac{29}{2}

Solution

Step 1: Set a simpler variable

Let \(S_1=x+y\). From \(\log_{10}(x+y)=z\), we have \(S_1=10^z\).

Step 2: Use the second equation

The equation \(\log_{10}(x^2+y^2)=z+1\) gives \[x^2+y^2=10^{z+1}=10\cdot10^z=10S_1.\]

Step 3: Find xy

Since \((x+y)^2=x^2+y^2+2xy\), \[xy=\frac{S_1^2-10S_1}{2}.\]

Step 4: Use the cube identity

\[x^3+y^3=(x+y)(x^2-xy+y^2)=S_1\big((x^2+y^2)-xy\big).\]

Step 5: Substitute

This equals \[S_1\left(10S_1-\frac{S_1^2-10S_1}{2}\right)=15S_1^2-\frac12S_1^3.\] With \(S_1=10^z\), this is \[-\frac12\cdot10^{3z}+15\cdot10^{2z}.\]

Step 6: Conclude

Thus \(a=-\frac12\), \(b=15\), and \(a+b=\boxed{\frac{29}{2}}\).

Key Idea

Use \(x+y\), \(x^2+y^2\), and \(x^3+y^3\) identities.
