2014 AMC 12A Problem 25

2014AMC 12AProblem 25几何三角形三角形角度

Problem Statement

The parabola $\mathcal P$ has focus $(0,0)$ and goes through the points $(4,3)$ and $(-4,-3)$. For how many points $(x,y)\in\mathcal P$ with integer coordinates is it true that \[|4x+3y|\le1000?\]

Choices

  1. A38
  2. B40
  3. C42
  4. D44
  5. E46

Answer

B. 40

Solution

Step 1: Find the direction of the directrix

The points $(4,3)$ and $(-4,-3)$ are both distance $5$ from the focus $(0,0)$. Since both lie on the parabola, each must also be distance $5$ from the directrix. This forces the directrix to be parallel to the line through those two points, so a useful perpendicular coordinate is

\[3x-4y.\]

Step 2: Write the parabola equation

One valid directrix is

\[3x-4y=25.\]

Using the focus-directrix definition,

\[\sqrt{x^2+y^2}=\frac{|3x-4y-25|}{5}.\]

Squaring and simplifying gives

\[(4x+3y)^2+50(3x-4y)-625=0.\]

Step 3: Introduce the key integer parameter

Let

\[w=4x+3y.\]

The condition in the problem is $|w|\le1000$. From the parabola equation,

\[3x-4y=\frac{625-w^2}{50}.\]

Since $x$ and $y$ are integers, $w$ is an integer, and this expression must be compatible with integer $x,y$.

Step 4: Reduce to a congruence

Write $w=5r$. Then

\[3x-4y=\frac{25-r^2}{2}.\]

Solving the two linear equations for $x$ and $y$ shows that $x$ and $y$ are integers exactly when

\[r\equiv5\pmod{10}.\]

Step 5: Count the possible r-values

The inequality $|w|\le1000$ becomes

\[|5r|\le1000,\]

so $|r|\le200$. The integers $r$ satisfying $r\equiv5\pmod{10}$ in this range are

\[-195,-185,\ldots,185,195.\]

There are $40$ such values. Hence there are $40$ integer-coordinate points.

Key Idea

Rotate coordinates using $4x+3y$ and $3x-4y$, then count a simple congruence.
