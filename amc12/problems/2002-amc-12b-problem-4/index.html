2002 AMC 12B Problem 4

2002AMC 12BProblem 4数论整数构造整数构造

Problem Statement

Let \(n\) be a positive integer such that \[\frac12+\frac13+\frac17+\frac1n\] is an integer. Which of the following statements is not true?

Choices

  1. A2 divides \(n\)
  2. B3 divides \(n\)
  3. C6 divides \(n\)
  4. D7 divides \(n\)
  5. E\(n>84\)

Answer

E. n>84

Solution

Step 1: Add the fixed fractions

First, \[\frac12+\frac13+\frac17=\frac{21+14+6}{42}=\frac{41}{42}.\]

Step 2: Force the total to be an integer

Since \(\frac{41}{42}<1\) and \(\frac1n>0\), the only possible integer value is \(1\). Therefore \[\frac{41}{42}+\frac1n=1.\]

Step 3: Solve for n

This gives \[\frac1n=\frac1{42},\] so \(n=42\).

Step 4: Check the statements

The number \(42\) is divisible by \(2\), \(3\), \(6\), and \(7\), but \(42>84\) is false.

Step 5: Conclude

The statement that is not true is $\boxed{n>84}$.

Key Idea

Solve the unit-fraction integrality condition.
