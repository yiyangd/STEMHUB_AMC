2024 AMC 12B Problem 14

2024AMC 12BProblem 14数论整除与同余模运算幂剩余125

Problem Statement

How many different remainders can result when the $100$th power of an integer is divided by $125$?

Choices

  1. A1
  2. B2
  3. C5
  4. D25
  5. E125

Answer

B. 2

Solution

Step 1: Separate integers by divisibility by 5

We are interested in $n^{100}\pmod{125}$. If $5\mid n$, then $n^{100}$ contains a very large power of $5$, so

\[n^{100}\equiv0\pmod{125}.\]

This gives one possible remainder.

Step 2: Handle integers relatively prime to 5

If $5\nmid n$, then $n$ is a unit modulo $125$. Euler's theorem applies because

\[\varphi(125)=125-25=100.\]

Thus

\[n^{100}\equiv1\pmod{125}.\]

Step 3: Check that no other cases exist

Every integer is either divisible by $5$ or relatively prime to $5$. So the only possible remainders are $0$ and $1$.

Step 4: Count the remainders

There are exactly $2$ different remainders. Therefore the answer is $2$.

Key Idea

Separate integers divisible by 5 from units modulo 125 and use Euler's theorem.
