2015AMC 12BProblem 13几何圆与曲线圆曲线

Problem Statement

Quadrilateral $ABCD$ is inscribed inside a circle with $\angle BAC=70^\circ$, $\angle ADB=40^\circ$, $AD=4$, and $BC=6$. What is $AC$?

Choices

  1. A$3+\sqrt5$
  2. B6
  3. C$9\sqrt2$
  4. D$8-\sqrt2$
  5. E$7\sqrt2$

Answer

B. 6

Solution

Step 1: Use the inscribed angle theorem

The angle $\angle ADB=40^\circ$ intercepts arc $AB$, so the minor arc $AB$ has measure $80^\circ$.

Step 2: Transfer the arc to another angle

The angle $\angle ACB$ intercepts the same arc $AB$, so \[\angle ACB=40^\circ.\]

Step 3: Find the angles in triangle ABC

In $\triangle ABC$, we are given \[\angle BAC=70^\circ,\] and we found \[\angle ACB=40^\circ.\] Therefore \[\angle ABC=70^\circ.\]

Step 4: Use equal angles

Since \[\angle A=\angle B=70^\circ,\] the opposite sides are equal: \[BC=AC.\]

Step 5: Use the given length

Because $BC=6$, we get \[AC=6.\]

Step 6: Conclude

The answer is $\boxed{6}$.

Key Idea

Use inscribed-angle relationships to identify an isosceles triangle.
