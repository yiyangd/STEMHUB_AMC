Problem Statement

Under what conditions is \[\sqrt{a^2+b^2}=a+b\] true, where $a$ and $b$ are real numbers?

Choices

  1. AIt is never true.
  2. BIt is true if and only if $ab=0$.
  3. CIt is true if and only if $a+b\ge0$.
  4. DIt is true if and only if $ab=0$ and $a+b\ge0$.
  5. EIt is always true.

Answer

D. ab=0 and a+b\ge0

Solution

Step 1: Start with the sign condition

The left side $\sqrt{a^2+b^2}$ is always nonnegative, so we must have \[a+b\ge0.\]

Step 2: Square both sides

If $a+b\ge0$, then squaring is reversible. We get \[a^2+b^2=(a+b)^2=a^2+2ab+b^2.\]

Step 3: Simplify

The equality becomes \[2ab=0,\] so \[ab=0.\]

Step 4: Combine conditions

Both conditions are needed: \[ab=0\quad\text{and}\quad a+b\ge0.\]

Step 5: Conclude

The answer is $\boxed{\text{D}}$.

Key Idea

Square both sides while preserving the nonnegative condition.
