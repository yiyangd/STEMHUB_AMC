2024 AMC 12B Problem 6

2024AMC 12BProblem 6数论进制进制位数对数数量级

Problem Statement

The national debt of the United States is on track to reach $5\cdot10^{13}$ dollars by 2033. How many digits does this number have when written as a numeral in base $5$? Use $\log_{10}5\approx0.7$.

Choices

  1. A18
  2. B20
  3. C22
  4. D24
  5. E26

Answer

B. 20

Solution

Step 1: Recall how base digits are counted

A positive integer $N$ has

\[\lfloor\log_b N\rfloor+1\]

digits when written in base $b$. Here $N=5\cdot10^{13}$ and $b=5$.

Step 2: Compute the common logarithm of the number

Using the given approximation,

\[\log_{10}(5\cdot10^{13})=\log_{10}5+13\approx0.7+13=13.7.\]

Step 3: Change from base 10 to base 5

By change of base,

\[\log_5(5\cdot10^{13})=\frac{\log_{10}(5\cdot10^{13})}{\log_{10}5}\approx\frac{13.7}{0.7}.\]

This is approximately $19.57$.

Step 4: Convert the logarithm into a digit count

Since the logarithm is between $19$ and $20$, the number has

\[\lfloor19.57\rfloor+1=20\]

digits in base $5$.

Key Idea

Use the base-b digit count formula with logarithms.
