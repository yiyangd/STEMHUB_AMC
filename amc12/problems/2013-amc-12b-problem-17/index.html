Problem Statement

Let $a,b,$ and $c$ be real numbers such that \[a+b+c=2,\qquad a^2+b^2+c^2=12.\] What is the difference between the maximum and minimum possible values of $c$?

Choices

  1. A2
  2. B$\frac{10}{3}$
  3. C4
  4. D$\frac{16}{3}$
  5. E$\frac{20}{3}$

Answer

D. \frac{16}{3}

Solution

Step 1: Separate c from a and b

From $a+b+c=2$, we have \[a+b=2-c.\] Also \[a^2+b^2=12-c^2.\]

Step 2: Use the minimum square sum for a fixed sum

For real $a$ and $b$ with fixed sum $s$, the smallest possible value of $a^2+b^2$ is \[\frac{s^2}{2},\] occurring when $a=b=s/2$.

Step 3: Require real a and b

Thus we need \[12-c^2\ge \frac{(2-c)^2}{2}.\]

Step 4: Solve the inequality

Multiply by $2$: \[24-2c^2\ge c^2-4c+4.\] This becomes \[3c^2-4c-20\le0.\] The roots are \[-2\quad\text{and}\quad\frac{10}{3}.\]

Step 5: Find the range

So $c$ can range from $-2$ to $\frac{10}{3}$. The difference between the maximum and minimum is \[\frac{10}{3}-(-2)=\frac{16}{3}.\]

Step 6: Conclude

The answer is \[\boxed{\frac{16}{3}}.\]

Key Idea

Reduce the problem to the range of c using the minimum possible value of a^2+b^2 for a fixed sum.
