2019 AMC 12A Problem 3

2019AMC 12AProblem 3组合数学染色与构造染色构造

Problem Statement

A box contains \(28\) red balls, \(20\) green balls, \(19\) yellow balls, \(13\) blue balls, \(11\) white balls, and \(9\) black balls. What is the minimum number of balls that must be drawn without replacement to guarantee that at least \(15\) balls of a single color will be drawn?

Choices

  1. A75
  2. B76
  3. C79
  4. D84
  5. E91

Answer

B. 76

Solution

Step 1: Avoid reaching 15 as long as possible

To delay getting \(15\) balls of one color, we can draw at most \(14\) balls of any color that has at least \(15\) balls available.

Step 2: Apply this to each color

For red, green, and yellow, we can draw \(14\) each without reaching \(15\). For blue, white, and black, we can draw all of them: \(13\), \(11\), and \(9\).

Step 3: Find the largest safe number

The maximum number of balls that can be drawn without guaranteeing \(15\) of one color is \[14+14+14+13+11+9=75.\]

Step 4: Add one more draw

Therefore the next draw, the \(76\)th, guarantees at least \(15\) balls of some color.

Step 5: Conclude

The minimum guaranteed number is \(\boxed{76}\).

Key Idea

Use the pigeonhole principle with the largest safe draw count.
