2015 AMC 12A Problem 14

2015AMC 12AProblem 14代数对数与指数对数指数

Problem Statement

What is the value of $a$ for which \[\frac1{\log_2 a}+\frac1{\log_3 a}+\frac1{\log_4 a}=1?\]

Choices

  1. A9
  2. B12
  3. C18
  4. D24
  5. E36

Answer

D. 24

Solution

Step 1: Use reciprocal logarithms

The identity \[\frac1{\log_b a}=\log_a b\] changes the equation into \[\log_a2+\log_a3+\log_a4=1.\]

Step 2: Combine logs

The left side becomes \[\log_a(2\cdot3\cdot4)=\log_a24.\]

Step 3: Solve

So \[\log_a24=1,\] which means \[a=24.\]

Step 4: Conclude

The answer is $\boxed{24}$.

Key Idea

Use reciprocal logarithm identities.
