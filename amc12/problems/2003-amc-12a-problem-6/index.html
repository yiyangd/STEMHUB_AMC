2003 AMC 12A Problem 6

2003AMC 12AProblem 6代数运算与化简代数化简

Problem Statement

Define \(x\heartsuit y\) to be \(|x-y|\) for all real numbers \(x\) and \(y\). Which of the following statements is not true?

Choices

  1. A\(x\heartsuit y=y\heartsuit x\) for all \(x,y\)
  2. B\(2(x\heartsuit y)=(2x)\heartsuit(2y)\) for all \(x,y\)
  3. C\(x\heartsuit0=x\) for all \(x\)
  4. D\(x\heartsuit x=0\) for all \(x\)
  5. E\(x\heartsuit y>0\) if \(x\ne y\)

Answer

C. x\heartsuit0=x

Solution

Step 1: Check the true statements

The operation \(x\heartsuit y=|x-y|\) is symmetric, so statement A is true. Scaling both inputs by \(2\) doubles the absolute difference, so B is true.

Step 2: Check the zero statement

Statement C says \(x\heartsuit0=x\), but \(x\heartsuit0=|x|\). This equals \(x\) only when \(x\ge0\).

Step 3: Use a counterexample

For example, if \(x=-1\), then \[-1\heartsuit0=|-1|=1\ne -1.\]

Step 4: Confirm the rest

Statement D is true because \(|x-x|=0\), and E is true because \(|x-y|>0\) when \(x\ne y\).

Step 5: Conclude

The statement that is not true is $\boxed{x\heartsuit0=x}$.

Key Idea

Test the absolute-value operation on negative inputs.
