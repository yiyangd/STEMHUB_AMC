2018 AMC 12A Problem 12

2018AMC 12AProblem 12数论整数构造整数构造

Problem Statement

Let $S$ be a set of $6$ integers taken from \(\{1,2,\ldots,12\}\) with the property that if \(a\) and \(b\) are elements of \(S\) with \(a<b\), then \(b\) is not a multiple of \(a\). What is the least possible value of an element in \(S\)?

Choices

  1. A2
  2. B3
  3. C4
  4. D5
  5. E7

Answer

C. 4

Solution

Step 1: Try to make the minimum small

If the set contained \(1\), then every larger positive integer would be a multiple of \(1\), so the set could not have six elements. If it contained \(2\), then it could not contain \(4,6,8,10,12\), leaving too few choices.

Step 2: Rule out minimum 3

If the minimum were \(3\), then \(6,9,12\) could not be used. From the remaining numbers \(4,5,7,8,10,11\), we cannot use both \(4\) and \(8\), and cannot use both \(5\) and \(10\). Thus at most four additional numbers can be chosen, not enough for a set of size $6$.

Step 3: Show minimum 4 is possible

The set \[\{4,6,7,9,10,11\}\] works: no larger element in the set is a multiple of a smaller one.

Step 4: Conclude

The least possible value of an element of \(S\) is \(\boxed{4}\).

Key Idea

Construct a large divisibility antichain and prove smaller minimum is impossible.
