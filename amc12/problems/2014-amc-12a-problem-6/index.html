2014 AMC 12A Problem 6

2014AMC 12AProblem 6数论进制与数字数字进制

Problem Statement

The difference between a two-digit number and the number obtained by reversing its digits is $5$ times the sum of the digits of either number. What is the sum of the two-digit number and its reverse?

Choices

  1. A44
  2. B55
  3. C77
  4. D99
  5. E110

Answer

D. 99

Solution

Step 1: Write the digits

Let the two-digit number be $10a+b$ and its reverse be $10b+a$.

Step 2: Use the difference condition

The difference between them is \[|10a+b-(10b+a)|=9|a-b|.\] The sum of the digits is $a+b$, so \[9|a-b|=5(a+b).\]

Step 3: Choose the possible direction

The digit relation that works is \[9(b-a)=5(a+b),\] which simplifies to \[4b=14a,\quad 2b=7a.\]

Step 4: Find the digits

The digit solution is $a=2$, $b=7$, giving the numbers $27$ and $72$.

Step 5: Add the number and its reverse

\[27+72=99.\]

Step 6: Conclude

The answer is $\boxed{99}$.

Key Idea

Write the number and its reverse using digits.
