Problem Statement

An object in the plane moves from one lattice point to another. At each step, the object may move one unit to the right, one unit to the left, one unit up, or one unit down. If the object starts at the origin and takes a ten-step path, how many different points could be the final point?

Choices

  1. A120
  2. B121
  3. C221
  4. D230
  5. E231

Answer

B. 121

Solution

Step 1: Describe reachable points

After \(10\) unit moves on the grid, a final point \((a,b)\) must satisfy \(|a|+|b|\le10\). Also, the parity of \(|a|+|b|\) must match the number of steps, so it must be even.

Step 2: Count by Manhattan distance

The possible Manhattan distances are \(0,2,4,6,8,10\). There is \(1\) point at distance \(0\).

Step 3: Count points at positive distance

For a positive distance \(d\), the number of lattice points satisfying \(|a|+|b|=d\) is \(4d\).

Step 4: Add the even distances

The total is \[1+4(2+4+6+8+10).\]

Step 5: Compute

\[1+4\cdot30=121.\]

Step 6: Conclude

There are \(\boxed{121}\) possible final points.

Key Idea

Count lattice points reachable in at most 10 steps with even parity.
