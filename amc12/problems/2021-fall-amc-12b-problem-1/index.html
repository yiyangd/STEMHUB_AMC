2021 Fall AMC 12B Problem 1

2021 FallAMC 12BProblem 1数论整数构造整数构造

Problem Statement

How many integer values satisfy \[|x|<3\pi?\]

Choices

  1. A9
  2. B10
  3. C18
  4. D19
  5. E20

Answer

D. 19

Solution

Step 1: Estimate the interval

Since $\pi$ is a little more than $3$, we have \[3\pi\approx9.42.\] So the inequality is approximately \[|x|<9.42.\]

Step 2: List the integer range

The integers satisfying this are \[-9,-8,\ldots,0,\ldots,8,9.\]

Step 3: Count symmetrically

There are $9$ negative integers, $9$ positive integers, and $0$.

Step 4: Conclude

The total number is \[9+1+9=19,\] so the answer is $\boxed{19}$.

Key Idea

Estimate the bounds from pi and count integers in a symmetric interval.
