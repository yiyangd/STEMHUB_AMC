2009AMC 12AProblem 7代数数列与递推数列递推

Problem Statement

The first three terms of an arithmetic sequence are \(2x-3\), \(5x-11\), and \(3x+1\), respectively. The \(n\)th term of the sequence is \(2009\). What is \(n\)?

Choices

  1. A255
  2. B502
  3. C1004
  4. D1506
  5. E8037

Answer

B. 502

Solution

Step 1: Use equal differences

In an arithmetic sequence, consecutive differences are equal. So \[(5x-11)-(2x-3)=(3x+1)-(5x-11).\]

Step 2: Solve for x

The left side is \(3x-8\), and the right side is \(-2x+12\). Thus \[3x-8=-2x+12,\] so \(5x=20\), and \(x=4\).

Step 3: Find the sequence

The first term is \(2(4)-3=5\), and the common difference is \(4\).

Step 4: Write the nth term

The \(n\)th term is \[5+4(n-1)=4n+1.\]

Step 5: Solve for n

Set \(4n+1=2009\). Then \(4n=2008\), so \(n=502\).

Step 6: Conclude

The answer is \(\boxed{502}\).

Key Idea

Use equal differences in the arithmetic sequence.
