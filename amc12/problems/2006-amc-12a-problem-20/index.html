2006 AMC 12A Problem 20

2006AMC 12AProblem 20概率与统计独立性独立事件概率

Problem Statement

A bug starts at one vertex of a cube and moves along the edges of the cube according to the following rule. At each vertex the bug will choose to travel along one of the three edges emanating from that vertex. Each edge has equal probability of being chosen, and all choices are independent. What is the probability that after seven moves the bug will have visited every vertex exactly once?

Choices

  1. A\(\frac1{2187}\)
  2. B\(\frac1{729}\)
  3. C\(\frac2{243}\)
  4. D\(\frac1{81}\)
  5. E\(\frac5{243}\)

Answer

C. \frac{2}{243}

Solution

Step 1: Count all possible walks

At each of the \(7\) moves, the bug has \(3\) equally likely edge choices. So there are \[3^7=2187\] possible move sequences.

Step 2: Translate the target event

Visiting every vertex exactly once in \(7\) moves means the bug follows a Hamiltonian path of the cube graph starting from its initial vertex.

Step 3: Use symmetry for the first moves

The first move has \(3\) choices. After that, the second move cannot go back to the starting vertex, so it has \(2\) useful choices if the path is to remain self-avoiding.

Step 4: Count completions after two moves

Once the first two moves are fixed, the remaining shape of the cube leaves exactly \(3\) ways to finish a Hamiltonian path through the remaining five vertices. This can be checked by following the two possible side faces and the one path that crosses to the opposite face earlier.

Step 5: Compute favorable paths

Thus the number of favorable paths is \[3\cdot2\cdot3=18.\]

Step 6: Find the probability

The probability is \[\frac{18}{2187}=\frac{2}{243}.\] The answer is \(\boxed{\frac{2}{243}}\).

Key Idea

Count Hamiltonian paths on the cube graph from a fixed starting vertex.
