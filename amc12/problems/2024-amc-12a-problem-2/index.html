Problem Statement

A model used to estimate hiking time has the form \[T=aL+bG,\] where $T$ is in minutes, $L$ is trail length in miles, and $G$ is altitude gain in feet. It gives $69$ minutes for $(L,G)=(1.5,800)$ and also for $(1.2,1100)$. How many minutes does it estimate for $(4.2,4000)$?

Choices

  1. A240
  2. B246
  3. C252
  4. D258
  5. E264

Answer

B. 246

Solution

Step 1: Set up the two equations

The two given hikes produce \[69=1.5a+800b,\] and \[69=1.2a+1100b.\]

Step 2: Subtract to find a relation

Subtracting the equations gives \[0=0.3a-300b,\] so \[a=1000b.\]

Step 3: Solve for b

Substitute into the first equation: \[69=1.5(1000b)+800b=2300b,\] so \[b=\frac3{100}.\] Then $a=30$.

Step 4: Evaluate the target trail

For $(L,G)=(4.2,4000)$, \[T=30(4.2)+\frac3{100}(4000)=126+120=246.\]

Step 5: Conclude

The answer is $\boxed{246}$.

Key Idea

Solve the linear model or rescale variables to compute the target time.
