2007 AMC 12A Problem 20

2007AMC 12AProblem 20几何空间几何空间几何体积

Problem Statement

Corners are sliced off a unit cube so that the six faces each become regular octagons. What is the total volume of the removed tetrahedra?

Choices

  1. A\(\frac{5\sqrt2-7}{3}\)
  2. B\(\frac{10-7\sqrt2}{3}\)
  3. C\(\frac{3-2\sqrt2}{3}\)
  4. D\(\frac{8\sqrt2-11}{3}\)
  5. E\(\frac{6-4\sqrt2}{3}\)

Answer

B. \frac{10-7\sqrt2}{3}

Solution

Step 1: Let each octagon side be x

When a corner is cut off, each original edge of the cube is split into three parts: a slanted contribution from one cut, a middle octagon side of length \(x\), and another slanted contribution.

Step 2: Relate x to the unit edge

The slanted parts come from \(45^\circ\)-\(45^\circ\)-\(90^\circ\) triangles, so each contributes \(\frac{x}{\sqrt2}\) along the original cube edge. Thus \[x+2\cdot\frac{x}{\sqrt2}=1.\]

Step 3: Solve for x

This gives \(x(1+\sqrt2)=1\), so \[x=\frac1{1+\sqrt2}=\sqrt2-1.\]

Step 4: Find the corner cut length

The leg of each removed corner tetrahedron along a cube edge is \[\frac{x}{\sqrt2}=1-\frac1{\sqrt2}.\] Call this length \(t\).

Step 5: Compute one tetrahedron volume

Each removed corner is a right tetrahedron with three mutually perpendicular edges of length \(t\), so its volume is \[\frac{t^3}{6}.\] There are \(8\) corners, so total removed volume is \[\frac{8t^3}{6}=\frac43\left(1-\frac1{\sqrt2}\right)^3.\]

Step 6: Simplify

This simplifies to \[\frac{10-7\sqrt2}{3}.\] The answer is \(\boxed{\frac{10-7\sqrt2}{3}}\).

Key Idea

Find the cut length that makes each cube face a regular octagon.
