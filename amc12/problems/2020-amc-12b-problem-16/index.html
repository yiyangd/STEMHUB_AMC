2020 AMC 12B Problem 16

2020AMC 12BProblem 16概率与统计组合概率概率计数

Problem Statement

An urn contains one red ball and one blue ball. George performs the following operation four times: he draws a ball from the urn at random and then takes a ball of the same color from a box and returns those two matching balls to the urn. After the four iterations the urn contains six balls. What is the probability that the urn contains three balls of each color?

Choices

  1. A$\frac16$
  2. B$\frac15$
  3. C$\frac14$
  4. D$\frac13$
  5. E$\frac12$

Answer

B. \frac15

Solution

Step 1: Recognize the urn process

This is Polya's urn: drawing a color makes that color more likely later because the drawn ball is returned along with one matching ball.

Step 2: Use symmetry of compositions

Starting with one red and one blue ball, after $4$ additions, the number of added red balls is equally likely to be \[0,1,2,3,4.\]

Step 3: Identify the desired composition

The urn ends with three red and three blue balls exactly when George has added $2$ red balls and $2$ blue balls.

Step 4: Compute the probability

Among the five equally likely possibilities for the number of added red balls, exactly one is favorable.

Step 5: Conclude

The probability is $\boxed{\frac15}$.

Key Idea

Recognize the symmetric Polya urn distribution after four draws.
