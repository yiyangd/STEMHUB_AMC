2017 AMC 12A Problem 9

2017AMC 12AProblem 9几何坐标几何坐标几何

Problem Statement

Let $S$ be the set of points $(x,y)$ in the coordinate plane such that two of the three quantities $3$, $x+2$, and $y-4$ are equal and the third of the three quantities is no greater than this common value. Which of the following is a correct description of $S$?

Choices

  1. Aa single point
  2. Btwo intersecting lines
  3. Cthree lines whose pairwise intersections are three distinct points
  4. Da triangle
  5. Ethree rays with a common endpoint

Answer

E. three rays with a common endpoint

Solution

Step 1: Check 3 equals x plus 2

If \(3=x+2\), then \(x=1\). The third quantity \(y-4\) must be no greater than $3$, so \(y\le7\). This gives a vertical ray ending at \((1,7)\).

Step 2: Check 3 equals y minus 4

If \(3=y-4\), then \(y=7\). The third quantity \(x+2\) must be no greater than $3$, so \(x\le1\). This gives a horizontal ray ending at \((1,7)\).

Step 3: Check x plus 2 equals y minus 4

If \(x+2=y-4\), then \(y=x+6\). The third quantity $3$ must be no greater than the common value, so \(3\le x+2\), giving \(x\ge1\). This gives a diagonal ray starting at \((1,7)\).

Step 4: Combine the cases

The set \(S\) is exactly three rays, all sharing the endpoint \((1,7)\).

Step 5: Conclude

The correct description is $\boxed{\text{three rays with a common endpoint}}$.

Key Idea

Check the three possible equality cases among the three expressions.
