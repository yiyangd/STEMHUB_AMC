2011 AMC 12B Problem 23

2011AMC 12BProblem 23组合数学图形计数网格计数

Problem Statement

A bug travels in the coordinate plane, moving only along the lines that are parallel to the $x$-axis or $y$-axis. Let $A=(-3,2)$ and $B=(3,-2)$. Consider all possible paths of the bug from $A$ to $B$ of length at most $20$. How many points with integer coordinates lie on at least one of these paths?

Choices

  1. A161
  2. B185
  3. C195
  4. D227
  5. E255

Answer

C. 195

Solution

Step 1: Translate path length into Manhattan distance

Because the bug moves only horizontally and vertically, the shortest path length from one point to another is Manhattan distance. A lattice point $P=(x,y)$ lies on some path from $A$ to $B$ of length at most $20$ exactly when \[d(A,P)+d(P,B)\le20.\]

Step 2: Write the inequality

With $A=(-3,2)$ and $B=(3,-2)$, this becomes \[|x+3|+|y-2|+|x-3|+|y+2|\le20.\]

Step 3: Separate x and y

The $x$-part is \[|x+3|+|x-3|,\] and the $y$-part is \[|y-2|+|y+2|.\] Each part is constant inside the interval between its two centers and grows linearly outside.

Step 4: Count by possible x-values

For each integer $x$, compute the remaining allowance for the $y$ expression. Summing over the possible integer $x$ values gives the row counts \[1,5,9,13,17,21,21,21,21,21,17,13,9,5,1.\]

Step 5: Add the row counts

The total number of lattice points is \[1+5+9+13+17+5\cdot21+17+13+9+5+1=195.\]

Step 6: Conclude

The answer is $\boxed{195}$.

Key Idea

A point lies on some allowed path exactly when its Manhattan distances to A and B sum to at most 20.
