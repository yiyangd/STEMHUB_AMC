Problem Statement

A function \(f\) has domain \([0,2]\) and range \([0,1]\). What are the domain and range, respectively, of the function \(g\) defined by \(g(x)=1-f(x+1)\)?

Choices

  1. A\([-1,1],[-1,0]\)
  2. B\([-1,1],[0,1]\)
  3. C\([0,2],[-1,0]\)
  4. D\([1,3],[-1,0]\)
  5. E\([1,3],[0,1]\)

Answer

B. [-1,1],[0,1]

Solution

Step 1: Find the domain first

The expression \(g(x)=1-f(x+1)\) is defined exactly when \(x+1\) is in the domain of \(f\). Since \(f\) has domain \([0,2]\), we need \[0\le x+1\le2.\]

Step 2: Solve for x

Subtracting \(1\) gives \[-1\le x\le1.\] So the domain of \(g\) is \([-1,1]\).

Step 3: Transform the range

The range of \(f\) is \([0,1]\). If \(y=f(x+1)\), then \(0\le y\le1\). The output of \(g\) is \(1-y\).

Step 4: Find the new range

As \(y\) goes from \(0\) to \(1\), \(1-y\) also ranges from \(1\) down to \(0\). Thus the range is still \([0,1]\).

Step 5: Conclude

The answer is \(\boxed{[-1,1],[0,1]}\).

Key Idea

Make \(x+1\) fall in the domain of \(f\), then transform the range by \(1-y\).
