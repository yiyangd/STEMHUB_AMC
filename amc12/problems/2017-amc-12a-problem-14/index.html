2017 AMC 12A Problem 14

2017AMC 12AProblem 14组合数学排列组合排列组合计数

Problem Statement

Alice refuses to sit next to either Bob or Carla. Derek refuses to sit next to Eric. How many ways are there for the five of them to sit in a row of $5$ chairs under these conditions?

Choices

  1. A12
  2. B16
  3. C28
  4. D32
  5. E40

Answer

C. 28

Solution

Step 1: Start with all arrangements

Without restrictions, the five people can sit in \[5!=120\] ways.

Step 2: Define the bad events

Let \(AB\) mean Alice sits next to Bob, \(AC\) mean Alice sits next to Carla, and \(DE\) mean Derek sits next to Eric. We subtract arrangements with any of these bad adjacencies.

Step 3: Count single bad events

Each adjacent pair can be treated as a block in \(2\cdot4!=48\) ways. So the three single counts contribute \(48+48+48\).

Step 4: Count overlaps

For \(AB\) and \(AC\), Alice must be between Bob and Carla, giving \(2\cdot3!=12\) arrangements. For \(AB\) with \(DE\), or \(AC\) with \(DE\), there are \(2\cdot2\cdot3!=24\) arrangements each.

Step 5: Add back the triple overlap

If all three bad adjacencies occur, Alice is between Bob and Carla and Derek is next to Eric, giving \(2\cdot2\cdot2!=8\) arrangements.

Step 6: Apply inclusion-exclusion

The number of bad arrangements is \[48+48+48-12-24-24+8=92.\] Therefore the valid arrangements total \[120-92=28.\]

Step 7: Conclude

The answer is $\boxed{28}$.

Key Idea

Use inclusion-exclusion on forbidden adjacent pairs.
