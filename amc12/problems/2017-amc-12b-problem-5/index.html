2017 AMC 12B Problem 5

2017AMC 12BProblem 5概率与统计平均数与数据集平均数数据

Problem Statement

The data set \([6,19,33,33,39,41,41,43,51,57]\) has median \(Q_2=40\), first quartile \(Q_1=33\), and third quartile \(Q_3=43\). An outlier is more than \(1.5\) times the interquartile range below \(Q_1\) or above \(Q_3\). How many outliers does this data set have?

Choices

  1. A0
  2. B1
  3. C2
  4. D3
  5. E4

Answer

B. 1

Solution

Step 1: Find the interquartile range

The interquartile range is \[Q_3-Q_1=43-33=10.\]

Step 2: Compute the outlier fences

One and a half times the interquartile range is \(1.5\cdot10=15\). So low outliers are below \[33-15=18,\] and high outliers are above \[43+15=58.\]

Step 3: Check the data

The only value below $18$ is \(6\). There are no values above \(58\), since the largest data value is \(57\).

Step 4: Conclude

There is \(\boxed{1}\) outlier.

Key Idea

Compute the interquartile range and the outlier fences.
