2013 AMC 12A Problem 21

2013AMC 12AProblem 21代数对数与指数对数指数

Problem Statement

Consider \[A=\log(2013+\log(2012+\log(2011+\log(\cdots+\log(3+\log2)\cdots)))).\] Which of the following intervals contains $A$?

Choices

  1. A$(\log 2016,\log 2017)$
  2. B$(\log 2017,\log 2018)$
  3. C$(\log 2018,\log 2019)$
  4. D$(\log 2019,\log 2020)$
  5. E$(\log 2020,\log 2021)$

Answer

A. $(\log 2016,\log 2017)$

Solution

Step 1: Name the nested expression

A long nested expression is easier to control if we name its pieces. Define

\[f(2)=\log2,\qquad f(n)=\log(n+f(n-1))\quad(n\ge3).\]

Then the expression in the problem is $A=f(2013)$. We want to locate $f(2013)$ between two nearby logarithms.

Step 2: Reduce the goal to bounding f(2012)

By the definition,

\[A=f(2013)=\log(2013+f(2012)).\]

So if we can show

\[3<f(2012)<4,\]

then

\[2016<2013+f(2012)<2017,\]

which would place $A$ in $(\log2016,\log2017)$.

Step 3: Get the lower bound

The lower bound is direct. Since the inner logarithm values are positive, we have

\[f(2012)=\log(2012+f(2011))>\log2012.\]

Because $1000<2012$, it follows that $\log2012>3$. Therefore $f(2012)>3$.

Step 4: Get a safe upper bound

For the upper bound, it is enough to know that $f(2011)<2011$. This follows by induction: $f(2)<2$, and if $f(n-1)<n-1$, then

\[f(n)=\log(n+f(n-1))<\log(2n-1)<n\]

for the values here. Thus

\[f(2012)=\log(2012+f(2011))<\log(2012+2011)=\log4023<4.\]

Step 5: Conclude the interval

We have shown

\[3<f(2012)<4.\]

Therefore

\[2016<2013+f(2012)<2017,\]

and applying the increasing function $\log$ gives

\[\log2016<A<\log2017.\]

The correct interval is $(\log2016,\log2017)$.

Key Idea

Bound the inner nested logarithm between 3 and 4, then use monotonicity of log.
