2005 AMC 12A Problem 20

2005AMC 12AProblem 20代数运算与化简代数化简

Problem Statement

For each \(x\in[0,1]\), define \[f(x)=\begin{cases}2x,&0\le x\le \frac12,\\2-2x,&\frac12<x\le1.\end{cases}\] Let \(f^{[2]}(x)=f(f(x))\), and \(f^{[n+1]}(x)=f^{[n]}(f(x))\) for each integer \(n\ge2\). For how many values of \(x\in[0,1]\) is \(f^{[2005]}(x)=\frac12\)?

Choices

  1. A0
  2. B2005
  3. C4010
  4. D\(2005^2\)
  5. E\(2^{2005}\)

Answer

E. 2^{2005}

Solution

Step 1: Understand one inverse step

The function is the tent map. For any value strictly between \(0\) and \(1\), there are exactly two preimages, one on each linear branch.

Step 2: Start with the target

The value \(\frac12\) is strictly between \(0\) and \(1\), so \(f(x)=\frac12\) has two solutions: \(x=\frac14\) and \(x=\frac34\).

Step 3: Iterate the idea

Each additional inverse step doubles the number of solutions, because each existing target value lies in \((0,1)\) and has two preimages.

Step 4: Apply 2005 iterations

Therefore the equation \(f^{[2005]}(x)=\frac12\) has \[2^{2005}\] solutions in \([0,1]\).

Step 5: Conclude

The answer is \(\boxed{2^{2005}}\).

Key Idea

Each iteration of the tent map doubles the number of preimages of \( rac12\).
