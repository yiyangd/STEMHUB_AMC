2022 AMC 12A Problem 17

2022AMC 12AProblem 17代数三角恒等式三角函数恒等式

Problem Statement

Suppose $a$ is a real number such that the equation \[a(\sin x+\sin(2x))=\sin(3x)\] has more than one solution in the interval $(0,\pi)$. The set of all such $a$ can be written in the form $(p,q)\cup(q,r)$, where $p<q<r$. What is $p+q+r$?

Choices

  1. A-4
  2. B-1
  3. C0
  4. D1
  5. E4

Answer

A. -4

Solution

Step 1: Use identities to isolate cosine

For $x\in(0,\pi)$, $\sin x>0$. Using \[\sin2x=2\sin x\cos x\] and \[\sin3x=\sin x(4\cos^2x-1),\] the equation becomes \[a(1+2c)=4c^2-1,\] where $c=\cos x$.

Step 2: Notice the special value

When $c=-\frac12$, both sides of the equation are $0$, so $x=\frac{2\pi}{3}$ is always a solution for every $a$.

Step 3: Find when another solution exists

For $c\ne-\frac12$, factor the right side: \[4c^2-1=(2c-1)(2c+1).\] Then \[a=2c-1.\]

Step 4: Find the range of a

Since $c$ ranges over $(-1,1)$, the expression $2c-1$ ranges over $(-3,1)$. But $c=-\frac12$ corresponds to $a=-2$, and that gives only the special solution, not a second one.

Step 5: Write the set

Thus the values of $a$ with more than one solution are \[(-3,-2)\cup(-2,1).\]

Step 6: Conclude

Here $p=-3$, $q=-2$, and $r=1$, so \[p+q+r=-4.\] The answer is $\boxed{-4}$.

Key Idea

Reduce the trigonometric equation using cosine and analyze when a second solution appears.
