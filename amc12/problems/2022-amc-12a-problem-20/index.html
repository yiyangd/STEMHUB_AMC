Problem Statement

Isosceles trapezoid $ABCD$ has parallel sides $AD$ and $BC$, with $BC<AD$ and $AB=CD$. There is a point $P$ in the plane such that $PA=1$, $PB=2$, $PC=3$, and $PD=4$. What is $\frac{BC}{AD}$?

Choices

  1. A$\frac14$
  2. B$\frac13$
  3. C$\frac12$
  4. D$\frac23$
  5. E$\frac34$

Answer

B. $\frac13$

Solution

Step 1: Put the trapezoid in symmetric coordinates

Because the trapezoid is isosceles, it has a line of symmetry perpendicular to the bases. Place the longer base $AD$ horizontally with

\[A=(-a,0),\qquad D=(a,0),\]

and the shorter base with

\[B=(-b,h),\qquad C=(b,h),\]

where $a>b>0$. Then

\[AD=2a,\qquad BC=2b.\]

Step 2: Let P be arbitrary

The point $P$ does not need to lie on the symmetry axis, so write

\[P=(x,y).\]

The distances to $A$ and $D$ are

\[(x+a)^2+y^2=1^2,\]

\[(x-a)^2+y^2=4^2.\]

Step 3: Subtract the equations for A and D

Subtracting the two equations removes $y^2$:

\[(x-a)^2-(x+a)^2=16-1.\]

The left side is $-4ax$, so

\[-4ax=15.\]

Step 4: Use the same idea for B and C

Similarly, the distances to $B$ and $C$ give

\[(x+b)^2+(y-h)^2=2^2,\]

\[(x-b)^2+(y-h)^2=3^2.\]

Subtracting gives

\[(x-b)^2-(x+b)^2=9-4,\]

so

\[-4bx=5.\]

Step 5: Compare the two results

We have

\[-4ax=15,\qquad -4bx=5.\]

Since the same point $P$ has the same $x$-coordinate in both equations,

\[\frac{a}{b}=\frac{15}{5}=3.\]

Therefore $a=3b$.

Step 6: Find the ratio of bases

Finally,

\[\frac{BC}{AD}=\frac{2b}{2a}=\frac ba=\frac13.\]

So the answer is $\frac13$.

Key Idea

Use symmetric coordinates for the isosceles trapezoid and subtract squared distance equations.
