Problem Statement

Find the number of ordered pairs of real numbers \((a,b)\) such that \[(a+bi)^{2002}=a-bi.\]

Choices

  1. A1001
  2. B1002
  3. C2001
  4. D2002
  5. E2004

Answer

E. 2004

Solution

Step 1: Use complex notation

Let \(z=a+bi\). Then \(a-bi=\overline z\), so the equation is \[z^{2002}=\overline z.\]

Step 2: Handle zero separately

If \(z=0\), the equation is true, giving one ordered pair \((0,0)\).

Step 3: Use polar form for nonzero z

For \(z\ne0\), write \(z=re^{i\theta}\). The equation becomes \[r^{2002}e^{i2002\theta}=re^{-i\theta}.\]

Step 4: Compare magnitudes

The magnitudes give \[r^{2002}=r.\] Since \(r>0\), this means \[r^{2001}=1,\] so \(r=1\).

Step 5: Compare angles

With \(r=1\), the angles must satisfy \[2002\theta\equiv-\theta\pmod{2\pi},\] so \[2003\theta\equiv0\pmod{2\pi}.\] This gives \(2003\) distinct points on the unit circle.

Step 6: Add the zero solution

Together with \(z=0\), there are \[2003+1=2004\] ordered pairs \((a,b)\).

Step 7: Conclude

The answer is $\boxed{2004}$.

Key Idea

Use polar form for a complex number and include the zero solution.
