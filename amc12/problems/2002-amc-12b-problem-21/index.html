2002 AMC 12B Problem 21

2002AMC 12BProblem 21数论质因数与整除质因数整除

Problem Statement

For each positive integer \(n<2002\), define \(a_n=11\) if \(n\) is divisible by \(13\) and \(14\), \(a_n=13\) if \(n\) is divisible by \(11\) and \(14\), \(a_n=14\) if \(n\) is divisible by \(11\) and \(13\), and \(a_n=0\) otherwise. Calculate \[\sum_{n=1}^{2001} a_n.\]

Choices

  1. A448
  2. B486
  3. C1560
  4. D2001
  5. E2002

Answer

A. 448

Solution

Step 1: Identify the relevant multiples

The value \(a_n=11\) occurs when \(n\) is a multiple of \(13\cdot14=182\). Since \(n<2002\), there are \(\left\lfloor\frac{2001}{182}\right\rfloor=10\) such multiples.

Step 2: Count the next type

The value \(a_n=13\) occurs for multiples of \(11\cdot14=154\). There are \[\left\lfloor\frac{2001}{154}\right\rfloor=12\] such multiples.

Step 3: Count the third type

The value \(a_n=14\) occurs for multiples of \(11\cdot13=143\). There are \[\left\lfloor\frac{2001}{143}\right\rfloor=13\] such multiples.

Step 4: Check overlap

A number divisible by all three of \(11,13,14\) would be divisible by \(2002\), but no positive multiple of \(2002\) is less than \(2002\). So there is no overlap to correct.

Step 5: Add

The sum is \[11\cdot10+13\cdot12+14\cdot13=110+156+182=448.\]

Step 6: Conclude

The answer is $\boxed{448}$.

Key Idea

Count multiples of pairwise products below 2002.
