2015 AMC 12A Problem 11

2015AMC 12AProblem 11几何圆与曲线圆曲线

Problem Statement

On a sheet of paper, Isabella draws a circle of radius $2$, a circle of radius $3$, and all possible lines simultaneously tangent to both circles. Isabella notices that she has drawn exactly $k\ge0$ lines. How many different values of $k$ are possible?

Choices

  1. A2
  2. B3
  3. C4
  4. D5
  5. E6

Answer

D. 5

Solution

Step 1: Think about center distance

The number of common tangent lines depends on the distance $d$ between the centers of the two circles. The radii are different: $2$ and $3$.

Step 2: When one circle is inside the other

If $d<1$, the smaller circle lies strictly inside the larger circle, so there are no common tangents. If $d=0$, the concentric case also gives $0$ common tangents.

Step 3: When internally tangent

If $d=1$, the circles are internally tangent. There is exactly one common tangent line at the point of tangency.

Step 4: When separated but overlapping

If $1<d<5$, the circles overlap but neither contains the other. There are exactly $2$ common external tangents.

Step 5: When externally tangent or disjoint

If $d=5$, there are $3$ common tangents. If $d>5$, there are $4$ common tangents.

Step 6: Count possible values

The possible values of $k$ are \[0,1,2,3,4,\] so there are $\boxed{5}$ different values.

Key Idea

Classify the number of common tangents by the distance between circle centers.
