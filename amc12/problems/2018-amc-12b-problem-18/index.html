2018AMC 12BProblem 18数论整数构造整数构造

Problem Statement

A function \(f\) is defined recursively by \(f(1)=f(2)=1\) and \(f(n)=f(n-1)-f(n-2)+n\) for all integers \(n\ge3\). What is \(f(2018)\)?

Choices

  1. A2016
  2. B2017
  3. C2018
  4. D2019
  5. E2020

Answer

B. 2017

Solution

Step 1: Compute a few values

Starting from \(f(1)=f(2)=1\), the next values are \[f(3)=3,\quad f(4)=6,\quad f(5)=8,\quad f(6)=8.\]

Step 2: Look at f(n)-n

The sequence \(f(n)-n\) begins \[0,-1,0,2,3,2,\] and then repeats with period \(6\). This follows directly by applying the same recurrence to the difference sequence.

Step 3: Use 2018 modulo 6

Since \(2018\equiv2\pmod6\), the corresponding difference is \(-1\).

Step 4: Compute

Therefore \[f(2018)=2018-1=2017.\]

Step 5: Conclude

The answer is \(\boxed{2017}\).

Key Idea

Find the period in f(n)-n.
