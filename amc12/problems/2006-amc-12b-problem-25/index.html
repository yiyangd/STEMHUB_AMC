2006 AMC 12B Problem 25

2006AMC 12BProblem 25数论整数构造整数构造

Problem Statement

A sequence \(a_1,a_2,\ldots\) of non-negative integers is defined by the rule \(a_{n+2}=|a_{n+1}-a_n|\) for \(n\ge1\). If \(a_1=999\), \(a_2<999\), and \(a_{2006}=1\), how many different values of \(a_2\) are possible?

Choices

  1. A165
  2. B324
  3. C495
  4. D499
  5. E660

Answer

B. 324

Solution

Step 1: Notice the Euclidean-algorithm behavior

The recurrence \(a_{n+2}=|a_{n+1}-a_n|\) repeatedly replaces two numbers by their difference. This preserves the greatest common divisor of consecutive terms.

Step 2: Use the gcd condition

Since \(a_{2006}=1\), the original pair \((999,a_2)\) must have gcd \(1\). If the gcd were larger than \(1\), every term would be divisible by that gcd and could never equal \(1\).

Step 3: Track the phase

When the gcd is \(1\), the sequence eventually reaches the repeating cycle \(1,1,0,1,1,0,\ldots\). The position of this cycle depends on the parity of \(a_2\). Since \(999\) is odd and \(2006\equiv2\pmod3\), the term \(a_{2006}\) is \(1\) exactly when \(a_2\) is odd.

Step 4: Count odd numbers coprime to 999

We need odd \(a_2\) with \(0\le a_2<999\) and \(\gcd(a_2,999)=1\). Since \[999=3^3\cdot37,\] \[\varphi(999)=999\left(1-\frac13\right)\left(1-\frac1{37}\right)=648.\]

Step 5: Take half by parity

Because \(999\) is odd, the coprime residues pair as \(t\) and \(999-t\), one odd and one even. Therefore exactly half of the \(648\) coprime values are odd.

Step 6: Conclude

The number of possible values is \[\frac{648}{2}=324.\] The answer is \(\boxed{324}\).

Key Idea

Use Euclidean-algorithm behavior and parity to count valid \(a_2\).
