2024 AMC 12B Problem 5

2024AMC 12BProblem 5数论整数构造奇数和贪心最值

Problem Statement

In the expression $1+3+5+7+\cdots+97+99$, Melanie changes some plus signs to minus signs. The new expression is negative. What is the least number of plus signs that Melanie could have changed to minus signs?

Choices

  1. A14
  2. B15
  3. C16
  4. D17
  5. E18

Answer

B. 15

Solution

Step 1: Find the original value of the expression

The sum of the first $50$ positive odd numbers is $50^2$. Therefore

\[1+3+5+\cdots+99=2500.\]

To make the expression negative, Melanie must reduce this sum by more than $2500$.

Step 2: Understand the effect of changing one sign

If a term $t$ changes from $+t$ to $-t$, the total changes by $-2t$. So changing signs on terms whose sum is $S$ decreases the expression by $2S$.

We need

\[2500-2S<0,\]

so $S>1250$.

Step 3: Choose the largest odd numbers first

To use the fewest sign changes, Melanie should choose the largest terms: $99,97,95,\ldots$. The sum of the $k$ largest odd numbers from $1$ to $99$ is

\[k(100-k).\]

Step 4: Find the smallest $k$ that works

For $k=14$,

\[14(86)=1204,\]

which is not enough. For $k=15$,

\[15(85)=1275,\]

which is greater than $1250$.

Step 5: Conclude the minimum

Thus $14$ changes cannot make the expression negative, but $15$ changes can. The least number is $15$.

Key Idea

Changing a plus to a minus lowers the sum by twice that odd number, so choose largest terms first.
