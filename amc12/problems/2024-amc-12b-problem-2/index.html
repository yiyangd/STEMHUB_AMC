Problem Statement

What is $10!-7!\cdot6!$?

Choices

  1. A$-120$
  2. B0
  3. C120
  4. D600
  5. E720

Answer

B. 0

Solution

Step 1: Look for a common factorial factor

The expression is

\[10!-7!\cdot6!.\]

A direct computation would use large numbers, but both terms contain $7!$ in a useful way.

Step 2: Rewrite $10!$ using $7!$

We have

\[10!=10\cdot9\cdot8\cdot7!.\]

Also $6!=720$, and

\[10\cdot9\cdot8=720.\]

Step 3: Compare the two terms

So

\[10!=720\cdot7!\]

and

\[7!\cdot6!=7!\cdot720.\]

These are exactly the same number.

Step 4: Subtract

Therefore

\[10!-7!\cdot6!=0.\]

The answer is $0$.

Key Idea

Factor out a common factorial to compare the two terms efficiently.
