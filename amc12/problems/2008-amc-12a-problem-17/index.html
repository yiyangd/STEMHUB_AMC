2008 AMC 12A Problem 17

2008AMC 12AProblem 17数论整数构造整数构造

Problem Statement

Let \(a_1,a_2,\ldots\) be a sequence of integers determined by the rule \(a_n=\frac{a_{n-1}}{2}\) if \(a_{n-1}\) is even and \(a_n=3a_{n-1}+1\) if \(a_{n-1}\) is odd. For how many positive integers \(a_1\le2008\) is it true that \(a_1\) is less than each of \(a_2,a_3,\) and \(a_4\)?

Choices

  1. A250
  2. B251
  3. C501
  4. D502
  5. E1004

Answer

D. 502

Solution

Step 1: Rule out even starting values

If \(a_1\) is even, then \(a_2=\frac{a_1}{2}<a_1\). That immediately fails the condition, so \(a_1\) must be odd.

Step 2: Compute the next two terms for odd a1

For odd \(a_1\), we have \[a_2=3a_1+1,\] which is even, so \[a_3=\frac{3a_1+1}{2}.\] This is always greater than \(a_1\) for positive \(a_1\).

Step 3: Decide what happens at a3

The key question is whether \(a_3\) is even or odd. If \(a_1\equiv1\pmod4\), then \(3a_1+1\) is divisible by \(4\), so \(a_3\) is even.

Step 4: Show the failing case

When \(a_1\equiv1\pmod4\), \[a_4=\frac{a_3}{2}=\frac{3a_1+1}{4},\] which is less than \(a_1\) for positive \(a_1>1\). Thus these do not work.

Step 5: Show the working case

When \(a_1\equiv3\pmod4\), \(a_3\) is odd, so \[a_4=3a_3+1=\frac{9a_1+5}{2},\] which is greater than \(a_1\). Thus exactly the numbers \(a_1\equiv3\pmod4\) work.

Step 6: Count them

The positive integers at most \(2008\) congruent to \(3\pmod4\) are \(3,7,\ldots,2007\). There are \[\frac{2007-3}{4}+1=502\] of them.

Step 7: Conclude

The answer is \(\boxed{502}\).

Key Idea

Analyze the first three Collatz-type steps by congruence modulo \(4\).
