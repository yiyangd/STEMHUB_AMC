Problem Statement

Rabbits Peter and Pauline have three offspring--Flopsie, Mopsie, and Cotton-tail. These five rabbits are to be distributed to four different pet stores so that no store gets both a parent and a child. It is not required that every store gets a rabbit. In how many different ways can this be done?

Choices

  1. A96
  2. B108
  3. C156
  4. D204
  5. E372

Answer

D. 204

Solution

Step 1: Focus on the parents first

The restriction is about parent-child pairs. It is natural to split the count based on whether the two parents go to the same store or to different stores.

Step 2: Parents in the same store

If both parents go to one store, choose that store in $4$ ways. Each of the three children must avoid that store, so each has $3$ choices. This gives \[4\cdot3^3=108\] arrangements.

Step 3: Parents in different stores

If the parents go to different stores, place Peter in $4$ ways and Pauline in $3$ ways. Each child must avoid both parent stores, so each child has $2$ choices. This gives \[4\cdot3\cdot2^3=96\] arrangements.

Step 4: Add the cases

The cases are disjoint, so the total is \[108+96=204.\]

Step 5: Conclude

The answer is $\boxed{204}$.

Key Idea

Separate the cases where the parents go to the same store or different stores.
