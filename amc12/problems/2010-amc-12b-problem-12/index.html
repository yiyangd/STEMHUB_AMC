2010 AMC 12B Problem 12

2010AMC 12BProblem 12代数对数与指数对数指数

Problem Statement

For what value of $x$ does \[\log_{\sqrt2}\sqrt{x}+\log_2 x+\log_4(x^2)+\log_8(x^3)+\log_{16}(x^4)=40?\]

Choices

  1. A8
  2. B16
  3. C32
  4. D256
  5. E1024

Answer

D. 256

Solution

Step 1: Use one logarithm base

Let \[t=\log_2 x.\] Then $\log_2\sqrt{x}=\frac12t$, but the first term has base $\sqrt2$, so \[\log_{\sqrt2}\sqrt{x}=\frac{\frac12t}{\frac12}=t.\]

Step 2: Convert the remaining terms

We also have \[\log_2x=t,\quad \log_4(x^2)=\frac{2t}{2}=t,\quad \log_8(x^3)=\frac{3t}{3}=t,\quad \log_{16}(x^4)=\frac{4t}{4}=t.\]

Step 3: Add the terms

The left side is therefore \[t+t+t+t+t=5t.\]

Step 4: Solve for t

The equation becomes \[5t=40,\] so $t=8$.

Step 5: Convert back to x

Since $t=\log_2x$, we get \[x=2^8=256.\]

Step 6: Conclude

The answer is $\boxed{256}$.

Key Idea

Convert every logarithm to base 2.
