2010 AMC 12A Problem 19

2010AMC 12AProblem 19概率与统计组合概率概率计数

Problem Statement

Each of $2010$ boxes in a line contains a single red marble, and for $1\le k\le2010$, the box in the $k^{\text{th}}$ position also contains $k$ white marbles. Isabella begins at the first box and successively draws a single marble at random from each box, in order. She stops when she first draws a red marble. Let $P(n)$ be the probability that Isabella stops after drawing exactly $n$ marbles. What is the smallest value of $n$ for which $P(n)<\frac1{2010}$?

Choices

  1. A45
  2. B63
  3. C64
  4. D201
  5. E1005

Answer

A. 45

Solution

Step 1: Write the stopping event

To stop after exactly $n$ marbles, Isabella must draw white marbles from boxes $1$ through $n-1$, and then draw a red marble from box $n$.

Step 2: Compute each probability

In box $k$, there are $k$ white marbles and $1$ red marble, so the probability of drawing white is \[\frac{k}{k+1}\] and the probability of drawing red is \[\frac1{k+1}.\]

Step 3: Use telescoping

Thus \[P(n)=\left(\frac12\cdot\frac23\cdot\frac34\cdots\frac{n-1}{n}\right)\cdot\frac1{n+1}.\] The product telescopes to $\frac1n$, so \[P(n)=\frac1{n(n+1)}.\]

Step 4: Apply the inequality

We need \[\frac1{n(n+1)}<\frac1{2010},\] which is equivalent to \[n(n+1)>2010.\]

Step 5: Find the smallest n

Since \[44\cdot45=1980<2010,\] but \[45\cdot46=2070>2010,\] the smallest possible $n$ is $45$.

Step 6: Conclude

The answer is $\boxed{45}$.

Key Idea

Use a telescoping product for drawing whites before the first red.
