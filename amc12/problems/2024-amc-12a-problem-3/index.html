2024 AMC 12A Problem 3

2024AMC 12AProblem 3数论整数构造两位数最值整数拆分

Problem Statement

The number $2024$ is written as the sum of not necessarily distinct two-digit numbers. What is the least number of two-digit numbers needed?

Choices

  1. A20
  2. B21
  3. C22
  4. D23
  5. E24

Answer

B. 21

Solution

Step 1: Use an upper bound

To minimize the number of two-digit summands, make each summand as large as possible. The largest two-digit number is $99$.

Step 2: Show 20 is not enough

With $20$ two-digit numbers, the largest possible sum is \[20\cdot99=1980,\] which is less than $2024$.

Step 3: Show 21 works

We can write \[2024=20\cdot99+44.\] This uses twenty copies of $99$ and one copy of $44$, all two-digit numbers.

Step 4: Conclude

The least number needed is $\boxed{21}$.

Key Idea

Use the largest possible two-digit summands and check achievability.
