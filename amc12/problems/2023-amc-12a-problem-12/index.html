Problem Statement

What is the value of \[2^3-1^3+4^3-3^3+6^3-5^3+\cdots+18^3-17^3?\]

Choices

  1. A2023
  2. B2679
  3. C2941
  4. D3159
  5. E3235

Answer

D. 3159

Solution

Step 1: Pair the cubes

Each pair has the form \[(2k)^3-(2k-1)^3,\] for $k=1,2,\ldots,9$.

Step 2: Simplify one pair

Using $n^3-(n-1)^3=3n^2-3n+1$, with $n=2k$, the pair becomes \[12k^2-6k+1.\]

Step 3: Sum over k

The total is \[\sum_{k=1}^{9}(12k^2-6k+1)=12\sum k^2-6\sum k+9.\]

Step 4: Compute

Using \[\sum_{k=1}^9 k=45,\quad \sum_{k=1}^9 k^2=285,\] the value is \[12(285)-6(45)+9=3420-270+9=3159.\]

Step 5: Conclude

The answer is $\boxed{3159}$.

Key Idea

Pair consecutive cubes and sum a quadratic expression.
