2024 AMC 12B Problem 3

2024AMC 12BProblem 3代数方程与不等式绝对值不等式整数解估计

Problem Statement

For how many integer values of $x$ is $|2x|\le 7\pi$?

Choices

  1. A16
  2. B17
  3. C19
  4. D20
  5. E21

Answer

E. 21

Solution

Step 1: Understand what is being counted

The problem asks for integer values of $x$, not for a length of an interval. After solving the inequality, we must count the integers inside it.

Step 2: Isolate $x$ inside the absolute value

The inequality is

\[|2x|\le7\pi.\]

Since $|2x|=2|x|$, divide both sides by $2$ to get

\[|x|\le\frac{7\pi}{2}.\]

Step 3: Estimate the endpoint only as much as needed

We only need to know which integers fit. Since $\pi$ is a little more than $3$, $\frac{7\pi}{2}$ is a little more than $10.5$. Since $\pi<\frac{22}{7}$, we also have $\frac{7\pi}{2}<11$.

So the cutoff is between $10.5$ and $11$.

Step 4: List the possible integers

The allowed integers are

\[-10,-9,\ldots,-1,0,1,\ldots,9,10.\]

That is $10$ negative integers, $0$, and $10$ positive integers.

Step 5: Count and check the endpoints

The total is

\[10+1+10=21.\]

The endpoint $11$ is too large, but $10$ is allowed. Therefore the answer is $21$.

Key Idea

Turn the absolute value inequality into a symmetric interval and count the integers.
