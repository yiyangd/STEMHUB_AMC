2017 AMC 12A Problem 15

2017AMC 12AProblem 15代数三角恒等式三角函数恒等式

Problem Statement

Let \[f(x)=\sin x+2\cos x+3\tan x,\] using radian measure for $x$. In what interval does the smallest positive value of $x$ for which $f(x)=0$ lie?

Choices

  1. A(0,1)
  2. B(1,2)
  3. C(2,3)
  4. D(3,4)
  5. E(4,5)

Answer

D. (3,4)

Solution

Step 1: Check the early positive interval

For \(0<x<\frac{\pi}{2}\), all three terms \(\sin x\), \(2\cos x\), and \(3\tan x\) are positive, so there is no zero there.

Step 2: Remove the interval from pi over 2 to pi

On \(\frac{\pi}{2}<x<\pi\), multiply by the negative number \(\cos x\). The equation \(f(x)=0\) is equivalent to \[\sin x\cos x+2\cos^2x+3\sin x=0.\] In this interval, this expression is positive, so \(f(x)\) cannot be zero.

Step 3: Look near pi

At \(x=\pi\), \[f(\pi)=0+2(-1)+0=-2,\] so the function is negative just after \(\pi\).

Step 4: Test x equals 4

At \(x=4\), \(\sin4<0\), \(\cos4<0\), and \(\tan4>0\). Numerically, \[f(4)=\sin4+2\cos4+3\tan4>0.\]

Step 5: Locate the first root

Since \(f\) changes from negative near \(\pi\approx3.14\) to positive by \(x=4\), the smallest positive zero lies between \(3\) and \(4\).

Step 6: Conclude

The answer is $\boxed{(3,4)}$.

Key Idea

Analyze signs of the trigonometric expression across standard intervals.
